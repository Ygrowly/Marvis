## 原始 JD

【我们需要你】

1. 服务器端通讯系统、逻辑系统的设计及开发；
2. 合理组织服务器端数据结构，并和客户端进行有效沟通；
3. 设计，编码，测试，文档记录；
4. 与设计人员配合，将设计开发成产品；
5. 与项目经理配合，详细了解并实现需求；
6. 与架构设计师配合，对模块进行设计和开发；
7. 与测试人员配合，了解并解决产品中存在的问题。

【我们希望你】

1. 2027 届本科及以上毕业生，计算机、软件、通讯等相关专业；java 优先；
2. 有游戏开发经验优先；
3. 了解数据结构、算法、TCP/IP 协议；
4. 学习能力强，能快速上手陌生技术栈和业务逻辑；
5. 有实际使用 AI Agent 工具的经验优先（如 Cursor Agent、GitHub Copilot Agent、Claude Code 等），能描述 AI 如何融入自己的日常开发流程。
