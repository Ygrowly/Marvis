## 2. 自我介绍

**30 秒版**：

> 我是刘宇广，2027 届数据科学本科，目标 AI 应用 / Agent 开发方向。两段 AI 实习：在金山独立设计实现了园区能耗 Agent 平台的工具治理与数据链路，Agent 任务完成率 83.3%→95.8%、越权拦截 100%；此前在初创公司核心开发企业问数平台 Data Agent 链路与查询安全边界，查询成功率（SQL 可执行且结果口径正确）78%→91%。另有个人项目 RuleArena，做 Agent 对抗验证与发布门禁。可提前实习。

**60 秒版**（在 30 秒基础上加主线收尾）：

> 三个项目分别证明三件事：数驭穹图让问数结果数据可信——语义层统一口径、五层安全、证据绑定；EnergyOps 让业务 Agent 执行可控——30 个 MCP 工具按 R0/R1/R2 分级、Hook 链拦截越权、评测分层回流；RuleArena 让 Agent 行为结果可证——确定性 Oracle 裁决、双评测集门禁、最小反例回归。我的判断是：Agent 生产化的瓶颈在可靠性工程，不在模型。

## 3. 项目速览卡

### A. 金山 EnergyOps（P0，独立设计与实现）
- **一句话**：把 604 台质量参差的水电表读数，变成可信的用能账、异常账、结算账，Agent 是受治理的入口。
- **最硬数字**：完成率 83.3→95.8%、越权拦截 100%、P95 20.4s→2.8s、研判 18→6min。
- **范式**：Hook 链治理 / 风险分级 / 异常三层分离 / 三道质量门。
- **面试卡**：`projects/EnergyOps/EnergyOps-项目说明.md` 第 14 节。

### B. 数驭穹图（P0，初创核心开发）
- **一句话**：让没有数据团队的中小企业用自然语言获得可信分析结果——"SQL 能执行 ≠ 业务答案正确"。
- **最硬数字**：查询成功率 78→91%、危险语句拦截 100%、Token -80.4%、Top-K Schema 召回 81→95%。
- **范式**：语义层先行 / 六阶段可归因 / 五层安全 / 证据绑定。
- **面试卡**：`projects/数驭穹图/数驭穹图项目说明.md` 第 13 节。

### C. RuleArena（P0，个人项目，独立设计与实现）
- **一句话**：业务 Agent 上线前的执行门禁——Agent 负责做事，系统负责证明它没做错。
- **最硬数字**：**已实测**（golden-v4 / deepseek-v4.1-flash）——dev 集 Multi 5/14 高于 BFS 2/14，但 hidden 重复 3 次暴露 **`pass@3 = 8/14` 而 `pass^3 = 1/14`**（搜索不可复现，必须与机制层达标成对陈述：误报 0 / 泄漏 0 / 稳定重放 42/42）；Gate 如实拒绝放行。**被测 Refund Agent 与运行时门禁仍是设计阶段（E3）**。
- **范式**：编译契约 / 防自证三角 / 双集隔离 / pass@k 与 pass^k 分开报 / 最小反例回归。
- **面试卡**：`projects/RuleArena/RuleArena-项目说明.md` 第 14 节。

### D. PayTrace / E. Ovanta（**2026-09-13 移出准备范围**）

- **不进简历、面试也不主动提**。材料完整留档在 `archive/PayTrace/`、`archive/Ovanta/` 下（说明见 `archive/README.md`），**被面试官直接问到再照实答**，但不进任何面试稿、不主动引导话题。
- 唯一保留的用法：被问到 2025/09–2026/01 经历空档时，用一句话说明那段全栈实习与数驭穹图并行（见 [[简历逐句作战地图]] 第 6 节）。

## 5. 高频问题清单

### 技术面
1. **自我介绍**（30/60 秒）→ 第 2 节
2. **介绍项目**（90 秒）→ 口述脚本逐项目稿
3. **简历逐句深挖** → [[简历逐句作战地图]]（本阶段主资料）
4. **业务架构**（上下游/模块/数据流）→ 四项目方案第 2.2 节骨架 + 口述脚本
5. **难点题** → 四项目方案第 2.3 节追杀方向预演
6. **范式题**（为什么不用 X？换场景还能用吗？）→ 四项目方案第 5 节八条能力轴
7. **量化防守** → 第 4 节 + 量化口径文件
8. **通用技术栈**（Agent/RAG/MCP/Python/DB/系统设计）→ wiki/interview/面试回答与复习验收手册.md 第 2 节十二个标准答案 + 第 3 节题库索引；字节向 wiki/interview/面经-字节AI-Agent.md

### 行为面
1. **「是你一个人做的吗」** → 金山话术第 2 节（结构通用）
2. **「实习生怎么主导架构」** → 金山话术第 3 节（新方向+数据挣来主导权）
3. **「协作最难的事 / 重来一次改哪里」** → 金山话术第 8 节候选
4. **职业规划 / 为什么选我们** → 结合对方 JD 说"我做过 X，想在贵司 Y 上继续做"

### 反问环节（准备 2-3 个）
- 这个岗位的 Agent 落地路径是平台复用还是场景定制？
- 团队目前最想攻克的 Agent 可靠性问题是什么？
- 校招生进来前 3 个月通常参与什么？

## 6. 金山专项（大厂必问「个人边界」）

详见金山话术文件。核心三句：

1. **"不是一个人"** → 团队共同推进，但数据模型/工具链/安全治理是我主导提出并实现。
2. **"我负责的部分有线上结果"** → 完成率 95.8%、越权拦截 100%、聚合完整率 99.7%。
3. **"为什么实习生能主导"** → Agent 是新方向无现成答案，我用方案+评测数据挣来主导权。

> 使用前必须补齐话术中的 7 个【】真实信息（作战地图第 8 节跟踪）。
