## 2. 自我介绍

**30 秒版（约 120 字）**：

> 我是刘宇广，2027 届数据科学本科，目标 Agent 开发 / AI 应用方向。在金山实习期间，主导构建了 25 个 MCP 工具与 R0/R1/R2 风险分级框架，把 Agent 任务完成率从 83.3% 提到 95.8%、越权拦截 100%；此前主导过一个跨行业可信 NL2SQL 平台，查询成功率 78%→91%。可提前实习。

**60 秒版**（在 30 秒基础上加）：
> 我做过四件事：一个商业化已上线的全栈平台（Ovanta，账权一致率 99.95%）、一个跨行业 NL2SQL 数据平台（数驭穹图）、一个企业级能耗运营 Agent（金山 EnergyOps）、一个支付诊断 Agent 个人项目（PayTrace，F1 0.87）。我的主线是"怎么让 AI 在真实业务里可靠落地"。

## 3. 四项目速览卡

### A. 金山 EnergyOps（重点，头部公司+进行中）
- **一句话**：把 604 台质量参差的水电表读数，变成可信的用能账、异常账、结算账。
- **我的角色**：主导数据模型、Agent 工具链、安全治理。
- **最硬数字**：任务完成率 83.3→95.8%、越权拦截 100%、P95 20.4s→2.8s、研判 18→6min。
- **版本侧重**：A 版主打项目。
- **范式**：Hook 链治理 / 异常三层分离 / 三道质量门 / Offload-Onload。
- **面试卡**：`projects/金山 EnergyOps.md` §13-14。

### B. 数驭穹图（重点，NL2SQL 落地）
- **一句话**：让没有数据团队的中小企业用自然语言获得可信分析结果。
- **我的角色**：主导 Data Agent 链路、语义层、安全边界。
- **最硬数字**：查询成功率 78→91%、危险语句拦截 100%、Token -80.4%、召回率 81→95%。
- **版本侧重**：B 版主打项目。
- **范式**：业务事实层优先 / 可信问数 / 混合 Runtime / 证据绑定。
- **面试卡**：`projects/数驭穹图项目说明.md` §12-13。

### C. Ovanta（商业化闭环，证明全栈）
- **一句话**：一套核心代码服务国内外两站的签证/移民自助申请平台，已上线。
- **我的角色**：主导内容模型、区域配置化、支付幂等。
- **最硬数字**：账权一致率 99.95%、2000 次回放重复 0、200+ 页面复用、日均 3 万事件。
- **版本侧重**：B 版补充项目，A 版可提。
- **面试卡**：`projects/Ovanta完整项目说明.md` §17-18。

### D. PayTrace（个人项目，Agent 可信闭环）
- **一句话**：用确定性代码算损失、Agent 查根因、证据契约阻止无依据结论的支付诊断 Agent。
- **我的角色**：独立完成（模拟数据，诚实说明）。
- **最硬数字**：F1 0.61→0.87、MAE 18.6→6.8、无依据结论 14.2→2.5、工具调用 11→6。
- **版本侧重**：A 版主打，B 版补充。
- **面试卡**：`projects/PayTrace完整项目说明.md` §20-21。

## 5. 高频问题清单

### 技术面
1. **自我介绍**（30/60 秒）→ §2
2. **介绍项目**（90 秒）→ 方法论见快速上手指南 §1；四项目速览见 §3
3. **业务架构**（上游/内部模块/数据流）→ 快速上手指南 §2.2
4. **讲一个难点**（背景→链路→难点→方案→选型）→ 快速上手指南 §2.3
5. **范式题**（为什么不用 Prompt？换场景还能用吗？）→ 快速上手指南 §3，四项目对照表见其 §5
6. **量化防守**（每个数字四件事）→ §4 + 口径文档
7. **技术栈提问**（Agent/RAG/MCP/Python/数据库）→ `wiki/interview/AI应用开发面试题.md`、`后端工程面试题.md`

### 行为面
1. **「这个项目是你一个人做的吗」** → 金山话术 §2（结构通用，可套到其他项目）
2. **「你只是实习生，怎么会主导架构」** → 金山话术 §3（新方向+数据挣来主导权）
3. **「协作中最难的事」** → 金山话术 §8 候选
4. **「重来一次改哪里」** → 金山话术 §8 候选
5. **职业规划 / 为什么选我们** → 提前准备：结合目标公司业务说"我做过 X，想在贵司的 Y 上继续做"

### 反问环节（准备 2-3 个）
- 这个岗位的 Agent 落地路径是平台复用还是场景定制？
- 团队目前最想攻克的 Agent 可靠性问题是什么？
- 校招生进来前 3 个月通常参与什么？

## 6. 金山专项（大厂必问的「个人边界」）

详见 `wiki/interview/金山实习-个人分工与团队协作话术.md`。核心三句：

1. **"不是一个人"** → 团队共同推进，但数据模型/工具链/安全治理是我主导提出并实现的。
2. **"我负责的部分有线上结果"** → 任务完成率 95.8%、越权拦截 100%、聚合完整率 99.7%。
3. **"为什么实习生能主导"** → Agent 是新方向无现成答案，我用方案+评测数据挣来的主导权。

> 使用前必须补齐话术中的 7 个【】真实信息，并从候选库选真实发生过的协作难点与反思点。

## 7. 面试前 Checklist

- [ ] 30 秒 + 60 秒自我介绍各练 10 遍，录音核对时长

- [ ] 每个版本简历对应的「主打项目」排在最前且能展开
- [ ] 量化速查表（§4）每个数字能回答"怎么算/样本/基线/验证"
- [ ] 金山话术 7 个【】已填真实信息
- [ ] 准备 2 个真实协作难点 + 2 个真实反思点
- [ ] 准备 3 个反问问题
- [ ] 确认投递版本与叙事一致（A 版→字节/美团，B 版→阿里/得物）

## 8. 长期训练节奏

完整 15 天冲刺与长期复训见 `四项目面试掌握与模拟训练方案.md` §9、§11。核心节奏：

- **第一周**：立骨架——90 秒介绍 + 业务架构 + 每个项目 1 个难点（用快速上手指南方法论）
- **第二周**：填血肉——36 道母题逐题过（方案 §6），量化数字全防守
- **持续**：每周 1 场模拟面试 + 范式跨项目对照 + 量化抽查
