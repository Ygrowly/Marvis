# 《儒释道》· 读厚卡片

> 来源是道篇（09-09）与儒家篇·佛家篇（09-28）两份笔记（术澄长视频，本人手写整理）。道篇的命功已沉淀 [[性命双修执行案]]，本组卡收三家**临场可用的功夫**：儒修关系、道修身体、佛修心。每张卡只回答：遇到什么情境 → 具体做什么。

## card rsd-1 · 生心无住

**一句话**：修行的目标态是「生心 + 无住」——事来全心应对，事去不留痕迹；其余三态（凡夫粘着 / 神秀式压抑 / 枯坐死寂）都不是。

**情境**：面试、模拟面、当面被追问——心跳上来了，一边应对一边想「我刚才那句是不是说砸了」，心被两个事撕着。

**标准动作**：事来时允许心动（生心），但只住在这件事上：全部注意力给当前这一问，答完即走，不回放（无住）；事后用三行描述性复盘采集，不粘着。慌张时刻 = 凡夫「生心有住」态，三行法 + 动作化就是练「生心无住」。

**触发器**：
- 当答完一题脑子还在回放上一题 → 默念「事去不留」，注意力给面试官的下一句
- 当强迫自己「别紧张」（不生心）→ 识别为神秀式压抑，改「可以紧张，只管当前这一问」
- 当面试结束反复想整体表现 → 留到当晚三行复盘，当场只收数据

**易错**：把「无住」演成「不上心」——无住是应对后不留，不是应对时不用力；生心在前，无住在后，顺序不能反。

**关联**：[[行动规则|R7-逆境：算自己的账]]、[[行动规则|R10-never miss twice]]

## card rsd-2 · 观自在：谁在观察

**一句话**：观自在 = 观察自己——被情绪、身份、念头驱动的是假我，能观察的是真我；观照起心动念，让真我做主。

**情境**：情绪上头（焦虑、委屈、亢奋）说不出为什么；或深夜胡思乱想停不下来，知道自己该睡却停不下来。

**标准动作**：从「想」切到「看想」——问一句「谁在观察这个念头？」；给情绪起名（「这是焦虑，在怕 10 月没面试」）不起判词；晚间记录的第一行就写「今天观察到自己在 X 时起了 Y 念」。

**触发器**：
- 当发现自己在心里跟人辩论（没发生的对话）→ 切观察者：「谁在辩论、在赢什么」
- 当情绪大到影响动作 → 起名 + 写一句来源，然后回到手上动作
- 当晚间记录写不出事 → 写「今天观察到的念头」一条即可，不空过

**易错**：把观照用成新的自我批判——观察不带评判（同 xd-1），发现「又在演假我」也是评判，看到即可。

**关联**：[[行动规则|R9-命功是电池]]

## card rsd-3 · 对自己不诚是判词

**一句话**：神秀输在压住本性、对自己不诚——明知如此却装作不如此，功夫全花在维持人设上。

**情境**：明知某事该做（内推开口、约面复盘）却在找体面的理由拖着；或明知自己某项弱，嘴上却说「问题不大」。

**标准动作**：先对自己诚实一句（写下来，不用告诉任何人）：「我其实在怕 X / 我其实想要 Y」→ 诚实之后动作自动清晰（怕丢脸→用 R 系话术开口；弱→进台账立闭环问题）。众弟子「不敢写」偈，不是「不如神秀」——敢认领才有的谈。

**触发器**：
- 当连续给同一件事找第三个理由时 → 停，写诚实句：「我其实在……」
- 当嘴上说问题不大 → 查台账有没有这个问题；没有就登记，有就看触碰日期
- 当想给别人一个更好的版本的我 → 先给自己真实版本（对自己不诚是最贵的表演）

**易错**：把「对自己诚实」用成自我贬低原料——诚实句的产出是动作，不是判决（同 xd-1 断评判）。

**关联**：[[行动规则|R6-我不负责清单]]

## card rsd-4 · 修什么，先分家

**一句话**：状态出问题先分类再选功夫——儒修关系、道修身体、佛修心；拿错功夫（用修心的办法治失眠、用修身的办法治社交）只会越修越乱。

**情境**：最近感觉「不对劲」，说不清是身体垮、心态飘、还是关系堵，什么都想抓一点，什么都治不到根。

**标准动作**：三问归家——① 身体：睡眠/饮食/运动有没有破功？破 → 回命功三约定（道）；② 心：是不是粘着某个结果/念头？是 → 观自在 + xd 组（佛）；③ 关系：是不是有个人/有句话堵着？是 → 出牌准则 + 课题分离（儒）。归家后只做那一家的动作，修好一处再论其余。

**触发器**：
- 当说「最近状态不行」 → 强制三问归家，写清是哪家的问题
- 当同时三个家都破 → 按道 → 佛 → 儒 顺序修（电池先于心，心先于事）
- 当用刷手机治焦虑 → 识别为拿错功夫（身的问题用逃避治），回对应家

**易错**：三家混修一次全上——命功没睡好就来「观心」，观的是低血糖的幻觉；顺序即纪律。

**关联**：[[行动规则|R9-命功是电池]]、[[出牌准则-文化属性与课题分离]]

## card rsd-5 · 平常心是道

**一句话**：修行不在深山，在搬柴运水——把某件事特殊化（这场面试决定一切 / 今天必须状态爆棚），本身就是「住」。

**情境**：大战之前给自己加戏（明天这场面试是人生转折 / 今晚必须爆发写出完美简历），越加戏越僵。

**标准动作**：降格回平常——这场面试 = 台账里一问的现场版（它考的就是练过的母题）；今晚任务 = 和周一一样的丑版本配额；「平常心做平常人」：该几点睡几点睡，该什么流程什么流程。入戏不迷戏：上场全力演，散场不带走。

**触发器**：
- 当说「这场不一样 / 这次特殊」 → 查台账：它是哪个练过的母题的现场版？找出对应卡
- 当大战前想改日常流程（不睡、加练到三点） → 禁止；特殊化流程=特殊化压力
- 当事后说「考砸了天塌了」 → 回 xd-4 记分牌口径 + 三行复盘

**易错**：把「平常心」用成降低标准——平常心是流程平常，不是目标降低；该有的丑版本、日课、复盘一个不少。

**关联**：[[行动规则|R5-丑版本配额]]、[[行动规则|R9-命功是电池]]
