# 《精准努力》· 读厚卡片

> 来源是我自己的闭环页与摘抄：目标篇六卡（jy-1~6，[[2026-09-25-精准努力目标篇]]，2026-09-25 闭卷复述七点提炼，已验证）＋策略篇六卡（jy-7~12，[[2026-10-07-精准努力策略篇]]，从本人摘抄读厚）。每张卡只回答一件事：**遇到什么情境 → 具体做什么**；情境和动作要经过真实用过、改到顺手才算内化。

## card jy-1 · 目标要少而准

**一句话**：二八原则用在目标上——大部分目标砍掉，把力气压到关键路径的少数几件上；「有用」不是做的理由，「在关键路径上」才是。

**情境**：早上坐下脑子里的清单有七八件：整理标签体系、补 PostgreSQL、改简历、看面经、内推开口……每件都有用，越想越乱。

**标准动作**：把清单按「投递流水线的关键路径」过一遍——今天真正推进转化率的最多两件（比如内推开口 + 复训保底）。其余的写一行记下，不展开（R2 有限计划会的写法）。晚上验收只对这两件，做了四件有用但不在关键路径的事 = 今天没完成。

**触发器**：
- 当清单超过 3 件 → 强制排序，问「哪件在投递→面试→offer 的主线上」
- 当想做「确实有用」的事 → 先说「做它的代价是少做哪件关键的事」（A-7 机会成本门句式）
- 当一天结束时只干了杂活 → 记进复盘：不是忙错了，是目标没砍

**易错**：把「少」理解成「不做别的」——是关键路径的事**先做且必做**，杂活排在它后面，而不是二选一。

**关联**：[[行动规则|R1-机会成本门]]、[[行动规则|R2-有限计划会]]

## card jy-2 · 目标写成可判真假的关键结果

**一句话**：愿望不可执行，「到某天可判定真假的关键结果」才可执行——前提是三件事有底：对目标足够了解、对时间有感知、对自己执行力有数。

**情境**：「这周把 MySQL 学完」——不可判定，周中永远焦虑，周末永远自责。

**标准动作**：三步改写。① 查现状：7 条主线里几条到 L1 了？（对目标了解）② 感知时间：本周真实可用专注小时数约多少，去掉复训和投递还剩几块？（对时间有概念）③ 写成关键结果：「周日 22:00 前 MySQL 主线 1–3 到『会了』（闭卷讲骨架通过）」，再拆到天：每天 1 条新主线 + 复训。能判真假，才知道今天差多少。

**触发器**：
- 当目标里出现「学完」「掌握」「提升」这类词 → 强制改成「日期 + 数字 + 可验证动作」
- 当周中焦虑进度 → 打开进度页看数字，不凭感觉判断落后
- 当定目标时心里发虚 → 缺的多半是三前提之一，先补了解/感知，再定数

**易错**：关键结果写成任务清单（「读三章」）——关键结果判的是**状态**（几条到 L1），不是动作（读了几页）；动作只是路径。

**关联**：[[questions|questions.md 闭环标准]]、[[秋招破局方案.html|秋招破局方案 §六]]

## card jy-3 · 能力圈管选赛道，不免修门槛

**一句话**：不懂的事情一定不做——那是选赛道的纪律；但门槛（手撕、八股）不因为「不在能力圈」就免修，两者别混。

**情境**：做算法题很痛苦，冒出念头「我是 AI 应用方向，是不是可以不卷算法，去卷点别的差异化的」。

**标准动作**：先把两件事分开。选赛道：AI 应用开发 / Agent 后端是我的能力圈与位置趋势的交点，不碰的只有「不懂也不准备进入」的赛道（比如纯算法岗、Infra GPU 向）；门槛：目标岗位的 JD 门槛（手撕 5 题日课、八股复训）照单全修——门槛是门票，不是机会。结论：算法日课照做，赛道不换。

**触发器**：
- 当想用「方向不同」豁免某项日课 → 查 JD：出现在门槛里的，不免修
- 当看到新赛道机会心动 → 过四档地图：在不在能力圈、在不在趋势上、有没有门槛欠账
- 当门槛练到怀疑人生 → 回看「机会 = 趋势 × 位置 × 门槛」，砍的是赛道不是门槛

**易错**：把「不懂不做」当成舒适区借口——它管的是「进入哪个市场」，不管「市场里的必经训练」。

**关联**：[[秋招破局方案.html|秋招破局方案 · 双非四档地图]]、[[行动规则|R10-never miss twice]]

## card jy-4 · 位置决定价值：让努力跟趋势叠加

**一句话**：你所在的位置决定你的价值——克服点状思维，努力要和所在位置的发展趋势叠加；并经常更新自己的画像和「工作的样子」。

**情境**：闷头学了两周，没再看过 JD 和行业动态，说不清「Agent 后端这个位置这周要什么」。

**标准动作**：每周一次 30 分钟「位置校准」：① 重读目标 JD，标出重合与缺口；② 更新能力地图的掌握度台账；③ 记 3 条本周的成就感瞬间（行为面素材，面试「你最有成就感的事」直接用）——画像不更新，努力就可能叠在一个过期的位置上。

**触发器**：
- 当连续 7 天没看过 JD → 强制做一次位置校准
- 当自我介绍还是半年前的版本 → 用本周的成就感瞬间替换掉一个旧例子
- 当努力产生「我到底在不在变强」的怀疑 → 对着位置要的东西验证，不对着感觉

**易错**：位置思维不是追热点——是「我的积累 × 位置趋势」的方向夹角尽量小；追着每个新框架跑恰恰是点状思维。

**关联**：[[AI应用开发能力地图]]、[[秋招投递台账.html|秋招投递台账]]

## card jy-5 · 记动作，不记观点

**一句话**：我自己的实测断点——行动条款的保留率远低于概念条款；读完任何东西，必须产出「明天能做的同一件事」，否则等于没读。

**情境**：读完一本书、一篇博客，划了很多线，感觉收获很大，一周后只剩一个概念名。

**标准动作**：阅读闭环强制三问：① 是什么（一句话）；② 具体怎么做（可执行动作，写不出来就回书里找）；③ 今天/本周在哪用一次（挂进台账或派单）。动作写不出来 = 没读懂，回炉；书里没有可执行动作的内容，明确标记「观点，不入卡」。

**触发器**：
- 当想说「这本书不错」→ 追问「它的哪条动作进了我的哪张卡」
- 当复述只能说出概念名 → 承认没内化，回读厚卡把动作层补上
- 当新知识进不了卡 → 检查是不是只有观点没有动作

**易错**：动作颗粒度太粗（「更主动一点」不算动作，「每天给一位大哥发内推消息」才算）。

**关联**：[[母题驱动证据闭环学习法]]、[[行动规则|R5-丑版本配额]]

## card jy-6 · 破釜沉舟，不烧第二遍船

**一句话**：选本科就业本身就是破釜沉舟——船已经开了，剩下的是每天稳定地动，不是反复烧第二遍船（反复怀疑当初的选择）。

**情境**：深夜焦虑「当初是不是应该考研」「现在转向还来不来得及」，第二天效率归零。

**标准动作**：认账两句：① 这条船已开，账已经结了；② 裁决权在 10/15 止损检查点的数据，不在情绪。然后把焦虑折算成一个当天的可控动作（投递 1 家 / 复训 1 条），做完睡觉。选择只在「检查点数据真的说不通」时才重议，其余时间一律不议。

**触发器**：
- 当「要不要考研/转行」的念头出现 → 标定「烧第二遍船」，只允许在检查点重议
- 当焦虑到睡不着 → 写下明天最早可行的一步，然后按 R9 停手去睡
- 当拿别人的读研进度对比 → R7 算自己的账：投递量、复训数、周闭环

**易错**：把「不怀疑」当成「不许思考」——检查点上用数据正式重议是纪律，平时用情绪反复重议是消耗，两者边界就是日期和数据。

**关联**：[[0713再就业男团-逆境准则|R7-算自己的账]]、[[性命双修执行案|R9-命功是电池]]、[[行动规则|R10-never miss twice]]

## card jy-7 · 定策略先找障碍，别把目标当策略

**一句话**：策略是「障碍 × 解法」的配对，不是动作的堆砌——没指认出真障碍就排出的计划，多半在已经会的东西上反复刷熟练感，越勤奋越空转。

**情境**：周计划写满「每天 20 道八股快问快答、2 道手撕、看一章面经」，执行率很高；两周下来手撕还是慢——真障碍其实是「排班主线只过了骨架、见变体就懵」，计划里根本没有它的位置。

**标准动作**：定计划前先走四步。① 写「通往目标的障碍清单」：现在到不了目标，卡在哪几件事（写成可解的题，如「Redis 数据结构选型讲不出判断依据」）；② 每个障碍至少配一个解法；③ 把解法排成系统——每一步都有它服务的障碍，按障碍大小排序；④ 再开始冲刺。执行中每个动作过一句自查：「它在解决哪个障碍？」答不上来 = 无用功，砍掉或换。

**触发器**：
- 当计划全是「每天做 X 遍 / 背 Y 个」式动作堆砌 → 停，先补障碍清单再排
- 当执行很勤却没靠近目标 → 识别成在解决假障碍，重走四步
- 当又挑会的东西练 → 停：这是在验证自己很牛，不是在进步，换到障碍对应的动作

**易错**：障碍清单不是自我批评清单——「我手撕就是慢」不可解，「变体型就懵 → 补排班母题组」可解；写不下去通常是障碍还没查到具体那一步。

**关联**：[[行动规则|R2-有限计划会]]、[[母题驱动证据闭环学习法]]

## card jy-8 · 穷尽方案：一个不行换下一个

**一句话**：「没路了」通常是解法池空了的错觉——把问题写下来、解法列满一页逐个试，单个尝试的失败小到不值得绝望，也不值得停下来难受。

**情境**：给三位学长发的内推消息都没回音，得出「内推这条路没用」的结论，停了两周没再开口。

**标准动作**：① 把问题压成一行题面（「内推消息零回复」）；② 穷尽解法，至少写 5 条（换对象：在职 1–3 年的比 senior 更爱回 / 换时机：对方工作日上午 / 换载体：先投递再补一句内推 / 换第一行：从对方项目说起 / 换渠道：脉脉、邮箱、线下）；③ 逐个试，失败一个划掉一个、写一行「它排除了什么」；④ 清单见底之前，不许下「此路不通」的结论。

**触发器**：
- 当冒出「没用了 / 不行了」 → 查解法清单：还空着就不配下结论，补满再试
- 当只试过一种方法就停 → 强制补 4 条解法再继续
- 当在原地反复想 → 想是买焦虑，试是买信息，下一个方案直接上手

**易错**：穷尽不是无脑蛮试——每次失败留一行「它排除了什么」，下一个解法才更准；这一行顺手进错题本（jy-11）。

**关联**：[[0713再就业男团-逆境准则|R7-算自己的账]]、[[行动规则|R5-丑版本配额]]

## card jy-9 · 恐惧拆账：把最坏后果按四格写出来

**一句话**：怕的不是失败，是没看清的失败——把最坏后果按物质 / 精神 / 人际 / 机会四格写具体，恐惧就从「说不清的大」降成「一格一格可以判定的账」。

**情境**：想在群里请一位大厂前辈帮忙内推，草稿打了删删了打：怕被拒绝、怕显得功利、怕别人看见——最后没发，机会过期。

**标准动作**：10 分钟四格账。① 物质：会损失什么钱或物？（开口被拒通常是 0）② 精神：会难受多久？（如实估，一般一小时）③ 人际：具体谁、会怎么看我？（写出名字，大多是想象出来的观众）④ 机会：不开这个口，确定失去的是什么？逐格判「可承受 / 不可承受」——四格全可承受 → 直接发；真有一格不可承受 → 只针对那一格改动作（改私聊、换时机），不整体放弃。

**触发器**：
- 当一件事因为怕拖着不做 → 停止脑补，开四格账，写完就动
- 当四格写完发现全是想象 → 按出牌阶梯 L0 直接认领，发出
- 当又把后果想成「身败名裂」级 → 回到四格，逐格压成一行

**易错**：四格账不是自我催眠「肯定没事」——它允许「真不可承受」的结论存在，杀的是模糊恐惧不是正当风险；每格一行，写成长文就变成新的拖延。

**关联**：[[出牌准则-文化属性与课题分离]]、[[行动规则|R6-我不负责清单]]

## card jy-10 · 归因三查：具体、短暂、可改

**一句话**：归到「性格 / 出身 / 环境」这类长期因素上的归因，再准也是提前签字放弃——有效归因必须同时过三查：具体到细节、限于此场此回、能长出下一步动作。

**情境**：模拟面试 17.7 分，当晚结论是「我表达就是不行」「双非背景就这样」——越想越丧，第二天效率归零，分一点没涨。

**标准动作**：坏结果先别下结论，过三查。① 具体：究竟哪一题、哪一句、哪个环节丢的分（能指认到题面细节，不是笼统的「差」）；② 短暂：是这次、这类场景的问题，还是「我这个人永远如此」（禁用「总是 / 就是 / 天生」）；③ 可改：从这个原因能长出什么动作（补哪条主线、改哪句话、练哪个题型）。三查过不了的归因当场作废，重归到能长出动作的那条原因上。

**触发器**：
- 当结论的主语是「我这个人 / 我的性格 / 我的学校」 → 停，长期归因，强制改写成行为句
- 当归因完没有任何下一步动作 → 无效归因，重归
- 当在反复懊悔旧账 → 转复盘：后悔无用成长最重，动作进错题本（jy-11）

**易错**：不等于自我开脱——「题太难 / 运气差」的外归因同样过不了三查（不具体也不可改）；该认的错认，认完必须落到动作。

**关联**：[[0713再就业男团-逆境准则|R7-算自己的账]]

## card jy-11 · 人生错题本：同类错误最多犯三次

**一句话**：错误有两个属性——顽固（是思维习惯不是一时疏忽）和会被忘掉（近因效应），所以「下次注意」必然无效；要像对待错题一样：记录、归因、配消灭动作，同类最多错三次。

**情境**：面试被追问「你在项目里具体负责哪一块」卡壳——上上周刚在金山话术上栽过同款跟头，当时懊悔了一下就翻篇了，错误原样等在下一场。

**标准动作**：① 当天记进错题本，四类入库：马虎和习惯出的错 / 别人说错做错的 / 自己不知道而错的 / 别人做对而我不知道的；② 原因追到细节再停（「没准备好」不算原因，「话术第 3 问的分工口径没背」算）；③ 给这个原因配一个消灭动作，记下来重复使用；④ 提炼一句话当类别标签，按对象 / 情境 / 目的归档，出场前翻对应类别；⑤ 同类第三次出现 → 升级成专项规则（写进行动规则或改流程），不再靠记忆防。

**触发器**：
- 当说错做错后只想「下次注意」 → 识别为无效动作，强制走五步
- 当不好意思记自己的错 → 不记 = 在裸奔：错误会在各个场合、各人面前重复暴露
- 当看到别人踩坑或做得漂亮 → 同样入库（第二 / 四类），不付学费白捡
- 当一件事办成了 → 也记一行「哪个动作带来的」，成功的经验同样要记录和迁移

**易错**：错题本不是忏悔录——只收「原因 + 消灭动作」，不收情绪；同一原因不重复记，只更新消灭动作。每周真复盘时走完整六步：对目标 → 客观按序回顾 → 圈错 → 析因 → 配解法 → 记录。

**关联**：[[行动规则|R10-never miss twice]]、[[questions|questions.md 问题台账]]

## card jy-12 · 杠杆：一次投入，N 次复用

**一句话**：快车道的本质不是更用力，是让一份时间卖出去不止一次——投入一得到一的是消耗，投入一得到多的是资产；自己搞不定的，列出「谁 / 什么能替我搞定」再动手。

**情境**：每次面试前都重新翻项目资料、重新组织说法，讲一次忘一次、每次口径还不太一样——同一份时间的第 N 次零收益劳动。

**标准动作**：① 动手前问一句：「这个产物第二次还用得上吗？」② 用得上 → 按资产标准做：写进作战地图 / 母题卡 / 错题本，一次写清楚，以后只改不改写；③ 用不上 → 快速做掉，丑版本过关就行，投入不超过它的价值；④ 自己搞不定的事，列「谁能替我搞定」清单再动手：内推链条、学长、现成模板、AI、工具——借力不丢人，硬扛才误事。

**触发器**：
- 当第二次手动重复同一件准备动作 → 停，先沉淀成可复用资产再继续
- 当又从零组织同一套说法 → 写进作战地图定稿口径，N 次复用
- 当硬扛一件不擅长的事 → 停半小时，列借力清单，问「谁能搞定这个」
- 当想把某件事「做得更漂亮」 → 先问它是不是资产：一次性消耗品不配打磨（机会成本门）

**易错**：资产化不等于万物皆整理——只复用一次的东西做成资产本身就是浪费；也别拿「搭系统」当不出手的借口：系统是为了让下一次出手更省，不是替代出手（别从追胡萝卜的驴变成只造胡萝卜工厂的驴）。
