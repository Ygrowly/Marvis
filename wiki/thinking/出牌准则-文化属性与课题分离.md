# 出牌准则 · 文化属性、课题分离与松弛感

> **一句话总纲**：不等环境给答案，自己按规律出牌并承担小成本；说完就结案。松弛感不是技能，是注意力外移、次数攒够后剩下的东西。
> **读厚方式**：不是摘书，是拿真实情境反向检验概念——哪些站得住，哪些只是鄙视链误读。
> **边界**：管「社交与评价敏感」；开工与决策门归 [[行动规则]]，逆境自处归 [[0713再就业男团-逆境准则]]。《天道》台词为凭记忆转述，未逐字核对原著。

## 一、问题与行为

2026-10 国庆回老家（农村，小学毕业即进城，与老家隔着一层膜），三个现场：

- **席前**：提前到却站在外面——没事干、没共同话题、称呼叫不出口。
- **席上**：长辈夹菜「为你好」；奶奶急着打包剩菜（带回吃、喂狗），且「其他大多桌都这样」——心里别扭。
- **饭后**：吃完站着没人理，怕开口后对方反应不可控，趁没人注意偷偷溜走。
- **次日冲突**：奶奶与哥哥因冰箱发霉「僵尸肉」爆发（哥哥要扔，奶奶捡回，哥哥撂话「再也不回来」），在场全程没出牌——**不敢，不是不会**；进而自察：不想说、躲安全圈、多一事不如少一事。

共同模式：**没有剧本 → 呆立；预演过载 → 溜走；有剧本 → 不敢出。**

## 二、根因（三层）

1. **两套文化操作系统**。十二岁前按乡土规则写入，之后被城市规则覆写——两套都在，哪套都不完整。席上的别扭拆开是三件事：角色缺位（体系没派节点）、信息不同频（缺话题原材料）、价值冲突（打包剩菜在两套代码里各自自洽、互不兼容，谁都没错）。
2. **生存程序未更新**。「扫描一切、预演一切」是十二岁独自进城的适应程序，保护过自己；问题只是它把「跟主家告辞」也当陌生教室处理。**不是改掉，是降级**：大决策上岗，十秒级交互不许插嘴。
3. **给社交安排了观众**。自命清高、怕人评价、想衣锦还乡，看似三件事，实为同一根轴（阿德勒：优越情结长在自卑感上）——每场社交都被当成「衣锦还乡」电影的试镜，所以预演 = 彩排，知道答案是挽留也停不下来（要的不是概率，是「保证不出错」，而保证不存在）。按《天道》标准，**衣锦还乡式强势仍是弱势文化**：把自我定价权外包给他人评价，等于「等救主」换成「等掌声」。
4. **躲闪是采购，不是无能**。「不想说 → 就没有自己的事 → 不用预演」——用躲闪购买确定性，每笔都成交；账单换货币回来：事后反刍、事态恶化没人管、「我不是敢说话的人」标签变厚。「多一事不如少一事」= 把处理权外包给运气和别人，仍是等救主。但柔软本身是资产（能同时看见两边、能翻译）——**柔软 + 出牌 = 担当；柔软 + 不出牌 = 隐身。**

## 三、读厚了什么

- **《天道》（原著《遥远的救世主》）**：文化属性 = 被浸泡的文化写好的生存程序；强势文化遵循事物规律靠自己，弱势文化依赖救主。**这个词的正确用法是取消评判，不是鄙视链**——奶奶打包剩菜与自己囤打折货是同一程序在不同算力下的输出，区别只是她真的饿过。全剧主线：杀富济贫的真意是「等救主的心态才是穷根」；叶晓明 / 刘冰 / 冯世杰同局三命；得救之道在「觉到悟到」，别人给不了。刘冰 = 观众席塌了人就塌（自我价值全押在别人眼中位置）；丁元英 = 不预演，只定自己的规则、让对方跑对方的程序、让现实回传数据；芮小丹 = 直接开口。**羡慕长辈的直言直语，羡慕的不是他们的话，是他们的「完成时」——说完就完，不回放。**
- **《被讨厌的勇气》（阿德勒）**：**课题分离——预演是提前替别人干他们的课题**（说出口是我的课题，脸色是对方的课题）；「自由就是被别人讨厌」；清高与怕评价是一根轴的两头。日常训练卡见 [[原则-被讨厌的勇气]]，此处不重复正文。
- **《0713 逆境准则》的现场印证**：粉陈楚生 = 羡慕担当与直言。拆解披哥 3 选罗杰夫部落那一下：在别人看着时出牌并说得出理由；「不愿被看轻」——同一个怕丢脸的情绪，他当燃料，我当躲藏的理由；选了就认全部后果（账单来了先签字）。他的担当有明码账单（解约官司、被雪藏、沉寂）——**直言的胆量不是天赋，是「说了很多次、而且没死」攒出的后验数据**。差距在次数，不在品质。leader = 局面卡住时第一个出牌的人——首秀在自家厨房。
- **三条通用判据**：① 越想越乱 = 假问题（原料是想象）；② 真实反应几乎总比预演便宜（「这就走啊」是挽留不是审判）；③ 别人给你的注意力比你感觉的少一个数量级。

## 四、行动指南与准则

### 台词冷备（五句，写死背熟——预演大多发生在组织语言上）

1. 称呼问法（提前问奶奶/爸妈）：「今天席上都有谁，我该叫啥？」
2. 到场：「有啥要帮忙的不？」
3. 席上：「这菜好吃。」
4. 告辞：对主家「我吃好了，先回去了，您忙」；对全桌「大家慢吃啊」。
5. 被留：「嗯，早点回去，你们慢吃。」（不编理由，说完就走）

### 出牌铁律（十条）

1. 十秒级的牌，三秒内出。不伤人、不花钱、可撤回的话，禁止预演。
2. 预演升级为书面：真需要想的事，纸上写十分钟，写完结案；脑内循环一律打断。
3. 我只管出牌，脸色归对方。
4. 说完即结案；回放来了贴标签「回放又来了」，回到手上的事。
5. 五句台词冷备背熟，热场只调库。
6. 上桌先派任务（帮个忙或问个问题）——注意力在事上，监视器自动断电。
7. 穿搭走默认制服，三十秒出门；「被高看一眼」挂作品上，不挂脸上。
8. 每天一件没有观众的小事；每周一次直言实验。
9. 溜走不审判：记一行，找机会补一句。没有失败，只有没补的账。
10. 计数台账：出牌 +1，溜走 +1，**躲闪 +1（事由六个字内）**；周日复盘五分钟，只看曲线不看感觉。

### 说完就完（三机制）

物理收工（告辞后立刻安排下一个动作，占住注意力）· 贴标签（回放不辩论）· 四格账（预想 / 现实 / 差距 / 一周后谁记得——攒十次，预测模型自己破产）。

### 每日最小闭环（三步，封顶十分钟）

上午 1 分钟认领今天最小的一张牌（写进备忘录）→ 临场 3 秒：话到喉咙被咽下去的那一下就是窗口，if-then「冒出『多一事不如少一事』→ 只做最小一步：一句话或认领一件事」，身体先动、理由后补（同 [[行动规则]] 总纲：临场只有触发和动作，没有分析）→ 事后 2 分钟收工：四格账一行 + 结案起身，回放没有资格拖堂。

### 六级出牌阶梯（每级 5–10 次再上；允许跳级，退级回炉不算失败）

- **L0 认领**：「奶奶，明天我帮你把冰箱理一理。」做事，不是调解——安全圈的最小出口。
- **L1 十秒社交卡**：叫人、「这菜好吃」、告辞。
- **L2 要活**：「有啥要帮忙的不？」
- **L3 一句翻译**：对哥哥「你是怕她吃坏肚子，她是饿怕了」；对奶奶「捡回来的我帮你放好，坏的咱挑出来」。
- **L4 直言**：席上说一个小意见，不包装。
- **L5 当众选择**：在别人看着你的时候做有风险的公开选择，并说得出理由——罗杰夫时刻。
- 进阶项：每天允许自己出一个小丑——尴尬从要躲的变成要收集的。

### 事后诸葛亮的改造（台词入库）

每句「我当时应该说 X」只允许发生一次：写进台词库即结案。它不是罪证，是免费的台词生成器——回放从自责程序降级为补给程序，台词库每一条都从真实场景长出来。

### 破「最省力的维持现状」（三机关）

成功标准 = 下一次出牌（不是性格改造）· if-then 预设写进手机（「开始预演十秒级的牌 → 数三秒直接说」）· 60 分原则（说出 60 分的话，好过预演出 100 分的沉默）。

## 五、现场应用：家庭冲突（2026-10 假期实测）

- **定性**：程序都对，事实有对错——发霉三个月的肉确实不能吃（细菌不认识节俭美德）。协调目标不是评理，是**让安全以奶奶能执行的方式落地**。
- **为什么爆发**：哥哥「替她扔」= 执行了奶奶的课题（她一辈子的判断系统被当众作废）；奶奶「捡回 + 老人家都是这样」= 拿群体规则跨进哥哥的课题。双方都在改写对方程序——不可能任务，哥哥说「再也不回来」就是改写失败后的退出。
- **我的角色**：不裁判、不传话、不当总责；做唯一能做的翻译器。牌只有三张：对哥哥一句、对奶奶一句（见 L3），加明天的三个动作——**挑不扔**（发霉的挑出来，给食物有尊严的离场，如沤肥）、**置换不禁止**（新鲜食材放最显眼处，满冰箱压过空冰箱）、**分装贴日期**（她的程序里没有「三个月」这个刻度，标签就是规律的输入）。
- **深一层**：奶奶的节俭背后是「我还有用」——没收逼她死守，给她新的阵地（新鲜食材的处理权），旧的才守得松。

## 六、边界与提醒

- 松弛感是副产品，不直接追——别每天检查「松弛了吗」，那是给监视器换新节目。
- 预演是高风险决策才配用的工具；穿衣、寒暄这类十秒级的事用它，是滥用。
- 清高是好资产，出口在作品和本事，不在饭桌和穿搭。
- 接住奶奶的夹菜 = 接住她的语言，不是接受她的价值观；理解不等于认同。
- 补救永远开放：补一句「那天吃完没跟您说一声」，在乡土系统里是加分项。
- 出牌 ≠ 什么都管：先分账，我的牌只到「我的一句话、我的一个动作」——否则从躲闪摆到多管闲事，再得出「果然还是躲着好」的错误结论。
- 别把训练做成新表演或新系统：每天三步封顶、台账两列；开始检查「今天出牌姿势标准吗」就停。
- 别让「分析自己为什么不敢」变成新的安全圈：任何一条分析不通向出牌，就是高级的逃避。
