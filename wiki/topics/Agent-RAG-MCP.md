# Agent-RAG-MCP

## 定义

> AI 应用开发中最核心的三个技术方向：Agent（智能体）、RAG（检索增强生成）、MCP（模型上下文协议）。

## Agent

### 核心原理

Agent 是能自主决策、调用工具、完成任务的 AI 系统。核心循环：感知 → 推理 → 行动 → 观察。

### 关键概念

- **框架化趋势**：从拼 Demo 到约定式框架（如 [[2026-06-18-vercel-eve-agent-framework|Vercel Eve]]）
- **Tools vs Skills**：Tools 是能力（能做什么），Skills 是知识（知道什么），分开管理更清晰
- **生产级能力**：持久化执行、沙箱执行、人工审批 — 是 Agent 上生产的必过门槛
- **Channel**：Agent 通过 adapter 同时跑在 Slack、GitHub、Teams 等多渠道
