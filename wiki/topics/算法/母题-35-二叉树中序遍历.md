# 母题 35 · 二叉树的中序遍历

> **模块**：树 · 遍历骨架
> **关联母题**：母题池-36道推导 · 其他树形母题
> **底库**：[[母题池-36道推导与手写指南]] · [[母题池-Hot100剩余22道]]（只查不练）

## 一、母题与主线

**题目**：给定一棵二叉树，返回它的中序遍历结果（左 → 根 → 右）。

**母题**：二叉树三种遍历顺序怎么写，迭代版又怎么写？

**为什么重要**：一切树题的地基。面试常追问迭代版和 Morris，用来看你对「显式栈替代递归」是否真的理解。

**一句话结论**：左—根—右递归；迭代版用显式栈模拟递归的调用顺序。

**恢复关键词**：左根右 / 递归形态 / 显式栈模拟 / BST 有序性

---

## 
中序遍历顺序：

```plain
左子树 → 当前节点 → 右子树
```

例如：

```plain
1
     \
      2
     /
    3
```

中序遍历结果：

```plain
[1, 3, 2]
```



完整代码：

```plain
def inorder_traversal(root):
    result = []

    def traverse(node):
        if not node:
            return

        traverse(node.left)
        result.append(node.val)
        traverse(node.right)

    traverse(root)
    return result
```

复杂度：

```plain
时间：O(n)，每个节点访问一次
空间：O(h)，取决于递归调用链的最大深度
```

其中：

```plain
平衡二叉树：O(log n)
退化成链表：O(n)
```

恢复脚本：

遇空返回，按照“左—根—右”递归，每个节点的值在左子树遍历完成后加入结果。
