## 一、母题与主线

**母题**：如何在 O(n²) 内枚举出所有不重复的三元组？

**为什么重要**：把 O(n³) 暴力降维的标准套路。真正的难点不是双指针，是三层去重——这里最容易写错。

**一句话结论**：排序 → 固定第一个数 → 双指针找相反数 → 三层去重。

**恢复关键词**：排序 / 固定一个 / 双指针找相反数 / 三层去重

---

给定整数数组 `nums`，找出所有满足以下条件且不重复的三元组：

nums[i]+nums[j]+nums[k]=0

```plain
输入：[-1, 0, 1, 2, -1, -4]
输出：[[-1, -1, 2], [-1, 0, 1]]
```

注意：

+  三个下标必须不同； 
+  答案中不能包含重复三元组； 
+  三元组内部顺序不重要。



```python
def threeSum(nums):
    res=[]
    nums=sorted(nums)
    for i in range(len(nums)):
        left,right=i+1,len(nums)-1
        while left<right:
            curr=nums[left]+nums[right]
            if curr==-nums[i]:
                res.append([i,left,right])
                break
            elif curr<-nums[i]:
                left+=1
            elif curr>-nums[i]:
                right-=1
    return res
        
```



去重：

+ 固定数
+ 移动指针，跳过相同数



+ 避免相同固定数再次执行相同搜索
+ 避免重复值组成相同三元组

固定数去重，防止重复搜索；左右值去重，防止重复答案







```python
def three_sum(nums):
    nums.sort()
    res=[]
    for i in range(len(nums)-2):
        if nums[i]>0:
            break
        if i>0 and nums[i]==nums[i-1]:
            continue
        left,right=i+1,len(nums)-1
        while left<right:
            total=nums[i]+nums[left]+nums[right]
            if total<0:
                left+=1
            elif total>0:
                right-=1
            else:
                res.append([nums[i],nums[left],nums[right]])
                left+=1
                right-=1
                while left<right and nums[left]==nums[left-1]:
                    left+=1
                while left<right and nums[right]==nums[right+1]:
                    right-=1
    return res
```

排序 O(nlogn)



恢复脚本：

排序 - 固定第一个数 - 双指针寻找相反数 - 和小左移，和大右移 - 命中后记录数值并双向收缩 - 三层去重
