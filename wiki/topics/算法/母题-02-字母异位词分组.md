> **模块**：哈希表 · 键设计

## 一、母题与主线

**题目**：给定一个字符串数组，把互为字母异位词的字符串归到同一组（字母种类与数量完全相同、顺序无关）。返回所有分组。

**母题**：如何把一组元素按「等价特征」归到同一组？

**为什么重要**：迁移价值极高：任何「分组 / 去重 / 归一化」问题都是这个模型。面试常从这里考哈希键的设计能力。

**一句话结论**：把每个元素映射成一个可哈希的标准化键，再用键做分组。

**恢复关键词**：等价特征 / 可哈希键 / 排序元组 或 26 位频次数组

---

你的核心方向对了：**把异位词转换成相同的分组标识，再用哈希表分组**。当前主要有三个断点：

1. 混用了“排序字符”和“字符计数”两种方案。
2. Python 的字典不能作为另一个字典的键。
3. 分组结果应该是字符串列表，不能直接对字符串做 `+=`。

### 逐项纠正
1. 判断方法：

可以将两个字符串排序，排序结果相同就是字母异位词。

2. 分组标识：

你的 `['a', 'e', 't']` 思路正确，但列表不可哈希，不能作为字典键。应转换成：

```python
key = tuple(sorted(s))
```

`"eat"`、`"tea"`、`"ate"` 都会得到：

```python
('a', 'e', 't')
```

3. 哈希表结构：

不是“存字符及出现次数”，而是：

键保存字符串的标准化特征，值保存具有该特征的所有原字符串。

```python
{
    ('a', 'e', 't'): ['eat', 'tea', 'ate']
}
```

4. 循环不变量：

你已经接近了，更准确地说：

每次开始处理新字符串前，哈希表已经按照统一分组标识，正确保存了所有已遍历字符串。

5. 排序方案代码：

```python
def group_anagrams(strs):
    groups = {}

    for s in strs:
        key = tuple(sorted(s))

        if key not in groups:
            groups[key] = []

        groups[key].append(s)

    return list(groups.values())
```

复杂度：

+ 设字符串数量为 (n)，每个字符串平均长度为 (k)。
+ 排序每个字符串需要 (O(k\log k))。
+ 总时间复杂度：(O(nk\log k))。
+ 空间复杂度：(O(nk))。



+ n：字符串数量
+ k：每个字符串的平均长度 

每个字符串排序需要 O(klogk)，共处理 n 个字符串：

+  时间复杂度：O(nklogk)
+  空间复杂度：O(nk)







不变量是它始终满足的性质：

每次开始处理新字符串前，`group` 已经按照排序后的字符元组，正确分组了所有已遍历字符串。



恢复脚本：

异位词具有相同的字符排序结果，因此用排序元组作为哈希键，用列表收集原字符串。

异位词的字符排序结果相同，用排序后的元组作为哈希键，用列表收集属于同一组的原字符串。



 列表是可变对象，因此不可哈希，不能作为字典键；  

字典键要求对象的哈希值在其生命周期中保持稳定。列表内容可以修改，如果允许作为键，修改后字典就无法可靠地定位原来的键。元组不可变，并且其中的字符也可哈希，所以可以作为键。



```python
def group_anagrams(strs):
    groups = {}

    for s in strs:
        count = [0] * 26

        for c in s:
            count[ord(c) - ord('a')] += 1

        key = tuple(count)

        if key not in groups:
            groups[key] = []

        groups[key].append(s)

    return list(groups.values())
```

为什么异位词的键相同：

异位词包含的字母种类及每个字母的出现次数完全相同，所以生成的 26 位计数元组相同。

复杂度：

+  时间：O(nk)，需要遍历每个字符串的每个字符。 
+  空间：O(nk)，主要用于保存全部输出字符串；计数数组本身是固定的 O(26)=O(1)。 

恢复脚本：

字符范围固定为 26 个小写字母 → 用 26 位频次数组表示字符串 → 转成可哈希元组作为分组键 → 一次遍历完成分组。

## 二、扩展：类似题与两层追问

**同类变体**

**两层追问**（能答完这两层才算通过）

1. 排序键和计数键怎么选？——字符集固定（26 个小写字母）用计数键更优，字符集大或含 Unicode 用排序键更稳
2. 为什么列表不能直接当字典键？——可变对象不可哈希，元组不可变所以可以
