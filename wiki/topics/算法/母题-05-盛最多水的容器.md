## 一、母题与主线

**题目**：给定一个高度数组 `height`，任选两条竖线作为容器两侧壁，容量 = 两壁间距 × 较矮那根的高度。求能装下的最大容量。

**母题**：两端向中间收缩时，凭什么保证不会漏掉最优解？

**为什么重要**：双指针贪心的经典证明题。面试几乎一定会追问「为什么移动短板是对的」——答不出证明就等于没掌握。

**一句话结论**：面积由宽度×短板决定，宽度只会变小，所以只能移动短板去赌一根更高的。

**恢复关键词**：短板决定面积 / 宽度必然缩小 / 只能移动短板

---

给定整数数组 `height`，每个元素表示一条竖线的高度。选择两条竖线，与横轴组成容器，求能够容纳水的最大面积。

```plain
输入：height = [1,8,6,2,5,4,8,3,7]
输出：49
解释：选择下标 1 和 8，面积为 min(8,7) × (8-1) = 49
```

注意：容器不能倾斜。



```python
def mostwater(height):
    res=0
    left,right=0,len(height)-1
    while left<right:
        curr=(right-left)*min(height[left],height[right])
        res=max(res,curr)
        if height[left]<height[right]:
            left+=1
        else:
            right-=1
    return res
```



两坐标间的距离就是下标差，元素个数要+1



 每轮开始时，所有已经排除的边界都不可能与剩余柱子组成超过 `res` 的容器，因此最大答案要么已经在 `res` 中，要么仍在 `[left, right]` 范围内。  



恢复脚本：

面积由”宽度 * 短板“决定，宽度必然缩小，因此只能移动短板，寻找更高的边界
