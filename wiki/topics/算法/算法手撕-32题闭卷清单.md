## 零、先说清策略（三条判断）

1. **手撕的胜负手是"肌肉记忆"，不是"见过"。** 9.9 乐元素实测的结论（练过输出 >> 有资料没练）在算法上放大十倍：面试现场没有时间回忆推导，只有"手比脑子快"。所以本清单每一题的目标是**闭卷 3 分钟写完 + 能口述不变量**，不是看懂。
2. **高频经典要"练到自动化"，笔试难题要"练到拿部分分"。** 面试手撕 90% 落在 S 层 15 题的变形上；笔试难题（加权区间调度、树上 DP、构造）靠的是模型识别 + 暴力版先拿分。两者训练方式不同，见第四、五节。
3. **不要扩题，要提频次。** 32 题已经覆盖 Hot100 的高频命中区。再加题的边际收益远低于把这 32 题各自闭卷写对 3 遍。

seen = {}

    seen[x] = i                                   # 先查后存：避免同一元素用两次

    pos[c] = right
    ans = max(ans, right - left + 1)

# S3 反转链表
prev, cur = None, head
while cur:
    cur.next, prev, cur = prev, cur, cur.next     # 三件套顺序别写错

# S4 合并两个有序链表（dummy 头）
d = cur = ListNode(0)

    if l1.val <= l2.val: cur.next, l1 = l1, l1.next
    else:                cur.next, l2 = l2, l2.next
    cur = cur.next
cur.next = l1 or l2

# S5 环形链表 II（Floyd）
slow = fast = head
while fast and fast.next:
    slow, fast = slow.next, fast.next.next
    if slow is fast:
        p = head
        while p is not slow: p, slow = p.next, slow.next
        return p                                  # 相遇后一头从 head 走，再遇即入环点

# S7 二叉树直径（后序 + 全局）
def dfs(r):
    if not r: return 0
    L, R = dfs(r.left), dfs(r.right)
    ans[0] = max(ans[0], L + R)
    return 1 + max(L, R)

# S8 最近公共祖先（后序汇合）
def lca(r, p, q):
    if not r or r is p or r is q: return r
    L, R = lca(r.left, p, q), lca(r.right, p, q)
    return r if L and R else (L or R)

# S9 有效括号
pair = {')': '(', ']': '[', '}': '{'}; st = []
for c in s:
    if c in '([{': st.append(c)
    elif not st or st.pop() != pair[c]: return False
return not st

# S11 第 K 大（小顶堆守门员）
heap = nums[:k]; heapq.heapify(heap)
for x in nums[k:]:
    if x > heap[0]: heapq.heapreplace(heap, x)
return heap[0]

# S14 合并区间
ivs.sort(key=lambda x: x[0]); res = [ivs[0]]
for s, e in ivs[1:]:
    if s <= res[-1][1]: res[-1][1] = max(res[-1][1], e)
    else: res.append([s, e])

# S15 三数之和
nums.sort(); res = []
for i in range(len(nums) - 2):
    if i and nums[i] == nums[i - 1]: continue
    l, r = i + 1, len(nums) - 1
    while l < r:
        t = nums[i] + nums[l] + nums[r]
        if t < 0:   l += 1
        elif t > 0: r -= 1
        else:
            res.append([nums[i], nums[l], nums[r]]); l += 1; r -= 1
            while l < r and nums[l] == nums[l - 1]: l += 1

### A 层代码脊柱

```python
# A1 最小覆盖子串（need 计数 + 右扩左收）
need = Counter(t); cnt = {}; have = 0; left = 0; best = None
for right, ch in enumerate(s):
    if ch in need:
        cnt[ch] = cnt.get(ch, 0) + 1
        if cnt[ch] == need[ch]: have += 1          # 只在这一档达标时 +1
    while have == len(need):                        # 全覆盖 → 尽量收缩左边界
        if best is None or right - left + 1 < len(best): best = s[left:right+1]
        lc = s[left]
        if lc in need:
            cnt[lc] -= 1
            if cnt[lc] < need[lc]: have -= 1        # 跌破档位才 -1
        left += 1

# A2 Kadane
cur = best = nums[0]
for x in nums[1:]:
    cur = max(x, cur + x); best = max(best, cur)

# A3 前缀和计数
cnt = {0: 1}; pre = ans = 0
for x in nums:
    pre += x
    ans += cnt.get(pre - k, 0)
    cnt[pre] = cnt.get(pre, 0) + 1                # 先统计再存：处理 k=0/前缀为 0

# A4 K 个一组翻转（数够 k 个再翻，接回前驱）
def reverse_k(head, k):
    def end_of(node):                      # 本组第 k 个节点，不足 k 个返回 None
        p = node
        for _ in range(k - 1):
            if not p or not p.next: return None
            p = p.next
        return p
    d = ListNode(0, head); gp = d          # gp = 本组前一个节点
    while True:
        kth = end_of(gp.next)
        if not kth: break                  # 剩余不足 k 个，保持原样
        gn = kth.next                      # 下一组起点
        prev, cur = gn, gp.next
        while cur is not gn:               # 组内翻转，尾接 gn
            cur.next, prev, cur = prev, cur, cur.next
        tail = gp.next                     # 翻转后的组尾 = 原来的组头
        gp.next = kth; gp = tail
    return d.next

# A5 验证 BST（上下界）
def ok(r, lo, hi):
    if not r: return True
    return lo < r.val < hi and ok(r.left, lo, r.val) and ok(r.right, r.val, hi)

# A7 全排列（回溯骨架）
def bt(path, used):
    if len(path) == n: res.append(path[:]); return
    for i in range(n):
        if not used[i]:
            used[i] = True; path.append(nums[i])
            bt(path, used)
            path.pop(); used[i] = False           # 恢复现场，两行都不能漏

# A8 每日温度（递减单调栈）
st = []; ans = [0] * n
for i, t in enumerate(T):
    while st and T[st[-1]] < t:
        j = st.pop(); ans[j] = i - j
    st.append(i)

# A9 跳跃游戏
far = 0
for i, x in enumerate(nums):
    if i > far: return False
    far = max(far, i + x)
return True

# A10 打家劫舍（滚动变量）
pp = p = 0
for v in nums: pp, p = p, max(p, pp + v)
return p
```

## 四、每天 35 分钟四格（S/A 层训练法）

| 2 · 新题 | 15 min | 新题 1 道：**先说四句**（识别模型 → 不变量 → 边界 → 复杂度），再写。卡住 3 分钟才准看清单的脊柱，看完关掉重写 | 3 分钟内写完 + 过题面示例 |

**排班（16 天过完 S+A，B 层穿插在第 9 天起的周末）：**

- D1–D15：每天 S 层新题 1 道（S1→S15 顺序推进）+ 复现前两天各 1 道
- D8 / D9：各加 A 层 1 道（A1–A4）
- D10–D15：每天 S 层剩余 + A 层 1 道（A5–A10）
- D16：全量抽考——随机抽 5 题闭卷写，写不出的回到 1-3-7-14-30 重排
- 周末整块（60–90 min）：B 层 2 道 + 一次限时模拟（2 题 40 分钟）

**铁律**：一天只推进 1 道新题。算法补短板的失败模式永远是"一天刷 5 道，第二天全忘"。

## 五、笔试的三条不同打法（和面试手撕分开练）

1. **时间盒**：读题 3min → 建模 5min → 编码 15min → 边界自测 5min。超时就先交"能过示例"的版本。
2. **先拿部分分**：想不出最优解时，先写暴力版（DFS/枚举/排序后贪心）拿小数据分，再在主逻辑外用 `if n <= 100: return brute(n)` 兜住。笔试按点给分，完整暴力 > 写崩的最优。
3. **看输出格式反推考点**：输出要 `%lld` → 提醒 long；要输出**方案本身** → 多半要存前驱或路径；要输出**字典序最小** → 排序 + 贪心。题面的输出格式是出题人给的白送提示（乐元素笔试 T1 的 5×10¹⁰ 就是这个信号）。

## 六、八大模型速查（识别信号 → 起手式）

| 看到 | 模型 | 起手第一句 |
|---|---|---|
| 凑一个值 / 计数 / 判重，要 O(n) | 哈希表 | 「先查后存，别把自己算进去」 |
| 有序数组两头往中间夹 | 相向双指针 | 「谁矮动谁」 |
| 连续子串/子数组 + 最长/最短/满足条件 | 滑动窗口 | 「右扩到不满足，左收到满足」 |
| 链表要改指针 | dummy 哑头 + 三指针 | 「先接住 next 再改指针」 |
| 树要"算高度/路径/是否" | 后序递归 + 返回值 | 「返回什么 = 我要向父节点汇报什么」 |
| 网格连成一片 / 最短几步 | 洪水填充 / 多源 BFS | 「沉岛标记访问，按层才算一轮」 |
| 前 K / 第 K / 每次取最优 | 堆 | 「堆顶是守门员，比它强才进门」 |
| 选不选 / 凑金额 / 两个序列比对 | DP | 「定义 dp[i] 是什么，再想最后一个决策」 |
