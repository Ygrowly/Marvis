# 母题 01 · 两数之和

> **模块**：哈希表
> **关联母题**：[[母题-02-字母异位词分组]] · [[母题-03-最长连续序列]]
> **底库**：[[母题池-36道推导与手写指南]] · [[母题池-Hot100剩余22道]]（只查不练）

## 一、母题与主线

**题目**：给定一个整数数组 `nums` 和一个整数 `target`，返回和为 target 的两个元素的下标（下标从 0 开始，同一元素不能重复使用）。要求一次遍历完成。

**母题**：在一个数组里，如何用一次遍历找出满足「两数之和 = target」的那一对下标？

**为什么重要**：哈希表「以空间换时间」的第一课，也是面试开场题。考的不是能不能写出来，是能不能主动说出循环不变量。

**一句话结论**：遍历时查补数、先查后存，保证不会拿当前元素和自己配对。

**恢复关键词**：补数 / 先查后存 / 哈希表只存旧元素

---

算法中的“不变量”是：

在循环每次开始处理 `nums[i]` 时，哈希表中只保存下标小于 `i`、也就是已经遍历过的元素及其下标。

它描述的是：**算法运行到任何一步，都必须成立的状态关系。**

****

### **为什么必须先检查，再记录？**
**更准确的回答是：**

**为了保证查找到的补数来自之前的元素，避免当前元素与自己配对。**

****

```json
def tow_sum(nums,target):
   seen={}
   for i,x in enumerate(nums):
      need=target-x
      if need in seen:
         return [seen[need],i]
      seen[x]=i
    return []
```

****

1. **循环不变量：**

**处理 **`**nums[i]**`** 之前，哈希表中只保存所有下标小于 **`**i**`** 的已遍历元素及其下标。**

2. ** 先查后存： **

**先在旧元素中寻找补数，再保存当前元素，可以保证两个下标不同，避免当前元素与自己匹配。**

****

母题 01「两数之和」通过。你的恢复脚本是：

**两数求和 → 遍历时寻找补数 → 哈希表保存旧元素 → 先查后存 → 保证不与自己配对。

## 二、扩展：类似题与两层追问

**同类变体**

- LC 167 两数之和 II（输入有序，改双指针 O(1) 空间）
- LC 15 三数之和（见 [[母题-06-三数之和]]）
- 变体：求两数之差 / 两数之和最接近 target

**两层追问**（能答完这两层才算通过）

1. 数组已经有序时，还需要哈希表吗？——不需要，双指针可以把空间降到 O(1)，说出取舍
2. 如果要返回所有不重复的数对，而不是任意一对？——排序 + 双指针 + 跳过重复值
