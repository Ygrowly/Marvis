怎么用（每天 30 分钟，不占学习时间）

  1. 先看上面的「窗口日历」——有红色日期的先投，那是硬截止，过了就没了。
  2. 点「今日抽 5 家」，系统从还没投的里面按优先级抽 5 家（黄色高亮）。
  3. 每家先找内推（10 分钟）：牛客 / 脉脉 搜「公司名 + 内推」，或找 2026 届刚入职的学长学姐——响应率最高。找不到就直投，别卡住。
  4. 按标的调整简历侧重：投 FDE / 交付 → 突出「交付、沟通、真实用户、负结果诚实」；投评测 → 突出「指标体系、口径、Bad Case」；投应用 / Agent → 突出「RAG、工具调用、评测闭环」。
  5. 投完立刻勾选并把状态改成「已投」，当天收手，不看第二遍。

投递是体力活。一次性做完就收手——不要用一整天泡在招聘网站上。

不谈判的六条

  1. 明牌写了 985/211/双一流、或写明只招硕士的岗位，直接跳过。不是认输，是算账——投递次数和精力是有限资源。
  2. 投「部门」不投「公司」。同一家公司不同事业群能差一整档；非核心部门、地方岗、内包岗的通过率明显高一档。
  3. 先投保底（C/D 层）再投冲刺。别因为「想先冲一冲大厂」把保底排到最后，秋招后期 HC 收得极快。
  4. 投递和练并行，投递不占学习时间。每天固定 30 分钟，做完收手。
  5. 挂 20 份简历之后不复盘到凌晨。那不是学习，是自罚。
  6. 掉了一天直接跳下一天，不补课、不自罚。never miss twice。

AI 评测 / 测试岗：投前先看两件事

规则一：AI 评测分两条序列，只看 JD 的「职位类别」就能分开。投错序列等于白投。

  • 测试 / 质量序列（字节的「研发 - 测试」、腾讯「测试开发」、百度「测试开发」）→ 本科可投。内容正好是「评测集 / LLM-as-a-Judge / Bad Case / 评测平台」。
  • 算法评测序列（多家挂「大模型算法评测工程师」）→ 要硕士，且考算法与模型训练部署。

规则二：「AI 测试开发」分两类，第二类不要投。

  • 应用 / 效果评测类 → 适合你。RuleArena 的双评测集 + 独立 Oracle + 发布门禁 + Bad Case 回流，是这条 JD 的逐条对应物。
  • 算力 / Infra 性能类 → 跳过。识别特征：JD 里出现 CUDA / GPU 内存层次 / Warp 调度 / Megatron / DeepSpeed / vLLM / 千卡集群。标题可能只写「测试开发」，别只看标题。

不要用社招 JD 判断校招门槛。腾讯侧搜得到的 AI 评测 JD 多写「3–5 年经验」，那是社招；校招该投的是 join.qq.com 技术类里的「测试开发」。看到年限要求直接关掉，换校招页。

投递标的

公司 / 入口部门 · 岗位方向门槛窗口状态

「门槛」是经验判断，非企业官方口径：本科可投＝有本科录取的公开记录或无学历限制；偏硕士＝公开岗位以硕博为主、本科可试但难；明牌卡＝公告里明确写了硕士或重点院校；Infra 跳过＝岗位真实要求算力／基础设施能力（CUDA / GPU / 集群），不是学历问题，投了也会在技术面挂——标出来是为了省你的投递次数。
「入口」列现在每条都能点：★ 域名 是 2026-09-20 核到的官方校招入口，直接新标签页打开；⌕ 搜索官网 是没核到固定入口的公司，点开直接搜「公司名 + 2027 校招」，顺便确认今年域名有没有变。合计线上内联的官方入口共 105 条。

数据说明

标的来源（2026-09-20 检索，均为公开信息）：各企业 2027 届校招官方公告与媒体转载（劳动报 / 中新经纬 / 京报网 / 中国劳动保障报）、银行招聘公告（中国银行软件中心、浦银金融科技、平安银行）、垂直招聘站校招条目（英特尔中国、瓴羊、万兴科技）。

数字的性质（两类，别混用）：

① 规定值——报名截止日、招聘人数、毕业时间口径、岗位名、官网入口。这类对公告核实过，可以当事实用；但企业会随时调整，投前扫一眼官网。

② 经验值——「门槛」三档、双非过筛率约 3%、各赛道竞争密度。这些来自公开讨论与往届投递反馈的概率统计，不是任何一家公司的官方口径，只用来排投递优先级，不能用来判断「这家公司一定不要我」。

用例只有两个：帮你排投递顺序、帮你决定简历往哪个方向改。它不是让你据此放弃任何一家公司的理由。
