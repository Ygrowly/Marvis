## 四、维护顺序（红线：事实只有一个入口）

```
改数字 / 口径 / 经历
      ↓
① 网申：改 刘宇广-网申-公共层.md → python make_net_versions.py → 四份成稿重新生成
② PDF ：改 刘宇广-AI应用开发-2027届.html（母版） → python make_variants.py
        → python check_layout.py --all --export
③ BOSS 三份 + 自我介绍：数字出现处手工同步（这几份没有派生脚本，改完 grep 一遍数字）
```

- **不要手改四份网申成稿和三个方向 PDF** —— 下次生成会覆盖，改了也白改。
- 所有数字的唯一定义处：`刘宇广-简历量化指标口径.md`。
- 方向语言体系（面试官第一问 / 该用的词 / 忌讳）：`投递方向与简历侧重.md` 第 6.2 节。
- 生成时会自动断言：改写的数字 ⊆ 原条数字、成稿数字 ⊆ 公共层数字、每方向核心锚点必在。
