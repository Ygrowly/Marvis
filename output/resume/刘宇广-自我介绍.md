# 刘宇广 — 面试自我介绍（口述稿）

> **这份管什么**：面试开场「介绍一下你自己」的**口语稿**——不是简历字段，也不是 BOSS 聊天里用的话术（那种见 `刘宇广-BOSS问答.md` Q5）。
> **怎么用**：选一档背到能自然说出来（**不是背字，是背结构**），开口前先说结论句。
> **原则**：① 全程不出现学校名（非 985/211 时，「2 段实习」比学校名更能立住）；② 每个主张后面跟一个数字；③ 结尾一定要落到「能实习到毕业 + 转正」，这是面试方最在的稳定性。
>
> 字数**按代码块正文去空白后真数**（脚本验过）；时长按中文口播约 4 字/秒折算，**是估算**，实际语速会有偏差。
> 电话初筛会被打断，优先用「短版」或最下面那个三句兜底版。

---

## 短版 · 实测 177 字（估算 44 秒）· HR 面 / 电话初筛

```
我叫刘宇广，南华大学数据科学专业，2027 届。有 2 段 AI 应用开发实习：目前在金山做园区能耗 Agent 平台，独立设计实现数据链路和工具治理——把 30 个 MCP 工具按风险分级，Agent 任务完成率从 83% 提到 96%，越权用例拦截 100%；上一段在初创公司核心开发企业问数平台。技术栈是 Python、FastAPI、PostgreSQL。可以全职实习到毕业转正。
```

> 结构：身份 → 主线 → 一段一个数字 → 到岗。电话里 30 秒是上限，说满会被打断。

## 标准版 · 实测 321 字（估算 80 秒）· 技术一面（最常用）

```
我叫刘宇广，2027 届，有 2 段 AI 应用开发实习，做的都是同一件事：把不确定的模型输出，做成生产里可验证、可回滚、可评测的系统。

第一段在金山，独立设计实现园区能耗 Agent 平台的数据链路与工具治理：四层数据模型加七类质量状态，可信聚合完整率 96.8% 提到 99.7%；30 个 MCP 工具按操作风险分级，越权用例拦截 100%。第二段在初创公司核心开发问数平台，150 条评测集上「可执行且口径正确」的查询占比从 78% 提到 91%。个人项目 RuleArena 做 Agent 上线前的执行门禁，实测重复退款从多退 1920 元压到 0。

技术栈 Python、FastAPI、PostgreSQL、Redis，幂等、状态机、失败恢复都做过完整实现。可以全职实习到毕业转正。
```

> 结构：一句定位（可验证·可回滚·可评测）→ 两段实习各一个数字 → 个人项目一个「对自己不利但真实」的数字 → 基本盘 → 到岗。
> **结尾那个 1920 元是故意的**：讲自己把资损压到 0，比讲「我做了很多优化」更可信，而且面试官一定会追问——追问的就是你想讲的项目。

## 展开版 · 实测 456 字（估算 114 秒）· 主管面 / 需要展开时

```
我叫刘宇广，2027 届，有 2 段 AI 应用开发实习，做的都是同一件事：把不确定的模型输出，做成生产里可验证、可回滚、可评测的系统——这条主线是数据可信、执行可控、结果可证。

第一段在金山，独立设计实现园区能耗 Agent 平台：四层数据模型加七类质量状态，可信聚合完整率 96.8% 提到 99.7%；把查询、设备、结算这些能力封装成 30 个 MCP 工具并按 R0/R1/R2 风险分级，80 条越权用例拦截 100%，固定任务集完成率 83.3% 提到 95.8%。第二段在初创公司核心开发问数平台，六阶段可归因链路让 Bad Case 能定位到是业务理解、SQL 生成还是执行出错，150 条评测集占比 78% 提到 91%。个人项目 RuleArena 是业务 Agent 上线前的执行门禁：同一份 Agent 跑两次实测，裸跑重复退款多退 1920 元，加门禁归零；而且我自己的门禁没过自己定的门槛时会如实拒绝放行——那条比任何单次成绩都重要。

技术栈 Python、FastAPI、PostgreSQL、Redis，前端能独立写 SSE 实时监控界面。可以全职实习到毕业转正。
```

> 主管面看的是「这人能不能独立负责一块」，所以 90 秒版把**判断**（为什么要分级、为什么要门禁）塞进去，数字反而降密度。

```
最近一年在金山独立做园区能耗 Agent 的数据链路与工具治理，越权拦截 100%、任务完成率 83% 提到 96%。
个人项目做 Agent 上线前的执行门禁，实测把重复退款压到 0。
```

## 纪律（三条）

1. **不出现学校名**（前面几档里「南华大学」只在 30 秒版出现，因为 HR 面会核对学校；技术面可省）。
2. **不许报没写进简历的数字**。所有数字都来自 `刘宇广-简历量化指标口径.md`，口径不一致会被当场抓。
3. **说完要停**。自我介绍不是把所有事讲完——它的唯一目的是让面试官问你最想被问的那个项目（RuleArena 或 EnergyOps），所以结尾那句要留钩子。
