八大模型速查：看到什么 → 起手第一句

看到模型起手第一句
凑一个值 / 计数 / 判重，要 O(n)哈希表先查后存，别把自己算进去
有序数组两头往中间夹相向双指针谁矮动谁
连续子串 / 子数组 + 最长最短滑动窗口右扩到不满足，左收到满足
链表要改指针dummy 哑头 + 三指针先接住 next，再改指针
树要算高度 / 路径 / 是否后序递归 + 返回值返回什么 = 我要向父节点汇报什么
网格连成一片 / 最短几步洪水填充 / 多源 BFS沉岛标记访问，按层才算一轮
前 K / 第 K / 每次取最优堆堆顶是守门员，比它强才进门
选不选 / 凑金额 / 两序列比对DP先定义 dp[i] 是什么，再想最后一个决策

笔试零分防线：输入输出（白板手撕练不到，笔试栽得最多的地方）

坑症状防线
多组数据没循环只过第一组，后面全错，自己还以为算法错了一次读光再取：data = sys.stdin.read().split()，用下标指针往前推；或者 while True: try: ... except EOFError: break
按行读，但一行几个数不定读到空串 / 下标越界别用 readline().split()，一律 read().split()，空白符统一吃掉
输出格式不对答案对了但判 0 分三看：有没有 Case #i: 前缀、组间要不要空行、末尾要不要换行——题面给的格式是白送的分
要取模 / 要 long大数溢出或答案被判错题面出现 1e9+7 就每步取模；写 C++ 一律 long long（题面要 %lld 就是明说要 long）
深递归爆栈本地过了，交上去 REPython 开头 sys.setrecursionlimit(10**6)；树的深链别用递归改用栈
保留小数位数不对用 f'{ans:.2f}'，不要用 round()（会丢末尾 0）
为什么单独列这一块：手撕练的是算法，笔试卡死的人多数不是不会写，是读错输入格式、忘了多组循环，直接零分。动作：国庆做 3 套 2 小时限时模拟（3 题、自己处理输入输出），每套结束把「读错格式」的题名记到本页最上面那张表里当错题。

笔试三条（和手撕分开练）

  1. 时间盒：读题 3min → 建模 5min → 编码 15min → 边界自测 5min。超时先交能过示例的版本。
  2. 先拿部分分：想不出最优就先写暴力版，主逻辑外用 if n <= 100: return brute(n) 兜住。完整暴力 > 写崩的最优。
  3. 看输出格式反推考点：要 %lld → 用 long；要输出方案本身 → 存前驱；要字典序最小 → 排序 + 贪心。题面输出格式是白送的提示。
