# 2026-09-30 局势判断：执行力 / 市场 / 多线布局

> 与 `秋招破局方案.html` §六（四动作）、§七（止损线）配套，**不替代正本**。本页只记这次的判断与动作，新增数字一律标来源性质。

## 一、三个判断

**判断一：执行力问题的根因不是懒，是目标设错了。**
「看背记教材」是无限游戏，没有终点 → 「心急想赶快学完」必然焦虑，因为永远学不完。
换成有终点的目标：**每天派单里闭卷能讲出来几条**。能打勾，才有完成感。
依据 = 库内 9.9 乐元素实测（25 分制）：练过输出 >> 有资料没练 >> 没练。

**判断二：市场在缩，但砍的不是他这个方向。**
被砍的是纯 CRUD 入门岗，扩的是 AI 岗。他投的 AI 应用 / Agent 后端 / AI 评测在扩的那一侧。
**真实短板是实习转正挤压统招名额**（他只有金山一段，不是转正通道），不是知识量。

**判断三：「不吊死」的正确形式不是开第二条路。**
保研/考研是同一目标的两条通道，共用一份备考；求职 vs 自媒体是两个目标，不共用 → 不是同一类备份。
他这边正确形式 = **同一目标（offer）的第二条通道：实习转正 + 春招补录**，以及已有的台账分层分散。

## 三、现在做（与求职共振）

1. **内推开口**——两位大哥，一条微信。挂在库里很久没做，边际收益最高的单一动作。
2. **投完 S 层 16 家**——每天固定 30 分钟投递块，做完收手，不占学习时间。
3. **每周发一篇公开输出**——站点（ygrowly.github.io/Marvis）已有 82 张母题卡 + 三项目口述 + 253 题答案，内容现成，只换外壳发到牛客/知乎/小红书。约 1 小时/篇，同时是：面试证据（L4 的最近似物）+ 简历可写「技术博客/开源知识库」+ HR 可搜。
4. **派单闭环**——目标从「看几页」改成「闭卷讲出几条」，学完 5 分钟内自评（防遗忘关键）。

## 四、现在不做（会稀释主线）

- **vlog / 视频**：一条 5–10 小时，反馈周期三个月，与 10 月窗口不共振。
- **建社群**：维护成本无底洞，冷启动失败反噬心气。
- **新开项目**：三个项目已够讲，边际收益低于把现有项目讲到 L3。
- **考研 / 留学再评估**：止损线已定 10/15，现在规划 = 付费买焦虑。
- joye 的路径（博客 + 自媒体 + 社群 + 个人项目 → 猎头约 coffee chat）是 **2–3 年积累的结果**，不是求职窗口期能复制的模板。**抄他的形式，不抄他的时间线。**

## 五、助学贷款 6w：算清就不焦虑

AI 应用岗总包按 25–35w 取下限（二手数据，估算），到手约 15–20k/月 → **6w 一年可清**。
结论：**这笔账的解药是一个 offer，不是一个副业。** 入职前能靠副业赚到的钱，量级远小于 offer 的有无。

## 六、明天的具体动作（按此顺序，不做完不开始下一条）

1. 给两位大哥发微信，问内推（**今天，不是明天**）。
2. 投递块 30 分钟，S 层里挑 3 家投掉。
3. 手机放另一个房间再开始学；**午休设 30 分钟闹钟，起来直接坐到学习位置**。
4. 打开 progress.html，把今天的派单闭卷过一遍，学完立刻自评。
5. 晚上花 1 小时，从站点挑一篇母题卡写成帖子发出去（第一篇就算只有 200 阅读也算）。

## 七、止损线（不动）

10/15 前面试场次 <3 = **过筛问题** → 问题在入口（内推/投递量/简历关键词），不在知识量。
≥5 场 0 offer = **转化问题** → 问题在表达与证据。
触发后按破局方案 §七 切「找实习 → 转正」通道。

## 八、国庆计划的四处校准

1. **「再背背题、夯实基础」是无限游戏**。假期七天后要有**产出物**，不是"感觉扎实了一点"：X 条母题达到 L2（闭卷能讲）、5 篇已发布的帖子、算法日课不欠。
2. **内推别等假期末尾**。理由：① 开口只要 5 分钟，推迟七天零收益；② 假期大家有空，回复率最高；③ 内推进池要排期，早一周是一周；④ **10/7–10/9 五大行窗口就卡在假期尾巴**。降难度话术：不要说"帮我内推"，说"哥，我秋招投 XX，想请教两个问题"——先请教，对方回复后提内推就很自然。
3. **假期投递不停**：网申系统照收，别错过 10/7–10/9 五大行窗口。
4. **实习要问一句「有没有转正名额」**。没有转正名额的实习等于白做——这正是判据二（实习转正挤压统招）的实际用法。

## 九、提升影响力的三条路径（按 ROI 排序，都能变现但机制不同）

**路径 1 · 内容输出（完全复用，零额外学习时间）**
不是 vlog。是图文 + 代码 + 数据。他独有的资产：**82 张母题卡口述稿 + 253 题题级答案 + 三项目口述 + 公开站点**。别人做面经碎片，**他能做一个别人几乎没人做过的东西：成体系、公开可查的 AI 应用岗完整面试知识库**。
- 频率：每周 **2 篇**（1 篇起不了量）。同一篇多平台发，不是写多篇。
- 平台优先级：牛客（校招流量最大、HR 在这）→ 知乎（长尾搜索）→ 小红书（校招生聚集）→ 掘金/公众号。

**路径 2 · 开源贡献（最硬，被业内工程师看见的最佳方式）**
给 Agent 框架（LangChain / LangGraph / Dify / LlamaIndex 等）提 issue + PR。**被 merge 一次 = 业内可见、可被搜到、写在简历上没人能否认的证据**，而且训练的就是面试要考的读源码能力。
- 缺点：merge 周期长。**国庆投产物之一 = 提交人生第一个 PR（哪怕只修文档/补测试）。**

**路径 3 · 黑客松 / 比赛（唯一同时给曝光 + 奖金 + 简历一行的）**
查到的真实赛事（媒体二手转述，报名前自己核实）：「莱森地平线」多智能体 AI 黑客松 2026/10/16–17 **长春线下**，万元级一等奖；OpenBuild「Eazo」全球青年 Agent 黑客松（8 月已结束）；西安「开元造物」（9/25–27 已结束）。
- 规律：**这类活动每月都有，但多为线下**，他看标杆；优先找线上赛。
- **判断：不主动找新的，只在「恰好贴合 RuleArena 主题」（规则/评测/Agent 评测类）时才参加**——能用现有项目改编参赛，成本才低。

## 十、外快：只有一类是"同一件事"

**在拿到 offer 前，任何不能给简历加分的赚钱动作都是亏的。** 他的时间单价现在是 offer 概率，不是每小时多少钱。6w 贷款靠副业每月几千是还不清的，靠 offer 一年清。

**唯一共振项：AI 评测 / 训练类远程兼职。**
- 主线之一就是 AI 评测与测试 → **评测/红队/RLHF 兼职 = 既是钱又是简历一行可验证经历**。
- 平台（英文评测站/Affiliate 站转述，差异大）：Outlier（Scale AI 旗下）、DataAnnotation、Alignerr（Labelbox）、Mercor、Surge AI、Appen/CrowdGen、TELUS Digital AI、Mindrift、Prolific。
- 报价（**二手转述、非保证收入、任务不稳定**）：coding / STEM 评测类大致 $20–50+/小时，入门标注 $5–15/小时。实际时薪会被 unpaid 资格测试 + 抢任务时间摊薄。
- **必须自己核实三条（我无法替他确认）**：① 多数平台偏英语母语，**中国身份/IP 能否准入、PayPal/Deel/Wise 结算与税务怎么办**；② 要过资格测试，申请到有活可能几天到几周；③ 有活才有钱，不是月薪。
- **投入上限：每天 ≤1 小时，且排在投递 + 派单之后。**

**明确排除**：通用外包私活（单价低、扯皮多、简历不加分）；付费专栏/知识星球/小册（现在做 = 提前透支，没人来会伤士气）。

## 十一、"不等机遇"的具体机制（挂在已有派单上，不新建系统）

- 每条**升到 L3 的母题 → 自动成为一篇候选帖子**（内容本来就写好了）。
- 每周六挑 2 篇改写成帖子发出去。**多出来的成本只有"改写"这一个小时，不是重新学习。**
- 每月看一次阅读/收藏，挑 top 1 深写。

这个机制顺带解决了"看教材没成就感"——发出去就有反馈。
外加一条保守社交量：**每周主动联系 1 个业内的人**（牛客/脉脉/开源社区/目标公司在职校友），目的不是求职位，是问"你们做 XX 用什么方案"。带来的是信息，偶尔是内推。
