## 三、项目经历

### 项目 1：RuleArena · 电商规则对抗验证与发布门禁平台（2026/06 - 至今，个人项目）

**【项目描述】**

```
面向电商促销、退款、积分与会员权益的规则变更风险：把自然语言规则编译为经人
工确认的可执行契约（RuleSpec），由受控 Agent 搜索高风险动作序列，经干净环
境真实 HTTP API 重放与确定性 Oracle 裁决，沉淀可回归的最小反例。核心设计
哲学：Agent 负责「找到人没想到的路径」，确定性程序负责「证明路径真的有问题」。
```

**【项目业绩】**

```
1. 「候选风险 ≠ 确认漏洞」防自证架构：Agent 提议只算候选，经 Reference
   Simulator 探索→独立 Commerce Sandbox 真实重放→Oracle 依据资金守恒与幂
   等不变量裁决方可确认，Agent 全程无法触达 Ground Truth；
2. 建立自然语言→RuleSpec 编译链路（确定性校验+歧义清单+人工确认），仅允许
   固定领域原语、禁止动态表达式求值；
3. 24 Case 双评测集（development 16 + hidden 8 隔离）与发布门禁：正常场景
   误报 0、同版本独立重放 3/3、Ground Truth 泄漏 0；Random/BFS 基线归一化
   预算消融；
4. 确认违规经 Delta Debugging 压缩为最小反例并绑定证据链，反例一键导出
   pytest 回归；FSM 编排支持 Checkpoint 恢复与 ACTION_UNKNOWN 超时语义。
```
