## 
中序遍历顺序：

```plain
左子树 → 当前节点 → 右子树
```

例如：

```plain
1
     \
      2
     /
    3
```

中序遍历结果：

```plain
[1, 3, 2]
```



完整代码：

```plain
def inorder_traversal(root):
    result = []

    def traverse(node):
        if not node:
            return

        traverse(node.left)
        result.append(node.val)
        traverse(node.right)

    traverse(root)
    return result
```

复杂度：

```plain
时间：O(n)，每个节点访问一次
空间：O(h)，取决于递归调用链的最大深度
```

其中：

```plain
平衡二叉树：O(log n)
退化成链表：O(n)
```

恢复脚本：

遇空返回，按照“左—根—右”递归，每个节点的值在左子树遍历完成后加入结果。
