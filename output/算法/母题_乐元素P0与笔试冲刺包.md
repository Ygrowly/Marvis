## A1 · 岛屿数量（LC 200）/ 最大岛屿（LC 695）

**题目**：给一个 m×n 的二维网格，'1' 是陆地、'0' 是水，陆地水平/垂直相邻连成岛屿。200 求岛屿**数量**；695 求最大岛屿的**面积**（格子数）。

**游戏映射**：连通块检测 = 消除波及范围 / 好友关系圈。消消乐手写消除检测的近亲。

### 识别题型
网格 + 「连成一片」→ **连通块 = 洪水填充**。信号词：相邻、连通、区域数量/大小。BFS 和 DFS 都行，网格大时说一句「用 BFS 防递归栈溢出」是加分项。

### 循环不变量（主动说）
> 「已访问的陆地一定被标记成 0；每个陆地格子恰好入队/入栈一次——所以每个格子最多被处理 4 次，总时间 O(mn)。」

### 编码（Python，DFS 沉岛版）
```python
def numIslands(grid):
    m, n = len(grid), len(grid[0])
    def sink(i, j):
        if i < 0 or i >= m or j < 0 or j >= n or grid[i][j] != '1':
            return 0
        grid[i][j] = '0'                      # 沉岛 = 标记访问
        return 1 + sink(i+1,j) + sink(i-1,j) + sink(i,j+1) + sink(i,j-1)
    return sum(sink(i, j) for i in range(m) for j in range(n))
# 695 最大面积：同框架，sink 返回面积，外面取 max
```

### 边界条件（主动过）
- 空网格 / 全水 → 0；全陆地 → 1（或 mn）；1×1。
- 递归深度：极端大网格全陆地会爆栈 → 改 BFS（队列）。
- 面积版别忘了在沉岛时累加，不是数连通块个数。

### 恢复脚本
「看到连通块就**沉岛**：越界返回、是水返回、是陆地就标记 + 四个方向扩散。」写不出循环时先把 sink 的三行守卫写出来，框架自然出来。

## A2 · 前 K 个高频元素（LC 347）/ 数组第 K 大（LC 215）

**题目**：215：给无序数组，返回**第 k 大**的元素（如 nums=[3,2,1,5,6,4], k=2 → 5）。347：给整数数组，返回**出现频率前 k 高**的元素（如 [1,1,1,2,2,3], k=2 → [1,2]）。两者都要求优于 O(n log n) 全排序。

**游戏映射**：**排行榜 TopK**——一面二面都可能拿排行榜场景引到这题。

### 识别题型
「前 K 个 / 第 K 大 / 最高频」→ **堆**（或 347 用桶排序 O(n)）。说出选型理由：只维护最好的 k 个，不必全排序。

### 循环不变量（主动说）
> 「小顶堆的大小始终 ≤ k，堆里永远是"当前最大的 k 个"，堆顶是这 k 个里最小的——新元素来先和堆顶比，比堆顶小直接丢弃，比堆顶大就弹出堆顶再压入。」

### 编码（Python）
```python
# 215 第 K 大：小顶堆维护最大的 k 个
import heapq
def findKthLargest(nums, k):
    heap = nums[:k]
    heapq.heapify(heap)
    for x in nums[k:]:
        if x > heap[0]:
            heapq.heapreplace(heap, x)
    return heap[0]

# 347 前 K 高频：计数 + 小顶堆（按频次）
from collections import Counter
def topKFrequent(nums, k):
    cnt = Counter(nums)
    heap = []
    for num, c in cnt.items():
        heapq.heappush(heap, (c, num))
        if len(heap) > k:
            heapq.heappop(heap)
    return [num for c, num in heap]
```

### 边界条件（主动过）
- k = n（全保留）/ k = 1（堆顶即答案）；全相同元素；负数（比较不受影响，口述确认一句）。
- 347 追问 O(n) 优化：频次做桶下标（频次上限是 n），从高往低收 k 个——说得出思路即可。

### 恢复脚本
「TopK 想**堆**：维护"目前最好的 k 个"，堆顶是守门员，新来的比守门员强才进门。」215 一行判据 `x > heap[0]`，347 先 Counter 再堆。

## A3 · 有效的括号（LC 20）

**题目**：给一个只含 `()[]{}` 的字符串，判断是否合法：每个左括号必须被**同类型的右括号**按正确顺序闭合，且嵌套正确。如 `"()[]{}"` → true，`"([)]"` → false，`"(]"` → false。

### 识别题型
括号/嵌套配对 + 「最近的未匹配」→ **栈**。

### 循环不变量（主动说）
> 「栈里始终是尚未匹配的左括号，从栈底到栈顶构成一个合法的嵌套前缀；扫完串后栈必须为空。」

### 编码（Python）
```python
def isValid(s):
    pair = {')': '(', ']': '[', '}': '{'}
    stack = []
    for c in s:
        if c in '([{':
            stack.append(c)
        elif not stack or stack.pop() != pair[c]:
            return False
    return not stack
```

### 边界条件（主动过）
- 空串 → 合法；奇数长度 → 直接 False（口述小优化）。
- 右括号开头（栈空弹出报错）✓ 已由 `not stack` 兜住；只剩左括号（栈非空）✓ 由 `return not stack` 兜住。

### 恢复脚本
「左括号进栈，右括号找栈顶配对；配不上或栈空都算错，**最后栈空才合法**。」

## A4 · 搜索旋转排序数组（LC 33）

**题目**：一个原本升序、**元素互不相同**的数组在某处被旋转了，如 `[4,5,6,7,0,1,2]`。给 target，返回其下标，不存在返回 -1。要求 **O(log n)**。

### 识别题型
有序 + 旋转 + 要求 O(log n) → **二分变形**。核心动作不是直接找 target，是**先判断哪一半有序**。

### 循环不变量（主动说）
> 「每次循环保证：若 target 存在，必在 [lo, hi] 内。mid 劈开后两半必有一半有序——target 要么在有序半的范围内（去有序半），要么在另一半。每次排除一半。」

### 编码（Python）
```python
def search(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if nums[mid] == target:
            return mid
        if nums[lo] <= nums[mid]:            # 左半有序（<= 是关键，处理区间只剩 1-2 个）
            if nums[lo] <= target < nums[mid]:
                hi = mid - 1
            else:
                lo = mid + 1
        else:                                 # 右半有序
            if nums[mid] < target <= nums[hi]:
                lo = mid + 1
            else:
                hi = mid - 1
    return -1
```

### 边界条件（主动过）
- 区间缩到 1–2 个元素：`nums[lo] <= nums[mid]` 用 `<=` 才不会把单元素区间判错。
- target 正好是旋转点 / 数组根本没旋转（左半恒有序，退化为普通二分）。
- 边界取等：`target < nums[mid]` 不带等号（mid 已判过）。

### 恢复脚本
「先问**哪半有序**（两端点比较），再问 **target 在不在有序半的范围里**——在就去有序半，不在去另一半。」记住两处取等：判有序用 `<=`，判范围两头都闭。

## B1 · 笔试 T1：广告排期（带权区间调度 + 最多 K 个 + 双目标）

**题目**：n 条广告，每条有投放区间 [start, end]（**闭区间**，前一条 end == 后一条 start 也算冲突）和收益 revenue。选**最多 K 条**互不冲突的广告，使收益总和最大；若多个方案收益并列，选**广告条数最少**的。输出：最大收益总和 + 对应广告数。规模 n=2×10⁴、K≤50、收益总和最大 5×10¹⁰。

### 识别题型
区间 + 选子集 + 收益最大 → **加权区间调度 DP**；「最多选 K 个」→ DP 加一维 j；「收益并列时广告数最少」→ DP 值存 **pair，字典序比较**，一次 DP 同时优化两个目标（不用二分答案）。

### 循环不变量（主动说）
> 「dp[i][j] = 按**结束时间排序**后的前 i 个广告、最多选 j 个的最优 (收益, 条数)。排序保证：与广告 i 兼容的广告恰好构成一个前缀——所以兼容位置可以用二分求。转移只有两个选择：不选 i（dp[i-1][j]），或选 i（dp[p(i)][j-1] + (r_i, 1)）。」

### 编码（Python，完整版在笔试复盘 §5）
```python
from bisect import bisect_left
def solve(n, k, ads):                    # ads=(adId, advId, s, e, rev)
    items = sorted(ads, key=lambda x: x[3])
    ends = [it[3] for it in items]
    dp = [[(0, 0)] * (k + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        s, r = items[i-1][2], items[i-1][4]
        p = bisect_left(ends, s)         # 结束时间严格 < s 的前缀长度
        for j in range(1, k + 1):
            skip = dp[i-1][j]
            pv = dp[p][j-1]
            take = (pv[0] + r, pv[1] + 1)
            dp[i][j] = take if take[0] > skip[0] or (take[0] == skip[0] and take[1] < skip[1]) else skip
    return dp[n][k]
```

### 边界条件（主动过，全是这题的得分点）
- **闭区间冲突**：end == start 也算冲突 → 必须 `bisect_left`（严格小于），不能 `bisect_right`。
- K = 0 → (0,0)；K ≥ n → 退化成不带 j 的经典版。
- 收益总和最大 5×10¹⁰ → **超 int32，Python 无所谓，Java 必须 long**（题目输出格式给 %lld 就是提示，主动说出来）。
- p(i) = 0（没有兼容前缀）→ dp[0][j-1] = (0,0) 自然兜住。

### 恢复脚本
「**排序 → 二分找兼容前缀 → 两个决策**：跳过 dp[i-1][j]，选走 dp[p][j-1] + (r,1)。pair 比较：收益大优先，同收益条数少优先。」忘了二分就先写 O(n) 回扫找 p，正确后再提优化。

## B2 · 笔试 T2：完全二叉树补全

**题目**：给一棵**任意**二叉树，只允许新增权值为 1 的节点（保留原节点和原结构），把它补全为**完全二叉树**，并按层序输出（尾部 # 截断）。示例：输入 `{1,#,1,1}`（根、根右、根右左）→ 输出 `{1,1,1,1,1,1}` 共 6 节点：第 2 层补满根左，第 3 层"集中在最左"补到最深真实节点为止。树高 ≤20。

### 识别题型
二叉树 + 「补成完全二叉树」→ **完全二叉树编号系统**：根 = 1，孩子 = 2p / 2p+1。考点不是树遍历，是**编号与按编号重建**。

### 循环不变量（主动说）
> 「编号为 ci 的节点，孩子编号恰为 2ci 和 2ci+1；补全后所有真实节点保留原结构，第 h 层（最深层）的真实节点编号恰好是 1..k 连续——所以 k 就是补全的截止线。」

### 编码（Python，完整版在笔试复盘 §6）
```python
def complete_tree(root):
    info, h = {}, 0
    def dfs(node, ci, d):                # 1) 标编号 + 记树高
        nonlocal h
        if not node: return
        info[ci] = node
        h = max(h, d + 1)
        dfs(node.left, 2*ci, d+1); dfs(node.right, 2*ci+1, d+1)
    dfs(root, 1, 0)
    k = max(ci for ci in info if ci >= 2**(h-1))   # 2) 最深层最大真实编号
    for ci in range(1, 2**h):            # 3) 按编号序补缺（最深层只补到 k）
        if ci >= 2**(h-1) and ci > k: break
        parent = info[ci // 2]
        child = info.get(ci)
        if child is None:
            child = TreeNode(1); info[ci] = child
        if ci % 2 == 0: parent.left = child
        else:           parent.right = child
    return root
```

### 边界条件（主动过）
- 树高 1（只有根）→ 直接返回。
- **斜树是最大的坑**：只往右长的链（如示例 {1,#,1,1}），第 2 层缺左孩子必须补满，最深层补到 k 为止——当时笔试就是这里输出成了原样返回。
- 层间空洞：编号循环天然处理（父节点必已在 info 里，因为编号序保证父先于子）。

### 恢复脚本
「**DFS 标编号 → 找最深层最大编号 k → 按编号 1..(2^h) 逐槽补**：不到最深层必须全补，最深层只补到 k。」三句话就是整个算法。

## B3 · 笔试 T3：最长特殊子序列（LC 522）

**题目**：给字符串数组 strs，找其中"特殊子序列"的**最长长度**。特殊子序列 = 它是**某串的子序列**，但**不是数组中任何其他串的子序列**。不存在输出 -1。示例：`["aba","bbb","eae"]` → 3（"aba" 整串即特殊）；`["abc","abc"]` → -1。

### 识别题型
「子序列 + 不是别人的子序列」→ 千万别枚举子序列（指数空间）。**逆向洞察**：候选只有 n 个整串。

### 不变量（这题的灵魂，必须脱口而出）
> 「若串 s 的某个子序列是特殊的，那 **s 整串本身必然特殊**——整串是它的超序列，连超序列都不是任何人的子序列，子序列更不是。所以答案只需在 n 个整串里找。」

### 编码（Python，完整版在笔试复盘 §7）
```python
def is_subseq(s, t):                     # 双指针贪心：s 是否为 t 的子序列
    it = iter(t)
    return all(c in it for c in s)

def find_lus_length(strs):
    ans = -1
    for i, s in enumerate(strs):
        if not any(j != i and is_subseq(s, t) for j, t in enumerate(strs)):
            ans = max(ans, len(s))
    return ans
```

### 边界条件（主动过）
- 全部相同 → 互为子序列 → -1；一个是另一个的超串 → 超串是候选。
- 重复串天然处理：相同串互为子序列，都被排除。
- 无候选 → -1（按题面）。

### 恢复脚本
「别枚举子序列——**答案只需整串**。」然后 is_subseq 用双指针贪心：t 的字符按序喂给 s 的指针，指针走完 s 即存在。
