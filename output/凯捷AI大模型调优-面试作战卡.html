01先认清：这不是一个 AI 岗（最要紧的一节）

这张 JD 的岗位职责四条里，三条是数据仓库 / BI 的那一套，AI 只占一条 12 个字的短语。 我把凯捷官方 2027 校招岗位表拉出来比对过——它的职责原文是「数据开发工程师（大连）」岗的逐字复制， 而真正的「AI 开发工程师」「AIGC 开发工程师」写的是别的内容。
JD 里的那条职责 实际要做的事 你库里有没有垫着
大模型的调优、微调、模型评估、安全 模型侧的实验、评测、防护 —— 唯一与 AI 有关的一条 部分有：评测观测与治理 E1–E7（含 AgentOps 平台）、LLM 与上下文模块；但「微调」没有实操
协助大数据平台、ETL 程序搭建 Hadoop / Spark / Hive / Storm / Kafka / Control-M —— 离线数仓的日常 空档：库里只有零散提及，没有一张母题卡
商业智能报表研发、维护优化 用 PowerBI / Tableau / SmartBI 拉报表、做看板 空档：一个字都没有
后台数据库需求开发 Oracle / DB2 / MySQL / SQL 优化 强：PostgreSQL 19 张 + MySQL 17 张母题，SQL 优化是你的主战场
这件事怎么用：不要在心里把它当「AI 岗」准备——那样你会把精力花在微调原理上，而对方要的其实是 SQL 与 ETL。 反过来也别因为「AI 只占一条」就轻视：你要展示的恰好是第 ③ 条「扎实语言基础 + SQL + 主流数据库 + 常用优化方法」，这是你的强项，而且 JD 明写「3、4、5 满足其中一项即可」。

凯捷这家公司的真实画像【判断，依据二手转述】

  • 性质：法资 IT 咨询公司（Capgemini，1967 年巴黎，全球 40 万+ 人）。中国业务以项目制交付 / 驻场为主，客户多为跨国企业与大型国企。
  • 岗位模式：官方流程为「简历投递 → HR 初面 → 业务复面 → 实习 → 转正」，实习期 120–160 元/日、要求全职连续实习至毕业。「AI 工程师约 7k-9k/月」这一档在公开薪酬信息里被明确提到过。
  • 要注意的点：部分岗位涉及驻场外包，实际做什么高度取决于被派到哪个项目、哪家甲方 —— 这也是为什么「岗位名」和「实际工作」会错位。另有凯捷社招 JD 明写「外派半导体大厂，介意的请忽略」。
  • 对你的意义：平台背书 + 体系化培养（凯捷大学）是真的；但**它不适合承载你「AI 应用 / Agent 工程」的职业主线**。当保底是合适的，当主攻会跑偏。

三个信号都指向 HR 面而不是技术面：① 对接人是「沈女士」（HR 称谓）；② 岗位挂着「毕业时间 2027 年」的校招属性；③ 官方流程第二步就是 HR 初面。HR 面的考点不是技术深度，而是下面五个。

03HR 四问 · 按这个说（可直接照念）

Q1「你现在什么状态？什么时候能到岗？」

大三升大四，现在在金山做 AI 开发实习，近期结束。之后学校基本没课，可以全职实习到毕业，毕业直接转正入职。如果贵司项目着急，结束时间我可以协调提前。

要点落点永远放在「能全职实习到毕业 + 可转正」。不要把话题引到「还在实习所以来不了」。

Q2「实习期你能多久？能转正吗？」

可以连续实习到毕业，答辩期间可能会请几天短假。我是按毕业后直接入职来规划的，也希望能通过转正考核留下来。

要点凯捷官方写明「全职连续实习至毕业，如涉及答辩可请短假」——你的回答正好踩在他们的要求上，这一问是你的加分题，答得越干脆越好。

Q3「你期望薪资多少？」唯一需要动脑的一问

作为应届生我更看重方向匹配和成长空间，薪资按贵司校招标准来就好——方便的话能不能告诉我这个岗位的范围？

如果对方坚持要你说，就报这个数：

我了解到贵司这一档大概在 7-9K·13 薪，我可以接受在这个范围里，按岗位标准定就行。
为什么敢直接说这个数：这个范围是你自己贴给我的 JD 原文（明码标在标题上），不是猜的——说 JD 上已有的数字没有任何风险，比支支吾吾或报一个虚高的数都安全。 注意不要说「7K 也行」——那等于自己往下压。说「在 7-9K 范围内，按标准定」，把定价权交回去，同时表明你不低于 7K。

Q4「你为什么投我们公司 / 为什么这个岗位？」有坑，见下

这是唯一可能露怯的一问——因为对方知道这岗主要是数据开发，你要是硬吹「我想做 AI 大模型」，一句就能被戳穿。

我投这个岗主要看两件事。
一是我的能力结构和它的要求是重合的：JD 里第 ③ 条要求扎实的语言基础、SQL、主流数据库和优化方法——我两段实习里一直在做数据侧的事情：金山那个项目我做了四层数据模型和口径治理，把 5.8 万条/日的设备读数做到完整率 99.7%、查询 P95 从 20.4 秒降到 2.8 秒；另一个问数平台项目里我把百万行的分析查询从 12.6 秒压到 2.7 秒。这些都是大数据的底子。
二是能力可以往上接：这个岗位还有模型评估和安全的部分，我上一段实习正好在做评测与治理——评测集设计、防污染、发布门禁这一套，跟「模型评估」是同一件事。

这么答的好处你说的每一条都是真的、可追问；而且主动把「数据侧」摆到前面，对方会觉得你读懂了岗，而不是海投瞎撞。

绝对不能说的两种话：
① 「我很想做大模型微调 / 我主要想做 AI。」——你这方面没有实操，而且岗位也不主要做这个，说了就是自己挖坑。
② 「大数据和报表我没做过，但可以学。」——不要自己先认怂。JD 明写「满足其一即可」，你满足的是 ③ 和（部分）AI 那一条，把自己说成不合格是白送。

04被问到大数据 / BI：如实认 + 立刻转

如果对方往 Hadoop / Spark / PowerBI 上追（HR 面概率低，业务面概率高），用这个固定动作：承认没做过 → 给出你已经有的等价能力 → 说清怎么补。三段话，不辩解。

对方问的 你这么说
用过 Hadoop / Spark 吗？ 「没有直接用过。我做的数据侧工作主要落在数据库层和查询层——建模、口径治理、索引与预聚合优化。分布式计算这部分我是有基本概念的，但没有生产实操，这块我需要补。」
（一句话认干净，然后把话题拉回你强的「数据库 + 优化」。不要背 Spark 八股充数——HR 听不出，业务面一听就知道你没跑过集群。）
会做 BI 报表吗？PowerBI / Tableau？ 「这些工具我没有用过。不过报表的底层是 SQL 和多维口径，这部分是我做得比较多的：我在金山做的四层数据模型（原始 → 区间 → 小时 → 日）本质上就是给报表准备的数据层，我当时还处理了跨页面、API、导出、账单四处的口径一致性，把一致率从 86.7% 做到 100%。工具上手我很快，报表逻辑我是熟的。」
（这是本卡最值钱的一段转移——把「没用过工具」翻译成「工具的活我干过、只是没用它这个壳」。是真的，不是话术。）
英语怎么样？ 「四级已过。读写没问题，我看技术文档和写文档都是用英文原始资料，平时读的官方文档基本都是英文的。听说还需要练，日常技术交流可以应付，正式会议我还要适应一下。」
（如实分层——法资公司更反感吹牛。若四级还没过，就说实际情况 + 正在备考。）

05开场 60 秒自我介绍（背下来）

面试官好，我是刘宇广，南华大学数据科学与大数据技术专业，2027 届。

我有两段实习。最近这段在金山做 AI 开发，负责一个园区能耗 Agent 后端：我做了四层数据模型和一套口径治理机制，把每天 5.8 万条设备读数的聚合完整率从 96.8% 提到 99.7%，常用查询 P95 从 20.4 秒降到 2.8 秒，同时用 30 个工具封装把 Agent 的任务完成率从 83.3% 提到 95.8%。

更早一段在一家 AI 公司做应用开发，做的是自然语言问数平台，我把百万行的分析查询从 12.6 秒优化到 2.7 秒，模型输入 token 从 18.4K 降到 3.6K。

我的技术栈是 Python 为主，PostgreSQL 和 SQL 优化是我的强项，也在做 Agent 工具编排和发布门禁这一套。这次投这个岗位，是因为它的数据库和 SQL 优化要求跟我的能力很对口，模型评估这块我也有实习积累，希望能在这个方向继续做下去。

两个刻意的设计① 数字全部取自简历母版口径，不新造；② 结尾落点放在「数据库 + SQL 优化对口」而不是「我想做大模型」——与第 01 节的岗位真相一致。

06反问环节：问这 3 个（会显得你懂行）

反问是保底岗最容易加分的位置——问对问题=你已经知道这岗实际要做什么。按优先级挑 2–3 个问：

  1. 「这个岗位具体会进哪一类的项目？是偏数据仓库 / 报表交付，还是也有模型侧的工作？」
    推荐首问直接问出真实工作内容。这是你唯一能在入职前打听到真相的机会，而且对方会觉得你务实。
  2. 「团队现在主要用什么技术栈？数据库是 Oracle 还是 MySQL 这一类，报表工具是自研还是用 PowerBI / Tableau？」
    问细节用 JD 里的原词问，等于告诉对方「我把要求读进去了」。
  3. 「实习期是有明确的项目跟着做，还是先培训？转正考核主要看什么？」
    问成长法资咨询公司有培训体系（凯捷大学），这一问会得到正反馈。
不要问的：「能不能只做 AI 部分」「加班多不多」「能不能远程」——前两个在保底岗上是减分项，第三个太早。加班这类问题留到有 offer 之后再谈。

07今晚 40 分钟怎么用

  • 10 分钟｜念一遍：第 05 节自我介绍，出声念 3 遍，掐表控制在 60 秒左右。最高优先级
  • 10 分钟｜念一遍：第 03 节 Q1–Q4，每问出声答一次。不要默读——HR 面输在结巴不输在内容。
  • 8 分钟｜记住一个数：你被问「期望薪资」时说的那句「7-9K 范围内，按标准定」。反复说到脱口而出，这一问最容易当场卡住。
  • 6 分钟｜准备两个反问：从第 06 节挑 2 个，念顺。
  • 6 分钟｜设备与材料：见下方清单。
  • 剩下的时间｜不要学新东西。尤其别去看 Hadoop / Spark 教程——明天用不上，而且会挤掉你练口条的时间。

设备与材料清单（视频 / 电话）

  • 手机 / 电脑充满电并插上电源；提前 15 分钟测试麦克风与摄像头。
  • 找出一个安静、背景干净的位置；告诉室友/家人 15:00–15:40 不要打扰。
  • 桌面只放三样：本卡（或第 03、05 节的一页纸）、简历 PDF、一支笔。不要放第二块屏幕开着别的资料——分神比不知道更致命。
  • 周边：一杯温水。紧张时嘴唇会干，说话会僵。
  • 提前 3 分钟进会议室 / 守在电话旁，不要踩点。
  • 如果是电话：站起来说、或者坐直——姿态直接影响声音的稳定感。
一条纪律：这是面试（官方条款允许的普通面试），赛前准备我全给你；但正式开始后不要一边聊一边查资料、不要让我在旁边递词——HR 会听出停顿和念稿感，而且这场是你的真实采样，被覆盖了就白打了。
