题目

给定一个整型数组，把所有 0 移到数组末尾，同时保持非零元素的相对顺序。要求原地操作，不得复制新数组。

三 · 面试输出 闭卷口述 60 秒，再看结论

如何原地把满足某条件的元素归位，同时保持其余元素的相对顺序？

翻面对照自测，评分会进训练台的复训调度。

为什么重要：快慢指针的最简形态，一切「原地改造数组」问题的母题。写起来简单，但讲清不变量才是得分点。

一句话结论 全卡唯一要背的锚点

快指针找非零元素，慢指针指向下一个写入位置，找到就交换并推进慢指针。
  • 快指针找目标
  • 慢指针指写入位
  • 交换而非覆盖

卡住时靠这几个词重建整条链。

1. 为什么用交换而不是直接覆盖？

交换顺带把零挤到尾部，省掉一趟补零

2. slow 到底是「下一个写入位」还是「最前面等待替换的零」？

始终成立的是前者，出现零之后两者恰好重合

讲解

给定数组 nums，将所有 0 移动到数组末尾，同时保持非零元素的相对顺序。要求原地修改数组。

输入：[0, 1, 0, 3, 12]
结果：[1, 3, 12, 0, 0]

✗ 第一版（错误，保留作对照——但别照抄）：三个问题——zero 未定义（NameError）、while 里没有推进（死循环）、写回的位置也不对。根因是没有先把不变量定下来就开始写。

# ✗ 错误版本：zero 未定义 + while 无推进
def moveZero(nums):
    for i in range(len(nums)):
        while nums[i]!=0:
            nums[zero]=nums[i]

两个指针：

+ fast：遍历数组，寻找非零元素。 + slow：指向下一个非零元素应该放置的位置，也可以理解为前面最早等待替换的零。

def move_zeros(nums):
    slow=0
    for fast in range(len(nums)):
        if nums[fast]!=0:
            nums[fast],nums[slow]=nums[slow],nums[fast]
            slow+=1

循环不变量：

每轮处理 nums[fast] 之前，nums[:slow] 是原数组已遍历部分中的所有非零元素，并且相对顺序不变；nums[slow:fast] 全部是零。

slow 表示下一个非零元素应该放入的位置，也等于当前已处理部分中非零元素的数量。

初始 slow = 0，表示尚未处理任何非零元素，下一个非零元素应放到下标 0。

所以两种理解的关系是：

+ 始终成立：slow 是下一个非零元素的写入位置。 + 当已遍历部分出现零后：slow 也恰好指向最前面等待替换的零。

循环不变量可以恢复为：

处理 fast 前，nums[:slow] 保存已遍历部分的全部非零元素且顺序不变，nums[slow:fast] 全部为零。

恢复脚本：

快指针寻找非零元素，慢指针表示下一个非零写入位置；遇到非零就交换并推进慢指针。
