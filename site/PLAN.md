# site · 人生操作系统方案 v2（2026-10-07 定稿）

> 本文件是 `site/` 与全库**方案正本**。v1（2026-09-10，理论地基与 md/html 判据）归档于 `archive/site/PLAN-v1-2026-09-10.md`，其第一性原理链、md/html 分工、"视图判据"全部继承，此处不重复。
> 更新规则沿用 v1：只在发现错误时改，新点子进〈方案停车场〉。

## 一、系统目的（v2 校准）

**这个库是一条内化流水线 + 一面人生画像，不是存储系统。** 秋招是当前挂载的战役，不是系统存在的理由。

两个回路、两个入口、每回路内部唯一：

| 回路 | 频率 | 动作 | 入口 |
|---|---|---|---|
| **内化回路** | 每天 | 看今天清单 → 闭卷练 → 记账回流 | **今日页** |
| **画像回路** | 每周/事件触发 | 照 X 光（亮暗空）→ 校准目标与策略 | **画像页** |

## 二、统一本体：万物皆卡 × 三轴

任何内容（经历、错题、一本书、一门技术、一笔投资反思）都是一张卡，卡有三个正交坐标：

1. **域（场）**：指导生活的哪一面。域登记表 `site/_data/domains.js`，**一行一域、有首张卡才建**。初始：事业 / 学识 / 关系 / 身心；候选（首卡落地时启用）：财富 / 审美。域是宪法——定了少动，纵向数据靠轴稳定。
2. **对象（人/事/物）**：挂靠谁。人（跟谁有关）、事（哪件事触发）、物（哪本书/作品/概念）。
3. **内化五档（亮暗空）**：`空 → 暗（记录过）→ 读厚（拆成情境→动作）→ 训练（进派单闭卷过）→ 亮（真实用上，uses 打卡）`。信号源：status、闭卷等级、复训位置、mv.brain.v1 uses——由 build 聚合成 `内化度`，与 `覆盖度`（学没学过）分开显示。

**功夫与场分离**：目标/策略/执行/心态是横切的功夫卡（行动规则、jy 系列，跨域适用）；社交归关系域、学习归学识域。卡上挂域，功夫不设域。

**派单边界**：有"标准动作"或"可判对错"才成卡进派单；鉴赏与纯感悟进滋养层（只进画像与年度回顾，免打卡）——保护内在动机。

## 三、五条设计律

1. **万物皆卡，一卡一生命**：一套卡 schema、一条内化管线、一个训练引擎，多种视图。
2. **功夫与场分离**（见上）。
3. **错题本/错话本不是新系统，是进料口**：走同一条管线（记录→复盘→提炼成"情境→动作"卡→派单），产出仍归行动规则/出牌准则/母题卡正本，绝不另立平行文体。
4. **可派单才派单**：滋养层不进每日配额。
5. **两页一库**：全站只两个面向人的页面（今日页、画像页），其余全是 build 派生详情页与备查层。**新增任何页面/入口必须回答"属于哪个回路、回答什么问题"，且每个新增捆绑一个退役。**

## 四、目标结构

```text
今日页（index+progress 合并，内化回路唯一入口）
  = 今天清单（唯一调度：progress 派单引擎）+ 台账提醒条 + 新到架信息流
画像页（brain 重构，画像回路唯一入口）
  = 我是谁（画像卡）+ 我的版图（域×内化矩阵，本体）+ 我的轨迹（成长曲线）
  + 宫殿皮肤（3D：房间=域，发光=内化档位，翻卡=详情——矩阵的渲染层，不是另一套数据）
派生详情层（build 生成）：topics/ modules/ onepage/ reviews/ projects/
备查层（不进任何入口页）：raw/ summaries/ sources/ archive/
战役工具（temporary）：resume-map、投递台账等——战役结束归档
```

退役清单（v1 结构 → v2 去向）：index review-deck → 删；decks.js/decks.json → 停生成；cards.html / rules.html 独立入口 → 画像页下钻视图；brain 今日侧栏 → 删（今日唯一化）；宫殿导航地图 → 删。

## 五、治理律（对"只加不减"根因）

1. **落盘即上站**：build 全量渲染内容目录 md（candidate 显示"AI 生成·待验收"徽标、不进派单——可见性与可信度分离）；CI 断言 `python site/build.py && git diff --exit-code site/`；`recent.js` 新到架信息流保证任何落盘 24h 内出现在站上。
2. **三态律**（断舍离）：所有文件只有三态——在用（资产层）/ 在箱（archive/，可找回）/ 不存在。**"散在地上"是非法状态。**
3. **月度断舍离**（每月首次画像巡检顺带 15 分钟）：candidate 超 30 天未触碰→抽屉三选一（验收/归档/删）；战役品完结即归档；中间件用完即删；**功能一月未用→下次触碰该页时删**；life/ 流水满季度移 archive；raw/ summaries/ 是矿仓例外不清零。
4. **备查层不出入口**：矿仓内容只被反链触达，不上首页。
