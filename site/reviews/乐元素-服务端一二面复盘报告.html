缺失知识模块

为什么是缺口：二面面试官原话：「Java 及常用部署、周边组件…这是它的基础」；你的栈是 Python

补到什么程度：能写 Java 版基础算法；能说清 Spring Boot 项目结构、Maven、线程池、集合类、JVM 内存模型基本概念；能讲「Python 转 Java 我准备怎么做」

挂靠：study 新增或并入 [[面试回答与复习验收手册]]

为什么是缺口：B16 手撕 15 分钟没写出来，自述「AI coding 多，自己写代码退化了一点」

补到什么程度：白板/共享屏限时 10 分钟写出：字符串处理、数组双指针、链表、简单 DP、二叉树遍历；必须手写不靠补全

挂靠：[[母题池-36道推导与手写指南]]

为什么是缺口：A19 Linux、A20 Redis、A21 锁、A22 网络分层、A23 状态码、B15 SSE

补到什么程度：每个知识点按「定义 → 原理 → 取舍 → 我用过的场景」四段式能讲 60 秒；尤其纠正 SSE 和 502/504

挂靠：[[study/09-数据缓存队列与一致性]]、[[study/08-Python异步与AI后端]]

为什么是缺口：A10 控制变量、A15 ground truth、A16 测量方法、B14 数字口径

补到什么程度：能说出：ground truth、Execution Accuracy、控制变量、口径（自建评测集 vs 生产 P99）、A/B 基本逻辑

挂靠：[[study/07-Eval-Trace与Observability]]

为什么是缺口：A24 排行榜设计崩；误判消消乐为单机；没提防作弊

补到什么程度：掌握 5 个母题：排行榜、匹配、活动系统、防作弊、弱联网同步；每题按「澄清 → 拆解 → 方案 → 风险 → 指标」

下次准备清单

  • 手撕 3 题限时训练：字符串翻转（保留空格版）、数组双指针、链表反转，每道题共享屏幕 / 白板手写，关掉 AI 补全和 IDE 提示，限时 10 分钟 —— 完成标准：三题都能一次跑通，不用调试器。
  • 八股 6 题写成 60 秒口述卡：Linux 排查线、Redis 五类数据结构 + 场景、乐观锁悲观锁（含版本号 / CAS / ABA）、URL 全过程、502/503/504 区分、SSE vs WebSocket —— 完成标准：不看笔记讲完，每卡计时 60–90 秒。
  • 纠正两处概念错误并录音复述：SSE 是长连接；502 是响应无效、504 是超时 —— 完成标准：录一遍音，回听没有含糊词。
  • Java 最小可用准备：写一个 Spring Boot 的 hello world + 一个 Controller + Redis 读写；能说清「我从 Python 转 Java 的学习路径」 —— 完成标准：能跑起来，能讲 3 分钟。
  • 补一道场景母题：排行榜（按第 3.3 节六步），写进 [[场景设计题库-十道母题]] —— 完成标准：对着空白纸讲完六步。
  • 三项目 90 秒服务端版各录一遍：EnergyOps / 数驭穹图 / RuleArena，主语换成「数据可信、幂等、性能优化、可验证」 —— 完成标准：每版 ≤95 秒，含至少 1 个数字。
  • 过一遍 6 张八股口述卡 + 3 段项目口述稿（只读不背）。
  • 过一遍「默认拒绝 + 白名单 + 不可逆清单 + 审批流 + 可回滚」五件套（A11 会再考）。
  • 准备 3 个反问：这个岗位半年内最要解决的问题 / 团队里做得好的人是什么样的 / 后面还有几轮、多久有反馈。
  • 在桌上贴一张纸：「被追问先给结论；不会就说不会 + 相邻已知 + 验证路径」。
  • 每题第一句先给结论，再说依据；被追问时先重复对方的问题确认理解。
  • 被否定时用四步：「您这个角度我没考虑到」→ 区分事实与判断 → 给依据 → 「如果数据证明我错了，我会改成……」。不要说「对，那可能确实」然后停住（A15 的教训）。
  • 数字一律自带口径：「这个 20 多秒是我们自建评测集的中位值，不是生产 P99」——主动交代比被追问出来强。
  • 手撕题：先复述题意 + 确认边界（空串？多空格？大小写？）→ 说思路 → 再写；卡住超过 2 分钟就说思路 + 写伪代码，不要沉默。
  • 收尾不说「有 AI 学得快」，改成：「Java 我目前是 Python 主力，Java 写过【填：你写过的东西】；如果需要转，我计划先用两周把 Spring Boot 和常用组件补到能独立写接口的程度。」
