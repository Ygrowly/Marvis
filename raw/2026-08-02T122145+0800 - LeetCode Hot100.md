## 第1题 | 1. 两数之和 (Two Sum)

⏱ 时间: O(n) 💾 空间: O(n)

### 题目描述

给定一个整数数组 nums 和一个整数目标值 target，请你在该数组中找出和为目标值 target 的那两个整数，并返回它们的数组下标。你可以假设每种输入只会对应一个答案，并且你不能使用两次相同的元素。你可以按任意顺序返回答案。  
  
输入：nums: List\[int\], target: int  
输出：List\[int\]，返回两个下标  
  
约束条件：  
\- 2 <= nums.length <= 10^4  
\- -10^9 <= nums\[i\] <= 10^9  
\- -10^9 <= target <= 10^9  
\- 只会存在一个有效答案

### 最优解法

方法：哈希表

思路：遍历数组，对于每个元素，检查 target - nums\[i\] 是否已经在哈希表中。如果在，直接返回两个下标；如果不在，将当前元素及其下标存入哈希表。

### 代码实现 (Python)

class Solution:

def twoSum(self, nums: List\[int\], target: int) -> List\[int\]:

hashmap = {}

for i, num in enumerate(nums):

complement = target - num

if complement in hashmap:

return \[hashmap\[complement\], i\]

hashmap\[num\] = i

复杂度分析：时间 O(n)，空间 O(n)

## 第2题 | 49. 字母异位词分组 (Group Anagrams)

⏱ 时间: O(n \* k \* log(k))，其中 n 是字符串数量，k 是最长字符串长度 💾 空间: O(n \* k)

### 题目描述

给你一个字符串数组，请你将字母异位词组合在一起。可以按任意顺序返回结果列表。字母异位词是由重新排列源单词的所有字母得到的一个新单词。  
  
输入：strs: List\[str\]  
输出：List\[List\[str\]\]  
  
约束条件：  
\- 1 <= strs.length <= 10^4  
\- 0 <= strs\[i\].length <= 100  
\- strs\[i\] 仅包含小写字母

### 最优解法

方法：排序哈希分组

思路：将每个字符串排序后作为哈希表的键，原字符串作为值加入对应的列表中。排序后相同的字符串一定是字母异位词。

### 代码实现 (Python)

class Solution:

def groupAnagrams(self, strs: List\[str\]) -> List\[List\[str\]\]:

groups = defaultdict(list)

for s in strs:

key = ''.join(sorted(s))

groups\[key\].append(s)

return list(groups.values())

复杂度分析：时间 O(n \* k \* log(k))，其中 n 是字符串数量，k 是最长字符串长度，空间 O(n \* k)

## 第3题 | 128. 最长连续序列 (Longest Consecutive Sequence)

⏱ 时间: O(n) 💾 空间: O(n)

### 题目描述

给定一个未排序的整数数组 nums，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。请你设计并实现时间复杂度为 O(n) 的算法解决此问题。  
  
输入：nums: List\[int\]  
输出：int  
  
约束条件：  
\- 0 <= nums.length <= 10^5  
\- -10^9 <= nums\[i\] <= 10^9

### 最优解法

方法：哈希集合

思路：将所有数字放入集合中。遍历集合，对于每个数字，如果 num-1 不在集合中，说明它是一段连续序列的起点，从它开始向后计数连续的数字个数，更新最大长度。

### 代码实现 (Python)

class Solution:

def longestConsecutive(self, nums: List\[int\]) -> int:

num\_set = set(nums)

longest = 0

for num in num\_set:

if num - 1 not in num\_set:

current = num

length = 1

while current + 1 in num\_set:

current += 1

length += 1

longest = max(longest, length)

return longest

复杂度分析：时间 O(n)，空间 O(n)

## 第4题 | 11. 盛最多水的容器 (Container With Most Water)

⏱ 时间: O(n) 💾 空间: O(1)

### 题目描述

给定一个长度为 n 的整数数组 height。有 n 条垂线，第 i 条线的两个端点是 (i, 0) 和 (i, height\[i\])。找出其中的两条线，使得它们与 x 轴共同构成的容器可以容纳最多的水。返回容器可以储存的最大水量。注意你不能倾斜容器。  
  
输入：height: List\[int\]  
输出：int  
  
约束条件：  
\- n == height.length  
\- 2 <= n <= 10^5  
\- 0 <= height\[i\] <= 10^4

### 最优解法

方法：双指针

思路：左右指针从两端开始向中间收缩。每次计算当前面积并更新最大值，然后移动较矮的那一侧指针，因为移动较高一侧不可能得到更大面积。

### 代码实现 (Python)

class Solution:

def maxArea(self, height: List\[int\]) -> int:

left, right = 0, len(height) - 1

max\_area = 0

while left < right:

area = min(height\[left\], height\[right\]) \* (right - left)

max\_area = max(max\_area, area)

if height\[left\] < height\[right\]:

left += 1

else:

right -= 1

return max\_area

复杂度分析：时间 O(n)，空间 O(1)

## 第5题 | 15. 三数之和 (3Sum)

⏱ 时间: O(n^2) 💾 空间: O(log n)，排序所需空间

### 题目描述

给你一个整数数组 nums，判断是否存在三元组 \[nums\[i\], nums\[j\], nums\[k\]\] 满足 i!= j、i!= k 且 j!= k，同时还满足 nums\[i\] + nums\[j\] + nums\[k\] == 0。请你返回所有和为 0 且不重复的三元组。注意：答案中不可以包含重复的三元组。  
  
输入：nums: List\[int\]  
输出：List\[List\[int\]\]  
  
约束条件：  
\- 3 <= nums.length <= 3000  
\- -10^5 <= nums\[i\] <= 10^5

### 最优解法

方法：排序 + 双指针

思路：先排序数组。固定第一个数，然后用双指针在其右侧区间找两数之和等于其相反数的组合。通过跳过重复元素来避免重复三元组。

### 代码实现 (Python)

class Solution:

def threeSum(self, nums: List\[int\]) -> List\[List\[int\]\]:

nums.sort()

result = \[\]

for i in range(len(nums) - 2):

if nums\[i\] > 0:

break

if i > 0 and nums\[i\] == nums\[i - 1\]:

continue

left, right = i + 1, len(nums) - 1

while left < right:

total = nums\[i\] + nums\[left\] + nums\[right\]

if total < 0:

left += 1

elif total > 0:

right -= 1

else:

result.append(\[nums\[i\], nums\[left\], nums\[right\]\])

while left < right and nums\[left\] == nums\[left + 1\]:

left += 1

while left < right and nums\[right\] == nums\[right - 1\]:

right -= 1

left += 1

right -= 1

return result

复杂度分析：时间 O(n^2)，空间 O(log n)，排序所需空间

## 第6题 | 42. 接雨水 (Trapping Rain Water)

⏱ 时间: O(n) 💾 空间: O(1)

### 题目描述

给定 n 个非负整数表示每个宽度为 1 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。  
  
输入：height: List\[int\]  
输出：int  
  
约束条件：  
\- n == height.length  
\- 1 <= n <= 2 \* 10^4  
\- 0 <= height\[i\] <= 10^5

### 最优解法

方法：双指针

思路：维护左右指针及各自遇到的最大高度。每次移动较矮一侧的指针，因为较矮一侧的接水量由该侧最大高度决定。当前位置能接的水等于该侧最大高度减去当前高度。

### 代码实现 (Python)

class Solution:

def trap(self, height: List\[int\]) -> int:

left, right = 0, len(height) - 1

left\_max = right\_max = 0

water = 0

while left < right:

if height\[left\] < height\[right\]:

if height\[left\] >= left\_max:

left\_max = height\[left\]

else:

water += left\_max - height\[left\]

left += 1

else:

if height\[right\] >= right\_max:

right\_max = height\[right\]

else:

water += right\_max - height\[right\]

right -= 1

return water

复杂度分析：时间 O(n)，空间 O(1)

## 第7题 | 283. 移动零 (Move Zeroes)

⏱ 时间: O(n) 💾 空间: O(1)

### 题目描述

给定一个数组 nums，编写一个函数将所有 0 移动到数组的末尾，同时保持非零元素的相对顺序。请注意，必须在不复制数组的情况下原地对数组进行操作。  
  
输入：nums: List\[int\]  
输出：None（原地修改）  
  
约束条件：  
\- 1 <= nums.length <= 10^4  
\- -2^31 <= nums\[i\] <= 2^31 - 1

### 最优解法

方法：双指针交换

思路：使用慢指针 j 记录下一个非零元素应该放置的位置，快指针 i 遍历数组。当 nums\[i\] 不为零时，将其与 nums\[j\] 交换，然后 j 前进一步。

### 代码实现 (Python)

class Solution:

def moveZeroes(self, nums: List\[int\]) -> None:

j = 0

for i in range(len(nums)):

if nums\[i\]!= 0:

nums\[i\], nums\[j\] = nums\[j\], nums\[i\]

j += 1

复杂度分析：时间 O(n)，空间 O(1)

## 第8题 | 3. 无重复字符的最长子串 (Longest Substring Without Repeating Characters)

⏱ 时间: O(n) 💾 空间: O(min(m, n))，m 为字符集大小

### 题目描述

给定一个字符串 s，请你找出其中不含有重复字符的最长子串的长度。  
  
输入：s: str  
输出：int  
  
约束条件：  
\- 0 <= s.length <= 5 \* 10^4  
\- s 由英文字母、数字、符号和空格组成

### 最优解法

方法：滑动窗口

思路：使用滑动窗口维护一个无重复字符的子串。用哈希表记录每个字符最近出现的位置，当遇到重复字符时，将窗口左边界移动到重复字符上次出现位置的右边。

### 代码实现 (Python)

class Solution:

def lengthOfLongestSubstring(self, s: str) -> int:

char\_index = {}

left = 0

max\_len = 0

for right, ch in enumerate(s):

if ch in char\_index and char\_index\[ch\] >= left:

left = char\_index\[ch\] + 1

char\_index\[ch\] = right

max\_len = max(max\_len, right - left + 1)

return max\_len

复杂度分析：时间 O(n)，空间 O(min(m, n))，m 为字符集大小

## 第9题 | 438. 找到字符串中所有字母异位词 (Find All Anagrams in a String)

⏱ 时间: O(n)，其中 n 为 s 的长度 💾 空间: O(1)，字符集大小固定为 26

### 题目描述

给定两个字符串 s 和 p，找到 s 中所有 p 的异位词的子串，返回这些子串的起始索引。不考虑答案输出的顺序。异位词指由相同字母重排列形成的字符串（包括相同的字符串）。  
  
输入：s: str, p: str  
输出：List\[int\]  
  
约束条件：  
\- 1 <= s.length, p.length <= 3 \* 10^4  
\- s 和 p 仅包含小写字母

### 最优解法

方法：滑动窗口 + 计数比较

思路：维护一个大小为 len(p) 的滑动窗口，用计数数组统计窗口内各字符出现次数，与 p 的字符计数进行比较。每次窗口滑动时增量更新计数。

### 代码实现 (Python)

class Solution:

def findAnagrams(self, s: str, p: str) -> List\[int\]:

if len(s) < len(p):

return \[\]

p\_count = \[0\] \* 26

s\_count = \[0\] \* 26

for ch in p:

p\_count\[ord(ch) - ord('a')\] += 1

result = \[\]

for i in range(len(s)):

s\_count\[ord(s\[i\]) - ord('a')\] += 1

if i >= len(p):

s\_count\[ord(s\[i - len(p)\]) - ord('a')\] -= 1

if s\_count == p\_count:

result.append(i - len(p) + 1)

return result

复杂度分析：时间 O(n)，其中 n 为 s 的长度，空间 O(1)，字符集大小固定为 26

输出：str  
  
约束条件：  
\- 1 <= s.length, t.length <= 10^5  
\- s 和 t 由英文字母组成

### 最优解法

方法：滑动窗口

思路：用两个指针维护滑动窗口，用哈希表记录 t 中各字符需要的个数和窗口中的字符计数。右指针扩展窗口直到包含 t 的所有字符，然后左指针收缩窗口寻找最小覆盖子串。

### 代码实现 (Python)

class Solution:

def minWindow(self, s: str, t: str) -> str:

from collections import Counter

need = Counter(t)

missing = len(t)

left = 0

start, end = 0, float('inf')

for right, ch in enumerate(s):

if need\[ch\] > 0:

missing -= 1

need\[ch\] -= 1

while missing == 0:

if right - left < end - start:

start, end = left, right

need\[s\[left\]\] += 1

if need\[s\[left\]\] > 0:

missing += 1

left += 1

return s\[start:end + 1\] if end!= float('inf') else

思路：维护当前子数组的最大和 current\_sum。遍历数组时，对于每个元素，要么将其加入之前的子数组，要么从它开始新的子数组，取两者较大值。同时更新全局最大和。

for i in range(m + 1):

dp\[i\]\[0\] = i

for j in range(n + 1):

dp\[0\]\[j\] = j

for i in range(1, m + 1):

for j in range(1, n + 1):

if word1\[i - 1\] == word2\[j - 1\]:

dp\[i\]\[j\] = dp\[i - 1\]\[j - 1\]

else:

dp\[i\]\[j\] = 1 + min(dp\[i - 1\]\[j\], dp\[i\]\[j - 1\], dp\[i - 1\]\[j - 1\])

return dp\[m\]\[n\]

复杂度分析：时间 O(m \* n)，空间 O(m \* n)

## 第95题 | 1143. 最长公共子序列 (Longest Common Subsequence)

⏱ 时间: O(m \* n) 💾 空间: O(m \* n)

### 题目描述

给定两个字符串 text1 和 text2，返回这两个字符串的最长公共子序列的长度。如果不存在公共子序列，返回 0。一个字符串的子序列是指这样一个新的字符串：它是由原字符串在不改变字符的相对顺序的情况下删除某些字符（也可以不删除任何字符）后组成的新字符串。两个字符串的公共子序列是这两个字符串所共同拥有的子序列。  
  
输入：两个字符串 text1 和 text2。  
输出：返回最长公共子序列的长度。  
  
约束条件：  
\- 1 <= text1.length, text2.length <= 1000  
\- text1 和 text2 仅由小写英文字符组成

### 最优解法

方法：二维动态规划

思路：定义 dp\[i\]\[j\] 为 text1 的前 i 个字符和 text2 的前 j 个字符的最长公共子序列长度。若 text1\[i-1\] == text2\[j-1\]，则 dp\[i\]\[j\] = dp\[i-1\]\[j-1\] + 1；否则 dp\[i\]\[j\] = max(dp\[i-1\]\[j\], dp\[i\]\[j-1\])。可用一维滚动数组优化空间。

### 代码实现 (Python)

class Solution:

def longestCommonSubsequence(self, text1: str, text2: str) -> int:

m, n = len(text1), len(text2)

dp = \[\[0\] \* (n + 1) for \_ in range(m + 1)\]

for i in range(1, m + 1):

for j in range(1, n + 1):

if text1\[i - 1\] == text2\[j - 1\]:

dp\[i\]\[j\] = dp\[i - 1\]\[j - 1\] + 1

else:

dp\[i\]\[j\] = max(dp\[i - 1\]\[j\], dp\[i\]\[j - 1\])

return dp\[m\]\[n\]

复杂度分析：时间 O(m \* n)，空间 O(m \* n)

## 第96题 | 31. 下一个排列 (Next Permutation)

⏱ 时间: O(n) 💾 空间: O(1)

### 题目描述

整数数组的一个排列就是将其所有成员以序列或线性顺序排列。整数数组的下一个排列是指其整数的下一个字典序更大的排列。更正式地，如果数组的所有排列根据其字典顺序从小到大排列在一个容器中，那么数组的下一个排列就是在这个有序容器中排在它后面的那个排列。如果不存在下一个更大的排列，那么这个数组必须重排为字典序最小的排列（即升序排列）。必须原地修改，只允许使用额外常数空间。  
  
输入：整数数组 nums。  
输出：原地将数组修改为下一个排列，无需返回值。  
  
约束条件：  
\- 1 <= nums.length <= 100  
\- 0 <= nums\[i\] <= 100

### 最优解法

方法：两遍扫描

思路：从右向左找到第一个相邻升序对 nums\[i\] < nums\[i+1\]，即 i 是需要变大的位置。然后从右向左找到第一个大于 nums\[i\] 的数 nums\[j\]，交换两者。最后将 i+1 到末尾的部分反转为升序，即得到下一个排列。若找不到升序对说明已是最大排列，直接反转整个数组。

### 代码实现 (Python)

class Solution:

def nextPermutation(self, nums: list\[int\]) -> None:

n = len(nums)

i = n - 2

while i >= 0 and nums\[i\] >= nums\[i + 1\]:

i -= 1

if i >= 0:

j = n - 1

while nums\[j\] <= nums\[i\]:

j -= 1

nums\[i\], nums\[j\] = nums\[j\], nums\[i\]

left, right = i + 1, n - 1

while left < right:

nums\[left\], nums\[right\] = nums\[right\], nums\[left\]

left += 1

right -= 1

复杂度分析：时间 O(n)，空间 O(1)

## 第97题 | 75. 颜色分类 (Sort Colors)

⏱ 时间: O(n) 💾 空间: O(1)

### 题目描述

给定一个包含红色、白色和蓝色、共 n 个元素的数组 nums，原地对它们进行排序，使得相同颜色的元素相邻，并按照红色、白色、蓝色顺序排列。我们使用整数 0、1 和 2 分别表示红色、白色和蓝色。必须在不使用库内置的 sort 函数的情况下解决这个问题。  
  
输入：整数数组 nums，其中元素只包含 0、1、2。  
输出：原地排序数组，无需返回值。  
  
约束条件：  
\- n == nums.length  
\- 1 <= n <= 300  
\- nums\[i\] 为 0、1 或 2  
  
进阶：你能想出一个仅使用常数空间的一趟扫描算法吗？

### 最优解法

方法：荷兰国旗问题（三路划分）

思路：使用三个指针：left 指向 0 区域的右边界，right 指向 2 区域的左边界，mid 用于遍历。遇到 0 则与 left 交换并两者右移，遇到 2 则与 right 交换并 right 左移（mid 不动），遇到 1 则 mid 右移。一次遍历完成排序。

### 代码实现 (Python)

class Solution:

def sortColors(self, nums: list\[int\]) -> None:

left, mid, right = 0, 0, len(nums) - 1

while mid <= right:

if nums\[mid\] == 0:

nums\[left\], nums\[mid\] = nums\[mid\], nums\[left\]

left += 1

mid += 1

elif nums\[mid\] == 2:

nums\[mid\], nums\[right\] = nums\[right\], nums\[mid\]

right -= 1

else:

mid += 1

复杂度分析：时间 O(n)，空间 O(1)

## 第98题 | 136. 只出现一次的数字 (Single Number)

⏱ 时间: O(n) 💾 空间: O(1)

### 题目描述

给你一个非空整数数组 nums，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。你必须设计并实现线性时间复杂度的算法来解决此问题，且该算法只使用常量额外空间。  
  
输入：非空整数数组 nums。  
输出：返回只出现一次的元素。  
  
约束条件：  
\- 1 <= nums.length <= 3 \* 10^4  
\- -3 \* 10^4 <= nums\[i\] <= 3 \* 10^4  
\- 除了某个元素只出现一次以外，其余每个元素均出现两次

### 最优解法

方法：异或运算

思路：利用异或运算的性质：a ^ a = 0，a ^ 0 = a，且异或满足交换律和结合律。将所有数字异或在一起，出现两次的数字互相抵消为 0，最终结果就是只出现一次的数字。

### 代码实现 (Python)

class Solution:

def singleNumber(self, nums: list\[int\]) -> int:

result = 0

for num in nums:

result ^= num

return result

复杂度分析：时间 O(n)，空间 O(1)

## 第99题 | 169. 多数元素 (Majority Element)

⏱ 时间: O(n) 💾 空间: O(1)

### 题目描述

给定一个大小为 n 的数组 nums，返回其中的多数元素。多数元素是指在数组中出现次数大于 n/2 的元素。你可以假设数组是非空的，并且给定的数组总是存在多数元素。  
  
输入：整数数组 nums。  
输出：返回多数元素。  
  
约束条件：  
\- n == nums.length  
\- 1 <= n <= 5 \* 10^4  
\- -10^9 <= nums\[i\] <= 10^9  
  
进阶：尝试设计时间复杂度为 O(n)、空间复杂度为 O(1) 的算法解决此问题。

### 最优解法

方法：Boyer-Moore 投票算法

思路：维护一个候选元素 candidate 和计数器 count。遍历数组，若 count 为 0 则将当前元素设为候选；若当前元素等于候选则 count 加 1，否则 count 减 1。由于多数元素出现次数超过一半，最终候选元素即为多数元素。

### 代码实现 (Python)

class Solution:

def majorityElement(self, nums: list\[int\]) -> int:

candidate = 0

count = 0

for num in nums:

if count == 0:

candidate = num

count += 1 if num == candidate else -1

return candidate

复杂度分析：时间 O(n)，空间 O(1)

## 第100题 | 287. 寻找重复数 (Find the Duplicate Number)

⏱ 时间: O(n) 💾 空间: O(1)

### 题目描述

给定一个包含 n + 1 个整数的数组 nums，其数字都在 \[1, n\] 范围内（包括 1 和 n），可知至少存在一个重复的整数。假设 nums 只有一个重复的整数，返回这个重复的数。你设计的解决方案必须不修改数组 nums 且只用常量级 O(1) 的额外空间。  
  
输入：包含 n + 1 个整数的数组 nums。  
输出：返回重复的整数。  
  
约束条件：  
\- 1 <= n <= 10^5  
\- nums.length == n + 1  
\- 1 <= nums\[i\] <= n  
\- nums 中只有一个整数出现两次或多次，其余整数均只出现一次  
  
进阶：  
\- 如何证明 nums 中至少存在一个重复的数字？  
\- 你可以设计一个线性级时间复杂度 O(n) 的解决方案吗？

### 最优解法

方法：Floyd 判圈算法（快慢指针）

思路：将数组视为链表，nums\[i\] 表示节点 i 指向的下一个节点。由于存在重复数，必定存在环。使用快慢指针先找到环内相遇点，然后将一个指针移到起点，两个指针同速前进，再次相遇的位置就是环的入口，即重复的数字。

### 代码实现 (Python)

class Solution:

def findDuplicate(self, nums: list\[int\]) -> int:

slow = fast = 0

while True:

slow = nums\[slow\]

fast = nums\[nums\[fast\]\]

if slow == fast:

break

slow = 0

while slow!= fast:

slow = nums\[slow\]

fast = nums\[fast\]

return slow

复杂度分析：时间 O(n)，空间 O(1)
