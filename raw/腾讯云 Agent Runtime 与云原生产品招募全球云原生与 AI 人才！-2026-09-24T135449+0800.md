等你加入的 腾讯云原生 *2026年9月15日 20:20*

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/6FZLmrnGCLvobGQclI2VnibgRllrJMTpQict3ADsumBkfk9fh79uAQYlFOdL21Lr9tkJia8clapDn2c7RHE9AYgU9uIvkbNw3agTGGuWoicvzG0/640?wx_fmt=png&from=appmsg&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=0)

我们是腾讯云 Agent Runtime 与云原生团队，目标是为腾讯集团及外部客户的互联网与 AI 业务，打造真正稳定、高效、面向未来的云基础设施。云原生产品家族支撑海量互联网业务，让应用跑得更稳、更快、更具弹性；Agent Runtime服务蓬勃发展的 Agentic AI 业务，让智能体从 Demo 走向真实生产环境。互联网的规模与 AI 的想象力正在这里交汇，而我们要做的，就是构建承载下一个时代的云底座！

面向智能体时代，我们推出腾讯云 Agent Runtime，围绕 Agent 的运行、治理与智能化，提供安全沙箱、执行引擎、工具网关、身份权限、记忆、可观测性和弹性调度等核心能力。我们用系统的确定性承接 Agent 的不确定性，让智能体能够安全、稳定、规模化地进入真实生产环境。目前，这套基础设施已经支持腾讯内部 WorkBuddy、CodeBuddy、IMA、元宝等 Agent 产品，也服务于国内大部分头部 LLM 大模型厂商的强化学习场景，承载数百万级沙箱并发规模。我们还开源了 CubeSandbox，期待与全球开发者一起，定义更加开放、标准和强大的 Agent 基础设施。

在云原生方向，我们持续建设腾讯云容器服务 TKE，基于原生 Kubernetes 提供企业级容器管理能力，支撑超大规模容器集群、微服务、弹性计算和复杂生产系统。我们的产品服务于微信、QQ、腾讯会议、王者荣耀等腾讯内部业务，也支持小红书、美团、富途、微众等众多外部客户。面对真实业务中的每一次流量洪峰和规模挑战，我们不断突破集群规模、极致弹性、资源调度、性能优化与稳定性的边界，让每一份计算、网络和存储资源释放更大价值。

现在，我们正在把这些经过大规模生产环境验证的能力带向全球：推进产品国际化，建设全球化 AI 基础设施，融入海外开发者生态，服务更多全球客户。这里有行业领先的业务规模，有技术深水区里的硬核挑战，更有一片正在快速生长、尚未被完全定义的新大陆。你可以深入操作系统、容器、调度、网络、存储和虚拟化，也可以参与产品规划、解决方案、开发者生态与全球商业化建设。

如果你渴望解决真正困难的问题，期待让自己的技术和产品影响亿万用户，并愿意与一群务实、专业、敢于突破的伙伴并肩前行，欢迎加入我们。一起把复杂的事情做成，把前沿技术推向生产，把云与 AI Agent 基础设施带向全球——共同构建互联网与 AI 智能体时代的坚实底座！
