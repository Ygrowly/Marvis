# 面试准备的第一性原理 —— 乐元素冲刺 & 全部面试的通用打法

> 依据：《面试官对历史实习都会问哪些东西》《面试官描述需求能力》《年包50w的字节Agent岗到底要会啥》三份材料 + 你的实际处境（明天 9/9 乐元素一面+二面）。

---

## 一、第一性原理：面试到底在测什么？

把三份文档剥到底，它们说的是同一句话：

> **面试官只有一个问题要回答："把我的需求交给这个人，他能不能扛住？"**
> 而他唯一的信息来源，是你讲述经历时暴露出来的**判断痕迹**。

由此推出三个不受任何公司、岗位影响的推论：

1. **面试不是知识考试，是证据采集。** 你背了多少八股、跑通了多少 Demo 都不是证据，只是入场券。
2. **面试官验证"真做过"的方式，不是问代码细节，而是看你有没有三种痕迹：**
   - **迭代痕迹**：一开始想做 A → 发现不行 → 换成 B。只有一个版本的故事 = 背教程。
   - **对比痕迹**：选 A 不选 B，能同时说出两者的优缺点和你场景的约束。"因为主流/常用" = 零分。
   - **复盘痕迹**：重做一次会改什么？最蠢的决策是什么？答不出来 = 没想过上线后的事。
3. **准备 ≠ 学更多东西。准备 = 把已经做过的事"开矿"成决策链 + 大量口述输出。**
   你的知识库 questions.md 是问题台账驱动的，但面试准备的台账不应该是"还有哪些知识没学"，而应该是"还有哪些做过的经历没被挖成决策链"。

## 二、三份文档各自解决什么（不要混用）

| 文档 | 它回答的问题 | 层面 |
|---|---|---|
| 面试官对实习问什么 | **怎么讲**：STAR 骨架 + 三问结构（介绍实习/业务架构/难点） | 表达结构 |
| 面试官描述需求能力 | **讲多深**：功能层(入场券)→设计层(及格线)→工程层(加分项) | 内容深度 |
| 字节Agent岗要会啥 | **面什么**：后端基本功 × AI工程落地 × 业务理解 | 岗位地图 |

常见错位：用"岗位地图"层面的努力（再学一个框架）去掩盖"内容深度"和"表达结构"层面的欠账（没有决策链、没口述过）。**这就是你感觉"方向偏了"的根源。**

## 三、对你的具体诊断

结合你的情况（系统设计强、瓶颈在精力与启动）：

1. **你的真实短板排序：口述输出 > 决策链整理 > 知识面。**
   系统设计能力是你已有的强项——但它只在"你讲出来"的那一刻才变成分数。
2. **"被动背诵滑坡"在面试准备里的形态就是：刷牛客、背八股、看面经 → 感觉在准备，实际面试官一句话就打回原形。** 三份文档全都印证了这一点。
3. **启动成本高的解法：把"准备"定义成一个可复用的最小动作**（见第五节的 45 分钟模板），而不是一个大计划。你不需要更多计划。

## 四、乐元素的特殊性（明天就要用）

乐元素是游戏公司（开心消消乐、偶像类产品），不是互联网大厂。差异化要点：

1. **考察重心**：游戏公司技术面试通常更看重**工程扎实度 + 解决具体问题的能力**，八股压力略低于字节系，但对"你是不是真动手做过、能不能独立兜住一件事"更敏感。深挖你的 Agent 项目时，迭代痕迹和工程意识（LLM 响应慢怎么办、Agent 死循环怎么发现、上下文超长怎么办）依然是硬通货。
2. **业务视角加分项**：提前想清楚 AI 在游戏里的落地场景——NPC 对话、剧情/文案生成、多语言翻译、QA 自动化测试、玩家客服、内容审核、美术辅助工具链。反问环节问一句"目前业务里哪些环节已经在用 LLM/Agent"——这比问加班能同时体现判断力和诚意。
3. **一天两面的节奏**：
   - 一面：大概率技术面——项目深挖 + 基础 + 可能手撕。把最难讲的那个项目难点书面稿写好。
   - 二面：更偏综合——系统设计（你的强项，主动往这里引）、工程取舍、行为面。准备好"重做会改什么"的复盘故事。
4. **今晚的三件事（保底，不超过这个）**：
   - 写好 3 个书面答案：①介绍实习/项目 ②服务架构 ③一个难点的完整决策链（含"还想过什么方案、为什么放弃"）
   - 准备 2 个反问
   - **23:00 手机放客厅，23:30 前上床**——睡眠约定照常执行，明天的状态值 20% 的分数。

## 五、接下来所有面试的通用循环（最小动作模板）

每一场面试前，只做这一个 45 分钟循环，做完一轮就算闭环：

```
挖（15min）：挑一段经历，逼问自己三个问题——
  为什么当时这么做？还考虑过什么、为什么放弃？
  出过什么问题、怎么定位怎么修的？

写（15min）：把答案写成书面稿（文档1的做法）。
  检查：里面有没有数字？有没有对比？有没有"后来发现不行"？

说（15min）：口述录音 3 分钟讲完，回听。
  听感标准：面试官不打断的话，他能不能在 3 分钟内
  得出"这人真做过"的结论？
```

落地到你的台账系统：
- questions.md 的"每周闭环 ≥1 问"照旧，但**每场真实面试后 24h 内，把被问住的问题写进台账**——真实面试是最便宜的 mock，错过不补课、不自罚，但 never miss twice。
- 有余力时（面试间隙、而非面试前夜），按字节 Agent 岗清单补硬通货：RAG 全链路选型理由、Agent 核心机制（ReAct/Plan-and-Execute/Memory/Tool Calling/MCP）、推理侧（KV Cache/vLLM/流式/Token 成本）。**这是面试间隙的事，不是冲刺的事。**

## 六、一句话总结

> 面试不考你知道多少，考你想过多深、讲得多清。
> 你的准备方向从"再学点什么"切换到"把做过的东西挖成决策链，再大声讲出来"——这就是全部。
