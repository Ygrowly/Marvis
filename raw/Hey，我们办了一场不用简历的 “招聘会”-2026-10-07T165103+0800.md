在电影《实习生》中，70 岁的 Ben 想去一家年轻的互联网公司做实习生。申请过程要求他录一段视频，于是他有些笨拙地架好镜头，坐下来介绍自己。

短短几分钟里，你很难记住他曾经在哪些公司工作，却会开始相信：这个人很可靠，始终保持着好奇，并且愿意重新出发。

**一份简历擅长记录一个人的经历，却很难解释为什么会想和他一起工作🙂↔️。** 但现实中的求职，往往都是从简历开始。

我们修改措辞，调整格式，努力把一个丰富多彩的自己压缩进一两页A4纸里。 **但一个人真正擅长什么，可能藏在他做过的项目里，他对什么保持好奇，也很难被几行经历说清楚。**

所以这一次，我们想把简历先扔掉，换一种方式认识你。

即日起， **Bonjour 联合 310 家正在招聘的公司，共同发起一场「没有简历的招聘会」🤩。** 你可以带着 GitHub、作品或个人主页来到「自荐墙」，让大家先看看你做过什么 **。**

![图片](https://mmecoa.qpic.cn/sz_mmecoa_png/zvZg7aSY4dPBCYiaiceXmlQxpAk7JsF9ShGBicEEpgkOJYwNHMiaOTdAlzibyJGm0TCW0vrn4FNfxmnJibgMjIPE6hpibGNRnkUWhYug2DnxCelEiaQ/640?wx_fmt=png&from=appmsg&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=1) 👆点击打开自荐墙，建议使用 PC Web 获取最佳使用体验 ![图片](https://mmecoa.qpic.cn/sz_mmecoa_jpg/zvZg7aSY4dNkBfKv1goU1ESjOy6YcOa3l8k0oTR2YcAdROLwMtS3tfTiaGPHylutibLa8qfxPFsfCefjic0FC7EUzIQichiaG0ZwMbvdTIQ5Rl2o/640?wx_fmt=jpeg&from=appmsg&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=2)

我们想先看到真实的那个你🫵。

**它可以只是一段真诚的自我介绍、一张 GitHub 截图，或者是一个展示作品的链接。**

哪怕你的作品还不是已完成的状态，即使是刚上线的 Demo、做到一半的 side project，甚至是一次没有成功的尝试，都可以来到自荐墙。

我们不按 Star 数评判价值，也不要求每个人都有一份包装精美的 CV。只要它确实由你参与完成，并且能帮助别人理解你，就值得被点开看看。

**因为我们相信一段真诚的介绍，往往能比一份简历提供更多线索。** 沿着它，别人能看到你对什么感兴趣，也能了解你如何把想法变成现实。

![图片](https://mmecoa.qpic.cn/sz_mmecoa_jpg/zvZg7aSY4dOibPRFGcd7WaUkKHmZQLgvlakebAzkcl0gjNUofTM1kPPTo0TFHnBkIMj0p1t7VOwGciczVL3QlW0Kb0FLeOPOoFibJc5hkTA0tQ/640?wx_fmt=jpeg&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=3)

就像此前，Bonjour 在帮助 AI 创业公司寻找 builder 的过程中， **一位创始人看到候选人的个人网站，只用了两秒就决定邀请他面试。**

那个网站采用了 1984 年 Macintosh 新粗野主义风格 的 UI 设计📺，展示了候选人过去完成的 AI Agent 项目。

比起“会 Python”或“熟悉某种技术栈”，这个作品更直观地呈现了他的审美、产品理解和解决问题的方式。

这一次，310 家公司的创始人也会来到墙上，从这些具体而鲜活的信息中，挖掘“野生人才”。

找工作不该是一遍遍猜测 HRBP 喜欢什么关键词，也不该要求每个人把自己压缩成一份标准答案。 **在自荐墙上，你可以坦然地说：这就是我做过的事情，这就是现在的我。**

![图片](https://mmecoa.qpic.cn/mmecoa_jpg/zvZg7aSY4dPqSuFMBE6EgjA61ic8S9AMOOr3o45WFVL2ThbOZcjfOMjNqk8zWW5JrX2jhzx2EJicXGwlV3wO9rQudyicxyXq5ZN6ia0d1ibK5fu8/640?wx_fmt=jpeg&from=appmsg&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=4)

参与方法很简单，三步就能上墙：

**第一步：进入 Bonjour 自荐墙**

进入 Bonjour 网页版 [https://bonjour.bio/open](https://bonjour.bio/open) ，侧边栏即可看到自荐墙入口。

![图片](https://mmecoa.qpic.cn/sz_mmecoa_png/zvZg7aSY4dPBCYiaiceXmlQxpAk7JsF9ShGBicEEpgkOJYwNHMiaOTdAlzibyJGm0TCW0vrn4FNfxmnJibgMjIPE6hpibGNRnkUWhYug2DnxCelEiaQ/640?wx_fmt=png&from=appmsg&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=5)

**第二步：发布你的帖子**

选一种最顺手的方式介绍自己就好。可以写几句最近的状态，也可以放上一张 GitHub 截图或一个作品链接。最后告诉大家你正在寻找怎样的机会，

不知道怎么写，可以直接使用这份模板：

👋你好，我是 \_\_\_\_\_\_。

最近在做，或最想分享的一件事是 \_\_\_\_\_\_。

想进一步认识我，可以看 \_\_\_\_\_\_。

接下来，我想寻找 \_\_\_\_\_\_。

![图片](https://mmecoa.qpic.cn/sz_mmecoa_jpg/zvZg7aSY4dMbKS84ZLmoVKUjbu4ttx5uBSkqBDMKRTB8wYEu6wJjopablIjx7thC5DfvZhzKrk9WceIdNyMLZicSAqicDKyANV9y6TCloqpgI/640?wx_fmt=jpeg&from=appmsg#imgIndex=6)

**第三步：等待一次真实的连接**

帖子发布后，就会出现在找工墙上，

社区里的成员可以留言、转发或帮你牵线，

参与活动的公司也会来到这里浏览和联系感兴趣的人。

![图片](https://mmecoa.qpic.cn/mmecoa_jpg/zvZg7aSY4dMNuf2OPdic5za07yZPuibu5gIbBTngVRuo550ZYiaJicZH1bOrv4ib6hicVIkxRV7d4oenFPmEg4aASpAvhlNUht9FyDqvAmo4VSqrI/640?wx_fmt=jpeg&from=appmsg#imgIndex=7)

第一批帖子已经出现在找工墙上。

这里没有统一格式，每个人介绍自己的方式都不太一样。但一个真实的片段，就足够让我们开始链接一个人。

下面这些朋友已经上墙了， **欢迎点开他们的帖子，看看他们做过什么。如果刚好遇到感兴趣的人，也可以留下一条回复，和他聊聊👋。**

你也可能有这样一位朋友，TA 很会工作，能力超强，但却不太擅长介绍自己。他们可能还在沉浸式地做自己的项目，但从没想过把自己的经历放到公开的地方。

**如果你想到了这样一个人，可以邀请 TA 来到找工墙。** 你也可以引用他在 Bonjour 社区发布过的内容，贴到找工墙上，说说你们一起做过什么，以及为什么喜欢和这个人合作。一段来自真实合作者的评价，有时比完整的履历更容易让人记住。

**不用等到一切都准备好，只需要一篇帖子就会让社区知道，你正在寻找新的可能。**

310 家正在招聘的公司也会来到这里，沿着作品和介绍认识你。offer 不一定会立刻到来，但一次新的交流可能会率先发生。

也许你会做的事情刚好是有人需要协助的，也许会有一位社区朋友愿意替你牵线……种种可能性，都藏在那个发布键之下。
