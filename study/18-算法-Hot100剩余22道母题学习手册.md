# 三、二叉树

## 母题 36｜104. 二叉树的最大深度【B】

### 题意

返回从根节点到最远叶子节点所经过的节点数；空树深度为 0。

### 先自己思考

1. 空节点应该返回多少？
2. 当前树的深度与左右子树深度有什么关系？
3. 递归函数 `max_depth(node)` 的返回值是什么？
4. 递归栈空间取决于节点数还是树高？

### 逐步答案

1. 暴力并不复杂，本题本质就是遍历整棵树。
2. 到达最深叶子的路径只能经过左子树或右子树，选择较深的一侧。
3. 定义递归契约：`max_depth(node)` 返回以 `node` 为根的子树最大深度。
4. 空节点深度为 0；非空节点深度为 `1 + max(left, right)`。

```python
def max_depth(root):
    if root is None:
        return 0

    left_depth = max_depth(root.left)
    right_depth = max_depth(root.right)
    return 1 + max(left_depth, right_depth)
```

- 时间：`O(n)`，每个节点访问一次。
- 空间：`O(h)`；平衡树为 `O(log n)`，退化链为 `O(n)`。
- 易错点：最大深度按节点数计算；空树不是 1。
- 恢复脚本：**空树为零，左右取大，再加当前一层。**

## 母题 37｜226. 翻转二叉树【B】

### 题意

将每个节点的左右子树交换，返回翻转后的根节点。

### 先自己思考

1. 只交换根节点左右孩子为什么不够？
2. 递归函数应该返回什么？
3. 交换前是否需要保存原来的左右子树？
4. 空树和单节点树如何处理？

### 逐步答案

1. 每个节点都要执行同一种“交换左右子树”操作，因此适合递归。
2. 定义 `invert(node)`：翻转以 `node` 为根的整棵子树，并返回其根。
3. 可以用 Python 同时赋值，右侧表达式会先求值，不会丢失原指针。

```python
def invert_tree(root):
    if root is None:
        return None

    root.left, root.right = (
        invert_tree(root.right),
        invert_tree(root.left),
    )
    return root
```

- 时间：`O(n)`；空间：`O(h)`。
- 易错点：不能只交换一层；返回值仍是原根节点对象。
- 恢复脚本：**空则返回；递归翻右作左，递归翻左作右。**

## 母题 38｜101. 对称二叉树【B】

### 题意

判断一棵树是否关于根节点中心轴镜像对称。

### 先自己思考

1. 镜像比较的是哪两对孩子？
2. 两个节点都为空、只有一个为空时分别返回什么？
3. 只比较当前两个值是否足够？
4. `mirror(left, right)` 的递归契约是什么？

### 逐步答案

1. 镜像关系不是“左对左、右对右”，而是“外侧对外侧、内侧对内侧”。
2. 定义 `mirror(a, b)`：判断两棵树是否互为镜像。
3. 两者都空为真；只有一者空为假；值不同为假。
4. 值相同后继续比较 `a.left` 与 `b.right`、`a.right` 与 `b.left`。

```python
def is_symmetric(root):
    def mirror(left, right):
        if left is None and right is None:
            return True
        if left is None or right is None:
            return False
        if left.val != right.val:
            return False

        return (
            mirror(left.left, right.right)
            and mirror(left.right, right.left)
        )

    return mirror(root.left, root.right) if root else True
```

- 时间：`O(n)`；空间：`O(h)`，最坏 `O(n)`。
- 易错点：必须交叉比较；两个空节点是对称的。
- 恢复脚本：**同空真、单空假、值不同假；外对外、内对内。**

## 母题 39｜543. 二叉树的直径【A】

### 题意

求任意两个节点之间最长路径的边数，路径不一定经过根节点。

### 先自己思考

1. 经过当前节点的最长路径由哪两部分构成？
2. 递归向父节点能同时返回左右两条路径吗？
3. 为什么需要一个全局答案？
4. 空节点深度取 0 时，直径如何按边数计算？

### 逐步答案

1. 对每个节点，经过它的路径长度是左子树向下深度加右子树向下深度。
2. 父节点只能接其中较长的一侧，否则路径会分叉，不再是一条简单路径。
3. 最长路径可能出现在任意子树，所以后序遍历每个节点并更新全局最大值。
4. 定义 `depth(node)` 返回从当前节点向下的最大节点深度；局部直径直接为 `left + right` 条边。

```python
def diameter_of_binary_tree(root):
    best = 0

    def depth(node):
        nonlocal best
        if node is None:
            return 0

        left = depth(node.left)
        right = depth(node.right)
        best = max(best, left + right)

        return 1 + max(left, right)

    depth(root)
    return best
```

- 时间：`O(n)`；空间：`O(h)`。
- 易错点：全局直径与向上返回值含义不同；答案按边数，不额外加 1。
- 恢复脚本：**后序求左右深度；左右相加更新直径；向上只交较长一侧。**

## 母题 40｜102. 二叉树的层序遍历【A】

### 题意

从上到下逐层输出节点值，每层形成一个数组。

### 先自己思考

1. 为什么使用队列而不是栈？
2. 一轮开始时怎样知道当前层有多少节点？
3. 本轮新加入的孩子为什么不会混入当前层？
4. 空树返回什么？

### 逐步答案

1. 按距离根节点从近到远访问是 BFS，使用先进先出队列。
2. 每轮开始记录 `level_size = len(queue)`，只弹出这批节点。
3. 孩子加入队尾，留给下一轮处理。
4. 不变量：一轮开始时，队列中现有节点恰好属于当前层。

```python
from collections import deque


def level_order(root):
    if root is None:
        return []

    result = []
    queue = deque([root])

    while queue:
        level = []
        level_size = len(queue)

        for _ in range(level_size):
            node = queue.popleft()
            level.append(node.val)

            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)

        result.append(level)

    return result
```

- 时间：`O(n)`；空间：`O(w)`，`w` 为树的最大宽度，最坏 `O(n)`。
- 易错点：必须在本轮开始固定层大小；空树返回空列表。
- 恢复脚本：**根入队；固定本层长度；出队收集，孩子入队。**

## 母题 41｜108. 将有序数组转换为二叉搜索树【C】

### 题意

将升序数组转换为一棵高度平衡的二叉搜索树。

### 先自己思考

1. 为什么选择中间元素作为根？
2. 左右子数组分别构成什么？
3. 递归区间采用闭区间还是左闭右开？
4. 偶数长度时选左中点或右中点有影响吗？

### 逐步答案

1. 有序数组的中点能让左右元素数量尽量接近，天然满足平衡要求。
2. 中点左侧全部小于根，构成左子树；右侧构成右子树。
3. 定义 `build(left, right)` 构造闭区间 `[left, right]`。

```python
def sorted_array_to_bst(nums):
    def build(left, right):
        if left > right:
            return None

        mid = (left + right) // 2
        root = TreeNode(nums[mid])
        root.left = build(left, mid - 1)
        root.right = build(mid + 1, right)
        return root

    return build(0, len(nums) - 1)
```

- 时间：`O(n)`；空间：`O(log n)` 递归栈，不计结果树。
- 易错点：区间规则必须统一；答案不唯一。
- 恢复脚本：**有序取中作根，左段建左，右段建右。**

## 母题 42｜98. 验证二叉搜索树【A】

### 题意

判断整棵树是否满足：任意节点左子树所有值严格小于它，右子树所有值严格大于它。

### 先自己思考

1. 为什么只比较父节点和直接孩子不够？
2. 祖先节点如何限制当前节点的取值范围？
3. BST 是否允许重复值？
4. 递归函数应该携带什么状态？

### 逐步答案

1. 左子树深处的节点不仅受父节点限制，还受所有祖先限制。
2. 为每个节点传递合法开区间 `(low, high)`。
3. 进入左子树把上界收紧为当前值；进入右子树把下界收紧为当前值。

```python
def is_valid_bst(root):
    def valid(node, low, high):
        if node is None:
            return True

        if not (low < node.val < high):
            return False

        return (
            valid(node.left, low, node.val)
            and valid(node.right, node.val, high)
        )

    return valid(root, float("-inf"), float("inf"))
```

- 时间：`O(n)`；空间：`O(h)`。
- 易错点：严格不等，重复值非法；不能只检查直接父子关系。
- 恢复脚本：**祖先传上下界；左收上界，右收下界；越界立即假。**

## 母题 43｜230. 二叉搜索树中第 K 小的元素【B】

### 题意

在 BST 中返回按值升序排列后的第 `k` 个元素。

### 先自己思考

1. BST 的哪种遍历天然得到升序序列？
2. 是否必须保存完整遍历结果？
3. 迭代中序时栈保存的是什么？
4. 什么时候停止？

### 逐步答案

1. BST 中序遍历是升序。
2. 不需要保存所有值，每弹出一个节点就把 `k` 减 1，减到 0 立即返回。
3. 栈保存尚未访问、但左侧路径已经展开的祖先节点。

```python
def kth_smallest(root, k):
    stack = []
    current = root

    while current or stack:
        while current:
            stack.append(current)
            current = current.left

        current = stack.pop()
        k -= 1
        if k == 0:
            return current.val

        current = current.right
```

- 时间：最坏 `O(n)`，通常访问到第 `k` 小即停止；空间 `O(h)`。
- 易错点：`k` 从 1 开始；外层条件是 `current or stack`。
- 恢复脚本：**BST 中序升序；沿左入栈，弹出计数，第 K 个返回。**

## 母题 44｜199. 二叉树的右视图【B】

### 题意

从树的右侧观察，返回从上到下每层能看到的节点值。

### 先自己思考

1. 每层答案是哪一个节点？
2. 使用 BFS 时如何识别每层最后一个节点？
3. 使用 DFS 时为什么应先访问右子树？
4. 空树如何处理？

### 逐步答案

1. BFS 每层从左到右遍历，最后一个节点就是右视图节点。
2. 固定本层长度，当循环下标等于 `level_size - 1` 时记录。

```python
from collections import deque


def right_side_view(root):
    if root is None:
        return []

    result = []
    queue = deque([root])

    while queue:
        level_size = len(queue)

        for index in range(level_size):
            node = queue.popleft()
            if index == level_size - 1:
                result.append(node.val)

            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)

    return result
```

- 时间：`O(n)`；空间：`O(w)`。
- 易错点：右视图不一定都是沿 `right` 指针形成；某层没有右孩子时仍可能看到左侧节点。
- 恢复脚本：**层序固定长度，每层记录最后一个。**

## 母题 45｜114. 二叉树展开为链表【C】

### 题意

原地把二叉树展开成只使用 `right` 指针的链表，顺序与前序遍历一致。

### 先自己思考

1. 前序遍历顺序是什么？
2. 若直接先处理左子树，怎样保存原右子树？
3. 反向按照“右—左—根”处理能否简化连接？
4. 处理完一个节点后，`left` 应该是什么？

### 逐步答案

1. 最终顺序是“根—左—右”。
2. 反向构造：先处理右子树，再处理左子树，维护已经展开好的后继链表头 `previous`。
3. 当前节点的 `right` 指向 `previous`，`left` 置空，再让 `previous = node`。

```python
def flatten(root):
    previous = None

    def dfs(node):
        nonlocal previous
        if node is None:
            return

        dfs(node.right)
        dfs(node.left)

        node.right = previous
        node.left = None
        previous = node

    dfs(root)
```

- 时间：`O(n)`；空间：`O(h)`。
- 易错点：必须先递归右再递归左；必须清空所有 `left`。
- 恢复脚本：**前序链表反向构造：右、左、根；当前右接 previous，左置空。**

## 母题 46｜105. 从前序与中序遍历构造二叉树【A】

### 题意

节点值互不相同，根据前序和中序遍历结果重建二叉树。

### 先自己思考

1. 前序序列的第一个未消费元素表示什么？
2. 根节点在中序序列中的位置能确定什么？
3. 为什么建立“值到中序下标”的哈希表？
4. 为什么必须先构造左子树再构造右子树？

### 逐步答案

1. 前序顺序为“根—左—右”，所以每次取下一个前序值作为当前根。
2. 根在中序中的位置将区间切成左右子树。
3. 哈希表让定位根下标从 `O(n)` 降为 `O(1)`，总复杂度从最坏 `O(n²)` 降为 `O(n)`。
4. 前序游标接下来先消费左子树节点。

```python
def build_tree(preorder, inorder):
    index = {value: i for i, value in enumerate(inorder)}
    preorder_index = 0

    def build(left, right):
        nonlocal preorder_index
        if left > right:
            return None

        root_value = preorder[preorder_index]
        preorder_index += 1

        root = TreeNode(root_value)
        middle = index[root_value]
        root.left = build(left, middle - 1)
        root.right = build(middle + 1, right)
        return root

    return build(0, len(inorder) - 1)
```

- 时间：`O(n)`；空间：`O(n)`，包含哈希表与递归栈。
- 易错点：先左后右；区间开闭规则一致；题目依赖节点值唯一。
- 恢复脚本：**前序取根，中序切段；前序游标先建左，再建右。**

## 母题 47｜437. 路径总和 III【B】

### 题意

统计和为 `target` 的向下路径数量。路径可从任意节点开始，但只能从父节点走向子节点。

### 先自己思考

1. 对当前根到当前节点的前缀和 `current`，怎样判断某段路径和为 `target`？
2. 为什么需要记录同一个前缀和出现的次数，而不是是否出现？
3. 为什么进入子树前要加入当前前缀和，离开时又要删除？
4. `prefix_count[0]` 为什么初始化为 1？

### 逐步答案

1. 若祖先路径前缀和为 `current - target`，从其下一节点到当前节点的路径和就是 `target`。
2. 不同祖先可能具有相同前缀和，每一个都对应一条合法路径。
3. DFS 的哈希表只应表示当前根到当前节点这条路径；回溯时撤销，避免把兄弟分支拼成非法路径。
4. `{0: 1}` 允许从根开始的路径被统计。

```python
from collections import defaultdict


def path_sum(root, target):
    prefix_count = defaultdict(int)
    prefix_count[0] = 1

    def dfs(node, current_sum):
        if node is None:
            return 0

        current_sum += node.val
        count = prefix_count[current_sum - target]

        prefix_count[current_sum] += 1
        count += dfs(node.left, current_sum)
        count += dfs(node.right, current_sum)
        prefix_count[current_sum] -= 1

        return count

    return dfs(root, 0)
```

- 时间：`O(n)`；空间：`O(h)`，最坏 `O(n)`。
- 易错点：先查询再加入当前前缀；递归返回前必须撤销；不能使用普通滑动窗口，因为节点值可能为负。
- 恢复脚本：**树上前缀和：查 current-target，加入当前，递归左右，离开撤销。**

### 题意

### 先自己思考

1. 当前节点等于 `p` 或 `q` 时应该返回什么？
2. 左右子树都返回非空意味着什么？
3. 只有一侧返回非空时怎样向上传递？
4. 递归函数返回的是“是否找到”，还是候选节点？

### 逐步答案

1. 定义 `dfs(node)` 返回：当前子树中发现的 `p`、`q` 或它们的公共祖先；没有则返回空。
2. 当前节点是目标之一时直接返回当前节点。
3. 左右都非空，说明两个目标分处两侧，当前节点就是最近公共祖先。
4. 只有一侧非空，原样向上传递该候选。

```python
def lowest_common_ancestor(root, p, q):
    if root is None or root is p or root is q:
        return root

    left = lowest_common_ancestor(root.left, p, q)
    right = lowest_common_ancestor(root.right, p, q)

    if left and right:
        return root
    return left if left else right
```

- 时间：`O(n)`；空间：`O(h)`。
- 易错点：比较节点身份，不只比较值；一个目标可以是另一个目标的祖先。
- 恢复脚本：**遇目标返回；左右汇合当前即祖先；单边非空向上传。**

## 母题 49｜124. 二叉树中的最大路径和【B】

### 题意

求二叉树任意非空路径的最大节点值之和。路径可从任意节点开始和结束，但不能重复经过节点。

### 先自己思考

1. 经过当前节点的完整路径可以使用左右两侧吗？
2. 向父节点返回的路径可以同时使用左右两侧吗？
3. 子树贡献为负时是否应该选择它？
4. 为什么全局答案不能初始化为 0？

### 逐步答案

1. 完整候选路径可以是“左侧最大向下贡献 + 当前值 + 右侧最大向下贡献”。
2. 向父节点返回时只能选择一侧，否则会形成分叉。
3. 负贡献不如不选，因此取 `max(gain, 0)`。
4. 所有节点都为负时答案仍必须选择一个节点，所以全局答案初始化为负无穷。

```python
def max_path_sum(root):
    best = float("-inf")

    def gain(node):
        nonlocal best
        if node is None:
            return 0

        left_gain = max(gain(node.left), 0)
        right_gain = max(gain(node.right), 0)

        best = max(best, node.val + left_gain + right_gain)
        return node.val + max(left_gain, right_gain)

    gain(root)
    return best
```

- 时间：`O(n)`；空间：`O(h)`。
- 易错点：全局候选可取两侧，向上返回只能取一侧；全负数组不能把 `best` 初始化为 0。
- 恢复脚本：**后序算非负贡献；左右加根更新全局；向上只带较大一侧。**

## 母题 50｜200. 岛屿数量【A】

### 题意

网格中 `"1"` 表示陆地、`"0"` 表示水，上下左右相邻陆地属于同一岛屿，统计岛屿数。

### 先自己思考

1. 扫描到一块未访问陆地时，为什么可以确定发现了一个新岛屿？
2. 怎样把整个岛屿标记为已访问？
3. 可以原地修改网格吗？如果不能怎么办？
4. 递归 DFS 的最坏栈空间是多少？

### 逐步答案

1. 逐格扫描；若当前仍是 `"1"`，说明它尚未被之前岛屿的遍历覆盖，因此岛屿数加 1。
2. 从该格开始 DFS/BFS，把同一连通分量中的所有 `"1"` 改为 `"0"`。
3. 不变量：扫描过的位置中，每座已计数岛屿都已被完整淹没，后续不会重复计数。

```python
def num_islands(grid):
    if not grid or not grid[0]:
        return 0

    rows, cols = len(grid), len(grid[0])

    def dfs(row, col):
        if (
            row < 0 or row >= rows
            or col < 0 or col >= cols
            or grid[row][col] != "1"
        ):
            return

        grid[row][col] = "0"
        dfs(row + 1, col)
        dfs(row - 1, col)
        dfs(row, col + 1)
        dfs(row, col - 1)

    count = 0
    for row in range(rows):
        for col in range(cols):
            if grid[row][col] == "1":
                count += 1
                dfs(row, col)

    return count
```

- 时间：`O(mn)`；空间：最坏 `O(mn)` 递归栈。
- 易错点：只允许上下左右，不含对角；若不能修改输入，使用 `visited` 集合。
- 恢复脚本：**遇未淹没陆地就计数；从它出发淹没整个连通块。**

## 母题 51｜994. 腐烂的橘子【A】

### 题意

所有腐烂橘子每分钟同时感染相邻新鲜橘子，求全部腐烂的最少分钟；无法完成返回 `-1`。

### 先自己思考

1. 为什么必须把所有初始腐烂橘子同时入队？
2. 怎样保证“一轮 BFS”恰好代表一分钟？
3. 为什么要统计新鲜橘子数量？
4. 没有新鲜橘子时应返回多少？

### 逐步答案

1. 这是多个起点同时扩散的最短时间问题，使用多源 BFS。
2. 初始扫描时把全部腐烂橘子入队并统计 `fresh`。
3. 每轮固定队列长度，只传播这一层；每感染一个新鲜橘子就令 `fresh -= 1`。
4. 只有确实发生新一轮传播时分钟数才增加。

```python
from collections import deque


def oranges_rotting(grid):
    rows, cols = len(grid), len(grid[0])
    queue = deque()
    fresh = 0

    for row in range(rows):
        for col in range(cols):
            if grid[row][col] == 2:
                queue.append((row, col))
            elif grid[row][col] == 1:
                fresh += 1

    minutes = 0
    directions = ((1, 0), (-1, 0), (0, 1), (0, -1))

    while queue and fresh > 0:
        for _ in range(len(queue)):
            row, col = queue.popleft()

            for dr, dc in directions:
                nr, nc = row + dr, col + dc
                if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == 1:
                    grid[nr][nc] = 2
                    fresh -= 1
                    queue.append((nr, nc))

        minutes += 1

    return minutes if fresh == 0 else -1
```

- 时间：`O(mn)`；空间：`O(mn)`。
- 易错点：必须是多源 BFS；没有新鲜橘子应返回 0；感染时立即标记，避免重复入队。
- 恢复脚本：**烂橘全入队，新鲜计数；分层扩散一分钟；最后看 fresh 是否归零。**

## 母题 52｜207. 课程表【A】

### 题意

给定课程先修关系 `[course, prerequisite]`，判断是否能完成全部课程。

### 先自己思考

1. 无法完成全部课程的本质是什么？
2. 有向边应该从先修课指向后续课，还是相反？
3. 入度为 0 的课程代表什么？
4. 如何根据最终处理数量判断是否存在环？

### 逐步答案

1. 先修关系形成有向图；存在环就没有合法学习顺序。
2. 建边 `prerequisite -> course`，并增加 `course` 的入度。
3. 所有入度为 0 的课程可以立即学习，加入队列。
4. 每完成一门课，就删除其出边；新出现的入度 0 节点入队。最终完成数等于课程总数才无环。

```python
from collections import deque


def can_finish(num_courses, prerequisites):
    graph = [[] for _ in range(num_courses)]
    indegree = [0] * num_courses

    for course, prerequisite in prerequisites:
        graph[prerequisite].append(course)
        indegree[course] += 1

    queue = deque(
        course for course in range(num_courses)
        if indegree[course] == 0
    )
    completed = 0

    while queue:
        prerequisite = queue.popleft()
        completed += 1

        for course in graph[prerequisite]:
            indegree[course] -= 1
            if indegree[course] == 0:
                queue.append(course)

    return completed == num_courses
```

- 时间：`O(V+E)`；空间：`O(V+E)`。
- 易错点：边方向和入度对象要匹配；孤立课程的入度也是 0。
- 恢复脚本：**先修指向后课；零入度入队；逐边减度；处理满 V 则无环。**

## 母题 53｜208. 实现 Trie 前缀树【C】

### 题意

实现 `insert(word)`、`search(word)` 和 `startsWith(prefix)`。

### 先自己思考

1. 为什么普通哈希集合不能高效共享前缀？
2. Trie 节点至少保存什么？
3. `search` 和 `startsWith` 的区别在哪里？
4. 为什么必须记录单词结束标记？

### 逐步答案

1. Trie 把每个字符作为一条边，相同前缀共享同一段路径。
2. 每个节点保存“字符到子节点”的映射和 `is_end`。
3. 两种查询都先沿字符路径行走；`startsWith` 只要求路径存在，`search` 还要求终点是完整单词。

```python
class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_end = False


class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word):
        node = self.root
        for char in word:
            if char not in node.children:
                node.children[char] = TrieNode()
            node = node.children[char]
        node.is_end = True

    def _find(self, text):
        node = self.root
        for char in text:
            if char not in node.children:
                return None
            node = node.children[char]
        return node

    def search(self, word):
        node = self._find(word)
        return node is not None and node.is_end

    def startsWith(self, prefix):
        return self._find(prefix) is not None
```

- 单次操作时间：`O(L)`；空间：所有新建字符节点总数。
- 易错点：路径存在不代表完整单词存在；不要忘记 `is_end`。
- 恢复脚本：**字符逐层走；插入建缺失边并标终点；查词还验终点，查前缀只验路径。**

### 题意

1. 每一层递归决定排列中的哪个位置？
2. 怎样避免同一个元素在一条路径中重复使用？
3. 为什么收集答案时必须复制 `path`？
4. 什么时候得到一个完整排列？

### 逐步答案

1. 第 `depth` 层决定排列下标 `depth` 放哪个尚未使用的元素。
2. 用 `used[i]` 记录当前路径是否已经使用下标 `i`。
3. `path` 会继续修改，必须保存快照。

```python
def permute(nums):
    result = []
    path = []
    used = [False] * len(nums)

    def backtrack():
        if len(path) == len(nums):
            result.append(path.copy())
            return

        for index, value in enumerate(nums):
            if used[index]:
                continue

            used[index] = True
            path.append(value)
            backtrack()
            path.pop()
            used[index] = False

    backtrack()
    return result
```

- 时间：`O(n·n!)`，复制每个排列需要 `O(n)`；空间：`O(n)`，不计答案。
- 易错点：收集 `path.copy()`；撤销顺序与选择相反。
- 恢复脚本：**每层填一位；枚举未用元素；选择、递归、撤销；长度 n 收集。**

## 母题 57｜39. 组合总和【A】

### 题意

### 先自己思考

1. 怎样允许重复使用当前数？
2. 怎样避免 `[2,3]` 和 `[3,2]` 重复？
3. 候选数为正带来什么剪枝？
4. 递归状态应该保存当前和还是剩余目标？

### 逐步答案

1. 用 `start` 保证组合按候选下标非递减选择。
2. 选择 `candidates[index]` 后，下一层仍从 `index` 开始，允许重复使用。
3. 先排序；当前值大于剩余目标时，后续更大值都无需尝试。

```python
def combination_sum(candidates, target):
    candidates.sort()
    result = []
    path = []

    def backtrack(start, remaining):
        if remaining == 0:
            result.append(path.copy())
            return

        for index in range(start, len(candidates)):
            value = candidates[index]
            if value > remaining:
                break

            path.append(value)
            backtrack(index, remaining - value)
            path.pop()

    backtrack(0, target)
    return result
```

- 时间：指数级，取决于候选和目标；空间：递归最深约 `target/min(candidates)`。
- 易错点：重复使用传 `index`，不是 `index+1`；正数排序后才能安全 `break`。
- 恢复脚本：**start 防乱序；选后仍从自己开始；剩余为零收集，大于剩余剪枝。**

## 母题 58｜22. 括号生成【B】

### 题意

生成由 `n` 对括号组成的所有合法字符串。

### 先自己思考

1. 什么情况下可以放左括号？
2. 什么情况下可以放右括号？
3. 为什么只需保证任意前缀中右括号数不超过左括号数？
4. 什么时候形成完整答案？

### 逐步答案

1. 已使用左括号数小于 `n` 时可以放 `(`。
2. 已使用右括号数小于左括号数时才可放 `)`，保证任何前缀都不会非法。
3. 长度达到 `2n` 时收集。

```python
def generate_parenthesis(n):
    result = []
    path = []

    def backtrack(open_count, close_count):
        if len(path) == 2 * n:
            result.append("".join(path))
            return

        if open_count < n:
            path.append("(")
            backtrack(open_count + 1, close_count)
            path.pop()

        if close_count < open_count:
            path.append(")")
            backtrack(open_count, close_count + 1)
            path.pop()

    backtrack(0, 0)
    return result
```

- 时间：与合法答案数量（卡特兰数）及字符串长度同阶；空间：`O(n)`，不计答案。
- 易错点：右括号条件是 `close < open`；不是生成全部 `2^(2n)` 后再过滤。
- 恢复脚本：**左未满可加左，右少于左可加右，长度 2n 收集。**

## 母题 59｜79. 单词搜索【A】

### 题意

判断字符网格中是否存在一条上下左右路径拼出目标单词；同一格在一条路径中不能重复使用。

### 先自己思考

1. DFS 状态至少包含哪些信息？
2. 当前格字符不匹配时为什么立即失败？
3. 怎样避免同一路径重复使用格子？
4. 为什么递归返回后必须恢复字符？

### 逐步答案

1. `dfs(row, col, index)` 表示从当前格开始匹配 `word[index:]`。
2. 越界或字符不等立即失败；匹配到最后一个字符立即成功。
3. 进入格子后临时标记为特殊字符，探索四邻；若失败再恢复，供其他起点和路径使用。

```python
def exist(board, word):
    rows, cols = len(board), len(board[0])

    def dfs(row, col, index):
        if (
            row < 0 or row >= rows
            or col < 0 or col >= cols
            or board[row][col] != word[index]
        ):
            return False

        if index == len(word) - 1:
            return True

        original = board[row][col]
        board[row][col] = "#"

        found = (
            dfs(row + 1, col, index + 1)
            or dfs(row - 1, col, index + 1)
            or dfs(row, col + 1, index + 1)
            or dfs(row, col - 1, index + 1)
        )

        board[row][col] = original
        return found

    for row in range(rows):
        for col in range(cols):
            if board[row][col] == word[0] and dfs(row, col, 0):
                return True

    return False
```

- 时间：最坏 `O(mn·4^L)`，更紧可写 `O(mn·3^L)`；空间：`O(L)`。
- 易错点：成功或失败都要保证输入状态可接受；同一路径不可复用，但不同路径可以复用格子。
- 恢复脚本：**每格作起点；匹配、标记、探四邻、恢复；走完单词成功。**

## 母题 60｜131. 分割回文串【B】

### 题意

把字符串分割成若干子串，使每段都是回文串，返回所有方案。

### 先自己思考

1. 每层递归决定哪一个切割点？
2. 什么子串才允许加入路径？
3. `start == len(s)` 表示什么？
4. 直接判断回文会产生什么复杂度？

### 逐步答案

1. `start` 表示下一段从哪里开始；枚举结束位置 `end`。
2. 仅当 `s[start:end+1]` 是回文时，才选择该段并递归处理后缀。
3. `start` 到末尾说明整个字符串已被合法切完。

```python
def partition(s):
    result = []
    path = []

    def is_palindrome(left, right):
        while left < right:
            if s[left] != s[right]:
                return False
            left += 1
            right -= 1
        return True

    def backtrack(start):
        if start == len(s):
            result.append(path.copy())
            return

        for end in range(start, len(s)):
            if not is_palindrome(start, end):
                continue

            path.append(s[start:end + 1])
            backtrack(end + 1)
            path.pop()

    backtrack(0)
    return result
```

- 时间：最坏 `O(n·2^n)` 到 `O(n²·2^n)`，取决于回文判断与复制；空间：`O(n)`，不计答案。
- 易错点：切割后从 `end+1` 继续；只有走到字符串末尾才收集。
- 恢复脚本：**从 start 枚举 end；当前段回文才选择；后缀递归；末尾收集。**

## 母题 61｜51. N 皇后【C】

### 题意

在 `n×n` 棋盘放置 `n` 个皇后，使任意两个皇后不同行、不同列、不同对角线，返回全部布局。

### 先自己思考

1. 为什么按行递归后不再需要记录“已用行”？
2. 主对角线和副对角线可以分别用什么表达式标识？
3. 每层有哪些候选选择？
4. 怎样在返回时撤销三个约束集合？

### 逐步答案

1. 第 `row` 层固定在这一行放一个皇后，只需枚举列。
2. 同一主对角线满足 `row-col` 相同；同一副对角线满足 `row+col` 相同。
3. 使用三个集合记录已占列和两类对角线。

```python
def solve_n_queens(n):
    result = []
    board = [["."] * n for _ in range(n)]
    columns = set()
    diagonals1 = set()  # row - col
    diagonals2 = set()  # row + col

    def backtrack(row):
        if row == n:
            result.append(["".join(line) for line in board])
            return

        for col in range(n):
            diagonal1 = row - col
            diagonal2 = row + col
            if (
                col in columns
                or diagonal1 in diagonals1
                or diagonal2 in diagonals2
            ):
                continue

            board[row][col] = "Q"
            columns.add(col)
            diagonals1.add(diagonal1)
            diagonals2.add(diagonal2)

            backtrack(row + 1)

            board[row][col] = "."
            columns.remove(col)
            diagonals1.remove(diagonal1)
            diagonals2.remove(diagonal2)

    backtrack(0)
    return result
```

- 时间：上界约 `O(n!)`；空间：`O(n)` 约束与递归，不计棋盘和答案。
- 易错点：两种对角线标识不要混淆；收集棋盘时要生成字符串快照。
- 恢复脚本：**一层一行，枚举列；列、差、和都未占才放；递归后全撤销。**

```python
def search_insert(nums, target):
```

## 母题 63｜74. 搜索二维矩阵【B】

### 题意

矩阵每行升序，且下一行首元素大于上一行尾元素，判断目标是否存在。

### 先自己思考

1. 整个矩阵能否看成一个升序一维数组？
2. 一维下标 `mid` 怎样映射为行列？
3. 总元素数是多少？
4. 空矩阵如何处理？

### 逐步答案

1. 题目保证跨行也严格有序，因此可在长度 `rows*cols` 的虚拟数组上二分。
2. `row = mid // cols`，`col = mid % cols`。

```python
def search_matrix(matrix, target):
    if not matrix or not matrix[0]:
        return False

    rows, cols = len(matrix), len(matrix[0])
    left, right = 0, rows * cols - 1

    while left <= right:
        mid = (left + right) // 2
        value = matrix[mid // cols][mid % cols]

        if value == target:
            return True
        if value < target:
            left = mid + 1
        else:
            right = mid - 1

    return False
```

- 时间：`O(log(mn))`；空间：`O(1)`。
- 易错点：本题条件比“每行每列有序”更强；行列映射的除数是列数。
- 恢复脚本：**矩阵虚拟拉平；mid 除列得行、模列得列。**

## 母题 64｜34. 查找第一个和最后一个位置【A】

### 题意

在非递减数组中返回 `target` 的第一次和最后一次出现位置，不存在返回 `[-1,-1]`。

### 先自己思考

1. 左边界是第一个满足什么条件的位置？
2. 右边界能否转化为“第一个大于 target 的位置减 1”？
3. 左边界找到后怎样确认目标确实存在？
4. 为什么不建议用 `target + 1` 代替上界查找？

### 逐步答案

1. `lower_bound(target)` 找第一个 `>= target`。
2. `upper_bound(target)` 找第一个 `> target`，答案右端为其减 1。
3. 若左边界越界或对应值不等于目标，直接返回不存在。

```python
def search_range(nums, target):
    def lower_bound(value):
        left, right = 0, len(nums)
        while left < right:
            mid = (left + right) // 2
            if nums[mid] >= value:
                right = mid
            else:
                left = mid + 1
        return left

    def upper_bound(value):
        left, right = 0, len(nums)
        while left < right:
            mid = (left + right) // 2
            if nums[mid] > value:
                right = mid
            else:
                left = mid + 1
        return left

    first = lower_bound(target)
    if first == len(nums) or nums[first] != target:
        return [-1, -1]

    return [first, upper_bound(target) - 1]
```

- 时间：`O(log n)`；空间：`O(1)`。
- 易错点：确认左边界对应值；右端是第一个 `>` 的位置减一。
- 恢复脚本：**左找首个 ≥，右找首个 > 再减一；左端验存在。**

## 母题 65｜33. 搜索旋转排序数组【A】

### 题意

互不重复的升序数组旋转后，在 `O(log n)` 时间内查找目标下标。

### 先自己思考

1. 每次二分后，左右两半至少有什么性质？
2. 怎样判断左半段有序？
3. 左半有序时，目标落入左半的边界条件是什么？
4. 元素允许重复时当前判断还可靠吗？

### 逐步答案

1. 旋转数组在任意 `mid` 处分开，至少一半仍然有序。
2. 若 `nums[left] <= nums[mid]`，左半有序。
3. 左半有序且 `nums[left] <= target < nums[mid]` 时保留左半；否则保留右半。右半情况对称。

```python
def search_rotated(nums, target):
    left, right = 0, len(nums) - 1

    while left <= right:
        mid = (left + right) // 2
        if nums[mid] == target:
            return mid

        if nums[left] <= nums[mid]:
            if nums[left] <= target < nums[mid]:
                right = mid - 1
            else:
                left = mid + 1
        else:
            if nums[mid] < target <= nums[right]:
                left = mid + 1
            else:
                right = mid - 1

    return -1
```

- 时间：`O(log n)`；空间：`O(1)`。
- 易错点：半区边界的等号必须与移动规则匹配；本题依赖元素不重复。
- 恢复脚本：**先判哪半有序，再判目标是否落在该有序值域。**

## 母题 66｜153. 寻找旋转排序数组中的最小值【B】

### 题意

在元素互不重复的旋转升序数组中寻找最小值。

### 先自己思考

1. 为什么应把 `nums[mid]` 与 `nums[right]` 比较？
2. `nums[mid] > nums[right]` 时最小值在哪一侧？
3. `nums[mid] < nums[right]` 时为什么不能排除 `mid`？
4. 循环何时结束？

### 逐步答案

1. 右端元素可帮助判断 `mid` 是否位于旋转前的较大段。
2. `nums[mid] > nums[right]`，最小值严格在 `mid` 右侧，令 `left = mid + 1`。
3. 否则 `mid` 可能就是最小值，令 `right = mid`。

```python
def find_min(nums):
    left, right = 0, len(nums) - 1

    while left < right:
        mid = (left + right) // 2
        if nums[mid] > nums[right]:
            left = mid + 1
        else:
            right = mid

    return nums[left]
```

- 时间：`O(log n)`；空间：`O(1)`。
- 易错点：右边界更新为 `mid` 而不是 `mid-1`；元素重复时需要额外退化处理。
- 恢复脚本：**mid 大于右端，最小在右；否则 mid 可能最小，收右到 mid。**

## 母题 67｜4. 寻找两个正序数组的中位数【C】

### 题意

在两个升序数组中求合并后的中位数，要求 `O(log(m+n))`。

### 先自己思考

1. 为什么不真正合并数组？其复杂度是多少？
2. 能否在较短数组中寻找一个切分位置，使左右两边元素数量相等或左边多一个？
3. 合法切分需要满足哪两个交叉大小关系？
4. 奇偶总长度分别怎样得到中位数？

### 逐步答案

1. 合并为 `O(m+n)`；目标复杂度要求在切分位置上二分。
2. 确保第一个数组较短。在其中选切分 `i`，第二个数组切分为 `j = half-i`。
3. 合法条件：`left_a <= right_b` 且 `left_b <= right_a`。
4. 奇数长度取左半最大值；偶数取左半最大与右半最小的平均值。越界处用正负无穷表示。

```python
def find_median_sorted_arrays(nums1, nums2):
    if len(nums1) > len(nums2):
        nums1, nums2 = nums2, nums1

    m, n = len(nums1), len(nums2)
    half = (m + n + 1) // 2
    left, right = 0, m

    while left <= right:
        i = (left + right) // 2
        j = half - i

        left_a = nums1[i - 1] if i > 0 else float("-inf")
        right_a = nums1[i] if i < m else float("inf")
        left_b = nums2[j - 1] if j > 0 else float("-inf")
        right_b = nums2[j] if j < n else float("inf")

        if left_a <= right_b and left_b <= right_a:
            left_max = max(left_a, left_b)
            if (m + n) % 2 == 1:
                return left_max

            right_min = min(right_a, right_b)
            return (left_max + right_min) / 2

        if left_a > right_b:
            right = i - 1
        else:
            left = i + 1
```

- 时间：`O(log(min(m,n)))`；空间：`O(1)`。
- 易错点：必须在短数组上二分；`half` 使用 `(m+n+1)//2`；切分边界用无穷处理。
- 恢复脚本：**短数组二分切口，另一个切口补齐左半；交叉有序即合法，奇取左大、偶取左右中值。**

## 母题 68｜20. 有效的括号【A】

### 题意

判断只包含三类括号的字符串是否类型匹配且闭合顺序正确。

### 先自己思考

1. 为什么“最近出现但尚未匹配的左括号”最先被右括号匹配？
2. 遇到右括号时栈为空意味着什么？
3. 扫描结束后为什么还要检查栈为空？
4. 可以把右括号映射到左括号吗？

### 逐步答案

1. 括号嵌套具有后进先出结构，使用栈。
2. 左括号入栈；右括号必须与栈顶类型匹配，否则非法。
3. 最终栈非空说明还有未闭合左括号。

```python
def is_valid(s):
    matching = {")": "(", "]": "[", "}": "{"}
    stack = []

    for char in s:
        if char not in matching:
            stack.append(char)
        else:
            if not stack or stack.pop() != matching[char]:
                return False

    return not stack
```

- 时间：`O(n)`；空间：`O(n)`。
- 易错点：右括号到来时先验栈非空；最后必须验栈空。
- 恢复脚本：**左括号入栈，右括号匹配栈顶；中途不配假，最后栈空真。**

## 母题 69｜155. 最小栈【B】

### 题意

实现支持 `push`、`pop`、`top`、`getMin` 且均为 `O(1)` 的栈。

### 先自己思考

1. 只保存一个全局最小值，弹出当前最小时怎么办？
2. 每个位置应该额外保存什么？
3. 新值与此前最小值怎样合成新的最小值？
4. 可以使用一个栈保存二元组吗？

### 逐步答案

1. 每个入栈元素同时记录“到当前位置为止的最小值”。
2. 弹出元素时，对应历史最小值也一并弹出，栈顶始终包含当前最小值。

```python
class MinStack:
    def __init__(self):
        self.stack = []

    def push(self, value):
        current_min = value
        if self.stack:
            current_min = min(value, self.stack[-1][1])
        self.stack.append((value, current_min))

    def pop(self):
        self.stack.pop()

    def top(self):
        return self.stack[-1][0]

    def getMin(self):
        return self.stack[-1][1]
```

- 所有操作：`O(1)`；空间：`O(n)`。
- 易错点：重复最小值也必须逐层保存；`pop` 后最小值自动恢复。
- 恢复脚本：**每层保存（当前值，到此最小值）；栈顶第二项永远是当前最小。**

## 母题 70｜394. 字符串解码【B】

### 题意

将形如 `3[a2[c]]` 的编码字符串解码为重复后的字符串。

### 先自己思考

1. 多位数字怎样解析？
2. 遇到 `[` 时需要保存哪些外层状态？
3. 遇到 `]` 时如何恢复外层并拼接？
4. 为什么嵌套结构适合栈？

### 逐步答案

1. 用 `number = number*10 + digit` 累积多位次数。
2. 遇 `[`，把外层字符串和次数压栈，然后重置当前层。
3. 遇 `]`，弹出 `(previous, repeat)`，令当前字符串为 `previous + current*repeat`。

```python
def decode_string(s):
    stack = []
    current = ""
    number = 0

    for char in s:
        if char.isdigit():
            number = number * 10 + int(char)
        elif char == "[":
            stack.append((current, number))
            current = ""
            number = 0
        elif char == "]":
            previous, repeat = stack.pop()
            current = previous + current * repeat
        else:
            current += char

    return current
```

- 时间：与解码后字符串长度相关；空间：与嵌套深度及中间字符串相关。
- 易错点：次数可能多位；进入新层要同时重置字符串和次数。
- 恢复脚本：**数字累积；左括号存外层；右括号弹出并做“外层 + 当前×次数”。**

3. 栈内温度保持递增还是递减？

### 逐步答案

1. 每天向后找第一个更高温度会重复扫描。
2. 栈保存尚未找到更高温度的下标；其对应温度从栈底到栈顶单调不增。
3. 当前温度高于栈顶温度时，当前就是栈顶位置第一个更高温度，弹出并计算下标差。

```python
def daily_temperatures(temperatures):
    answer = [0] * len(temperatures)
    stack = []

    for index, temperature in enumerate(temperatures):
        while stack and temperatures[stack[-1]] < temperature:
            previous_index = stack.pop()
            answer[previous_index] = index - previous_index

        stack.append(index)

    return answer
```

- 时间：`O(n)`，每个下标最多进出栈一次；空间：`O(n)`。

## 母题 72｜84. 柱状图中最大的矩形【A】

### 题意

每根柱宽为 1，求相邻柱子能组成的最大矩形面积。

1. 若固定某根柱为矩形最低高度，需要找哪两个边界？
2. 单调栈中保存什么性质的柱子？
3. 当前柱更矮时，为什么可以确定被弹柱子的右边界？
4. 弹栈后宽度为什么是 `right - stack[-1] - 1`？

### 逐步答案

1. 对高度 `h`，最大宽度由左侧第一个严格更矮柱和右侧第一个严格更矮柱决定。
2. 栈保存下标，对应高度单调不降。
3. 当前更矮柱是被弹柱子的第一个右侧更矮位置；弹栈后的新栈顶是左侧更矮位置。
4. 加入尾部高度 0 的哨兵，强制结算所有剩余柱子；栈底用下标 `-1` 简化左边界。

```python
def largest_rectangle_area(heights):
    values = heights + [0]
    stack = [-1]
    best = 0

    for right, height in enumerate(values):
        while stack[-1] != -1 and values[stack[-1]] > height:
            current_height = values[stack.pop()]
            width = right - stack[-1] - 1
            best = max(best, current_height * width)

        stack.append(right)

    return best
```

- 时间：`O(n)`；空间：`O(n)`。
- 易错点：宽度在弹栈之后计算；尾部哨兵用于清栈；`stack[-1]` 是左侧更矮位置，不是矩形左端本身。
- 恢复脚本：**递增栈等右边界；遇矮弹栈，右界是当前，左界是新栈顶，宽度减一。**

## 母题 73｜215. 数组中的第 K 个最大元素【A】

### 题意

返回数组排序后的第 `k` 大元素；重复值按排序位置计算。

### 先自己思考

1. 第 `k` 大对应升序下标多少？
2. 完整排序做了哪些不必要工作？
3. 快速选择一次分区后能排除哪一侧？
4. 为什么随机选择枢轴能降低退化风险？

### 逐步答案

1. 第 `k` 大对应升序下标 `target = n-k`。
2. 快速选择只需不断把枢轴放到最终位置，并保留包含 `target` 的一侧。
3. 平均时间 `O(n)`；极端分区可能退化为 `O(n²)`，随机枢轴可降低概率。

```python
import random


def find_kth_largest(nums, k):
    target = len(nums) - k
    left, right = 0, len(nums) - 1

    while True:
        pivot_index = random.randint(left, right)
        nums[pivot_index], nums[right] = nums[right], nums[pivot_index]
        pivot = nums[right]

        store = left
        for index in range(left, right):
            if nums[index] <= pivot:
                nums[store], nums[index] = nums[index], nums[store]
                store += 1

        nums[store], nums[right] = nums[right], nums[store]

        if store == target:
            return nums[store]
        if store < target:
            left = store + 1
        else:
            right = store - 1
```

- 平均时间：`O(n)`，最坏 `O(n²)`；额外空间：`O(1)`。
- 易错点：第 `k` 大转换为 `n-k`；题目允许修改数组；重复值仍按位置处理。
- 恢复脚本：**第 K 大转升序 n-k；分区定枢轴位置；只进目标所在半区。**

## 母题 74｜347. 前 K 个高频元素【B】

4. 新元素入堆后超过 `k` 为什么弹出堆顶？

### 逐步答案

1. 用哈希表统计 `value -> frequency`。
2. 小根堆保存当前频率最高的 `k` 个候选；堆顶是其中频率最低者，便于淘汰。

```python
from collections import Counter
import heapq


def top_k_frequent(nums, k):
    frequencies = Counter(nums)
    heap = []

    for value, frequency in frequencies.items():
        heapq.heappush(heap, (frequency, value))
        if len(heap) > k:
            heapq.heappop(heap)

    return [value for _, value in heap]
```

- 时间：`O(n + u log k)`，`u` 为不同元素数；空间：`O(u+k)`。

## 母题 75｜295. 数据流的中位数【C】

### 题意

不断加入数字，并随时返回当前所有数字的中位数。

### 先自己思考

1. 怎样把数据分成较小一半和较大一半？
2. Python 如何实现大根堆？
3. 两个堆的大小应该满足什么关系？
4. 奇数和偶数个元素时分别怎样取中位数？

### 逐步答案

1. 大根堆 `small` 保存较小一半，小根堆 `large` 保存较大一半。
2. Python 用负数模拟大根堆。
3. 维持 `len(small) == len(large)` 或 `len(small) == len(large)+1`，并保证 `small` 中元素都不大于 `large`。
4. 奇数取 `small` 堆顶；偶数取两堆顶平均。

```python
import heapq


class MedianFinder:
    def __init__(self):
        self.small = []  # 负数，大根堆
        self.large = []  # 正数，小根堆

    def addNum(self, number):
        heapq.heappush(self.small, -number)
        heapq.heappush(self.large, -heapq.heappop(self.small))

        if len(self.large) > len(self.small):
            heapq.heappush(self.small, -heapq.heappop(self.large))

    def findMedian(self):
        if len(self.small) > len(self.large):
            return -self.small[0]
        return (-self.small[0] + self.large[0]) / 2
```

- 插入：`O(log n)`；查询：`O(1)`；空间：`O(n)`。
- 易错点：负号转换；先保证跨堆有序，再平衡大小。
- 恢复脚本：**小半大根、大半小根；先经 small 转入 large，再让 small 数量不少于 large。**

2. 扫描到位置 `i` 的前提是什么？
3. `farthest` 表示什么？
4. 什么时候可以提前成功或失败？

### 逐步答案

1. 不关心具体路线，只关心当前所有可达位置能把最远边界推进到哪里。
2. 若 `i > farthest`，当前位置不可达，后面也无法继续。
3. 可达时更新 `farthest = max(farthest, i + nums[i])`。

```python
def can_jump(nums):
    farthest = 0

    for index, jump in enumerate(nums):
        if index > farthest:
            return False

        farthest = max(farthest, index + jump)
        if farthest >= len(nums) - 1:
            return True

    return True
```

- 时间：`O(n)`；空间：`O(1)`。
- 易错点：先确认当前位置可达再扩展；长度 1 自动成功。

## 母题 78｜45. 跳跃游戏 II【B】

### 题意

保证能到终点，求最少跳跃次数。

### 先自己思考

1. 当前一次跳跃覆盖的区间是什么？
2. 为什么扫描这一层时暂不立即增加步数？
3. `current_end` 与 `farthest` 分别表示什么？
4. 为什么无需处理最后一个下标？

### 逐步答案

1. 把可达区间看成 BFS 层：`current_end` 是当前步数能覆盖的最远位置。
2. 扫描当前区间内所有点，用 `farthest` 计算再跳一步能到的最远位置。
3. 到达 `current_end` 时才必须完成一次跳跃，并把边界更新为 `farthest`。

```python
def jump(nums):
    jumps = 0
    current_end = 0
    farthest = 0

    for index in range(len(nums) - 1):
        farthest = max(farthest, index + nums[index])

        if index == current_end:
            jumps += 1
            current_end = farthest

    return jumps
```

- 时间：`O(n)`；空间：`O(1)`。
- 易错点：遍历到 `n-2` 即可；只有到当前层边界才增加跳数。
- 恢复脚本：**当前边界是一层，层内扩下一层最远；走到边界，跳数加一并换层。**

4. “尽可能多”为什么由最早安全切点保证？

```python
def partition_labels(s):

    start = 0
    end = 0

        if index == end:
            result.append(end - start + 1)
            start = index + 1

    return result
```

```python
def climb_stairs(n):

    previous_one = 2

    for _ in range(3, n + 1):
        current = previous_one + previous_two
        previous_two = previous_one
        previous_one = current

    return previous_one
```

```python
def generate(num_rows):
```

```python
def num_squares(n):
    dp = [float("inf")] * (n + 1)
    dp[0] = 0

    for amount in range(1, n + 1):
        number = 1
        while number * number <= amount:
            square = number * number
            dp[amount] = min(dp[amount], dp[amount - square] + 1)
            number += 1

    return dp[n]
```

## 母题 84｜322. 零钱兑换【A】

### 题意

### 先自己思考

1. `dp[x]` 表示什么？
2. 若最后使用硬币 `coin`，前一个状态是什么？
3. 为什么其他状态初始化为无穷？
4. 怎样区分“最少数量”和“组合数量”的转移？

### 逐步答案

1. `dp[x]` 表示凑出金额 `x` 的最少硬币数。
2. 最后使用 `coin` 时，候选为 `dp[x-coin]+1`。
3. `dp[0]=0`；不可达状态为无穷，避免错误参与最小值。

```python
def coin_change(coins, amount):
    dp = [float("inf")] * (amount + 1)
    dp[0] = 0

    for current in range(1, amount + 1):
        for coin in coins:
            if coin <= current:
                dp[current] = min(
                    dp[current],
                    dp[current - coin] + 1,
                )

    return -1 if dp[amount] == float("inf") else dp[amount]
```

- 时间：`O(amount·len(coins))`；空间：`O(amount)`。
- 易错点：无穷状态与返回 `-1`；这是求最小值，不是方案计数。
- 恢复脚本：**金额状态；枚举最后一枚硬币；前金额最优加一取小。**

## 母题 85｜139. 单词拆分【B】

### 题意

判断字符串能否由字典中的单词重复拼接而成。

### 先自己思考

1. `dp[i]` 表示字符串哪个范围可被拆分？
2. 若最后一个单词是 `s[j:i]`，需要满足哪两个条件？
3. 为什么 `dp[0] = True`？
4. 字典为什么转成集合？

### 逐步答案

1. 定义 `dp[i]`：前缀 `s[:i]` 能被字典单词组成。
2. 若存在 `j<i`，满足 `dp[j]` 为真且 `s[j:i]` 在字典中，则 `dp[i]` 为真。
3. 空前缀可被“零个单词”组成，是转移起点。

```python
def word_break(s, word_dict):
    words = set(word_dict)
    dp = [False] * (len(s) + 1)
    dp[0] = True

    for end in range(1, len(s) + 1):
        for start in range(end):
            if dp[start] and s[start:end] in words:
                dp[end] = True
                break

    return dp[len(s)]
```

- 时间：通常写 `O(n²)` 次状态检查；考虑切片成本可达 `O(n³)`；空间：`O(n)`。
- 易错点：`dp` 长度是 `n+1`；子串使用左闭右开；找到可行切点即可停止。
- 恢复脚本：**dp[i] 表示前 i 字符可拆；枚举最后单词起点 j，前缀可拆且后段在词典则真。**

## 母题 86｜300. 最长递增子序列【B】

### 题意

求严格递增子序列的最大长度；子序列不要求连续。

### 先自己思考

1. `dp[i]` 若表示“以 `nums[i]` 结尾”的 LIS，有什么好处？
2. 哪些前驱 `j` 可以转移到 `i`？
3. 为什么最终答案是所有 `dp[i]` 的最大值？
4. 如何进一步优化到 `O(n log n)`？

### 逐步答案

1. 固定结尾后，枚举之前所有更小元素作为倒数第二个元素。
2. 若 `nums[j] < nums[i]`，候选为 `dp[j]+1`。
3. LIS 可能结束在任意位置，所以取全局最大。

```python
def length_of_lis(nums):
    if not nums:
        return 0

    dp = [1] * len(nums)

    for end in range(len(nums)):
        for previous in range(end):
            if nums[previous] < nums[end]:
                dp[end] = max(dp[end], dp[previous] + 1)

    return max(dp)
```

- 时间：`O(n²)`；空间：`O(n)`。
- 易错点：严格递增使用 `<`；状态是“必须以当前结尾”。
- 恢复脚本：**固定结尾 i，向前找更小 j，用 dp[j]+1 更新；最后取所有结尾最大。**

`O(n log n)` 追问：维护 `tails[length-1]` 为该长度递增子序列能取得的最小尾值，对每个数用 `lower_bound` 替换第一个 `>=` 它的位置。

## 母题 87｜152. 乘积最大子数组【B】

### 题意

求连续非空子数组的最大乘积。

### 先自己思考

1. 为什么只保存“以当前位置结尾的最大乘积”不够？
2. 负数到来时最大值和最小值会发生什么？
3. 当前状态有哪些来源？
4. 为什么要用首元素初始化？

### 逐步答案

1. 负数乘以很小的负乘积可能变成新的最大值，所以必须同时维护最大和最小乘积。
2. 对当前值 `x`，新状态来自 `x`、`previous_max*x`、`previous_min*x`。
3. 使用临时变量，避免更新最大值后污染最小值计算。

```python
def max_product(nums):
    current_max = nums[0]
    current_min = nums[0]
    best = nums[0]

    for value in nums[1:]:
        candidates = (
            value,
            current_max * value,
            current_min * value,
        )
        current_max = max(candidates)
        current_min = min(candidates)
        best = max(best, current_max)

    return best
```

- 时间：`O(n)`；空间：`O(1)`。
- 易错点：必须维护最小乘积；零会自然让状态重新开始；全负情况不能初始化为 0。
- 恢复脚本：**乘法遇负会翻转；每步同时保留以当前结尾的最大和最小。**

## 母题 88｜416. 分割等和子集【B】

### 题意

判断数组能否分为两个元素和相等的子集，每个元素最多使用一次。

### 先自己思考

1. 总和为奇数时为什么立即失败？
2. 问题怎样转化为 0/1 背包？
3. `dp[capacity]` 表示什么？
4. 为什么容量必须倒序遍历？

### 逐步答案

1. 两个子集和都应为 `total/2`，总和奇数不可能。
2. 转化为：能否从数组中选若干元素恰好组成 `target = total//2`。
3. `dp[capacity]` 表示是否能用已处理元素凑出该容量。
4. 每个元素只能使用一次，倒序更新可防止同一轮重复使用当前元素。

```python
def can_partition(nums):
    total = sum(nums)
    if total % 2 == 1:
        return False

    target = total // 2
    dp = [False] * (target + 1)
    dp[0] = True

    for value in nums:
        for capacity in range(target, value - 1, -1):
            dp[capacity] = (
                dp[capacity]
                or dp[capacity - value]
            )

    return dp[target]
```

- 时间：`O(n·target)`；空间：`O(target)`。
- 易错点：0/1 背包容量倒序；`dp[0]=True`；先判断奇偶。
- 恢复脚本：**总和偶数才找一半；0/1 背包布尔状态；每个数让容量倒序更新。**

## 母题 89｜32. 最长有效括号【C】

### 题意

求只含 `(`、`)` 的字符串中，最长连续合法括号子串长度。

### 先自己思考

1. 栈中为什么保存下标而不是字符？
2. 初始为什么放入哨兵下标 `-1`？
3. 遇到右括号时为什么先弹栈？
4. 弹栈后为空时为什么把当前下标作为新边界？

### 逐步答案

1. 栈保存尚未匹配的左括号下标，以及最近一个无法匹配的右括号边界。
2. `-1` 让从下标 0 开始的合法串长度可直接计算。
3. 遇 `)` 弹出一个左括号；若栈仍非空，当前合法长度是 `index-stack[-1]`。
4. 若弹空，当前右括号无法匹配，它成为后续合法串的左边界。

```python
def longest_valid_parentheses(s):
    stack = [-1]
    best = 0

    for index, char in enumerate(s):
        if char == "(":
            stack.append(index)
        else:
            stack.pop()
            if not stack:
                stack.append(index)
            else:
                best = max(best, index - stack[-1])

    return best
```

- 时间：`O(n)`；空间：`O(n)`。
- 易错点：哨兵表示合法区间左边界之前的位置；无法匹配的右括号要成为新哨兵。
- 恢复脚本：**栈存下标与失败边界；左入栈，右先弹；栈空重设边界，否则算距离。**

## 母题 90｜62. 不同路径【C】

### 题意

机器人从左上角出发，每次只能向右或向下，到右下角共有多少条路径？

### 先自己思考

1. 到达一个格子的最后一步来自哪里？
2. 第一行和第一列为什么都只有一种路径？
3. `dp[row][col]` 表示什么？
4. 怎样压缩为一维数组？

### 逐步答案

1. 到当前格只能从上方或左方到达，两类路径相加。
2. 一维压缩时，更新前 `dp[col]` 表示上方路径数，`dp[col-1]` 表示左方路径数。

```python
def unique_paths(rows, cols):
    dp = [1] * cols

    for _ in range(1, rows):
        for col in range(1, cols):
            dp[col] = dp[col] + dp[col - 1]

    return dp[-1]
```

- 时间：`O(mn)`；空间：`O(n)`。
- 易错点：第一行和第一列初始化为 1；一维更新需从左到右。
- 恢复脚本：**到格子来自上加左；一维 dp 中旧值是上，新左值是左。**

## 母题 91｜64. 最小路径和【C】

### 题意

从左上走到右下，每次只向右或向下，求路径上的最小数字和。

### 先自己思考

1. 与不同路径相比，转移从“相加”变成什么？
2. 第一行和第一列如何初始化？
3. 当前格状态是否包含当前格的值？
4. 能否直接原地修改网格？

### 逐步答案

1. 到当前格的最优前驱是上方和左方路径和的较小值，再加当前格值。
2. 第一行只能从左来，第一列只能从上来，需要累计。

```python
def min_path_sum(grid):
    rows, cols = len(grid), len(grid[0])
    dp = [float("inf")] * cols
    dp[0] = 0

    for row in range(rows):
        for col in range(cols):
            from_left = dp[col - 1] if col > 0 else float("inf")
            from_up = dp[col]
            dp[col] = min(from_up, from_left) + grid[row][col]

    return dp[-1]
```

- 时间：`O(mn)`；空间：`O(n)`。
- 易错点：左上角需要可达初值；更新前 `dp[col]` 仍是上方状态。
- 恢复脚本：**当前最小和等于上、左取小再加当前值；按行从左到右更新。**

## 母题 92｜1143. 最长公共子序列【A】

### 题意

求两个字符串的最长公共子序列长度；子序列保持相对顺序但不要求连续。

### 先自己思考

1. `dp[i][j]` 应表示哪两个前缀？
2. 当前两个字符相等时怎样转移？
3. 不相等时为什么取“删除一侧字符”两种状态的最大值？
4. 空前缀对应什么初值？

### 逐步答案

1. `dp[i][j]` 表示 `text1[:i]` 与 `text2[:j]` 的 LCS 长度。
2. 当前字符相等，它可以接在两个更短前缀的 LCS 后：`dp[i-1][j-1]+1`。
3. 不等时至少舍弃其中一个当前字符，取 `dp[i-1][j]` 与 `dp[i][j-1]` 的最大值。

```python
def longest_common_subsequence(text1, text2):
    rows, cols = len(text1), len(text2)
    dp = [[0] * (cols + 1) for _ in range(rows + 1)]

    for i in range(1, rows + 1):
        for j in range(1, cols + 1):
            if text1[i - 1] == text2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

    return dp[rows][cols]
```

- 时间：`O(mn)`；空间：`O(mn)`，可压缩到 `O(n)`。
- 易错点：DP 下标与字符串下标差 1；子序列不要求连续。
- 恢复脚本：**前缀二维状态；字符同接左上加一，不同取上或左最大。**

## 母题 93｜5. 最长回文子串【B】

### 题意

返回字符串中最长的连续回文子串。

### 先自己思考

1. 回文串的中心可能是什么？
2. 为什么要分别处理奇数和偶数长度？
3. 从中心向外扩展的停止条件是什么？
4. 怎样记录当前最佳区间？

### 逐步答案

1. 每个回文串都可由中心向两侧扩展；中心可能是一个字符，也可能是两个字符之间。
2. 对每个位置分别扩展 `(i,i)` 和 `(i,i+1)`。
3. 左右字符相等且未越界时继续扩展，返回最终合法长度。

```python
def longest_palindrome(s):
    if not s:
        return ""

    best_start = 0
    best_length = 1

    def expand(left, right):
        while left >= 0 and right < len(s) and s[left] == s[right]:
            left -= 1
            right += 1
        return left + 1, right - left - 1

    for center in range(len(s)):
        for left, right in ((center, center), (center, center + 1)):
            start, length = expand(left, right)
            if length > best_length:
                best_start = start
                best_length = length

    return s[best_start:best_start + best_length]
```

- 时间：`O(n²)`；空间：`O(1)`。
- 易错点：同时考虑奇偶中心；扩展循环退出后左右各多走一步。
- 恢复脚本：**枚举每个奇偶中心，向外等字符扩展，记录最长区间。**

## 母题 94｜72. 编辑距离【B】

### 题意

允许插入、删除、替换一个字符，求把 `word1` 转成 `word2` 的最少操作数。

### 先自己思考

1. `dp[i][j]` 表示哪两个前缀之间的编辑距离？
2. 当前字符相同时是否需要操作？
3. 插入、删除、替换分别对应哪个前驱状态？
4. 空串与长度为 `i` 的字符串之间距离是多少？

### 逐步答案

1. `dp[i][j]` 表示 `word1[:i]` 转换成 `word2[:j]` 的最少操作数。
2. 字符相同：继承 `dp[i-1][j-1]`。
3. 不同：从删除 `dp[i-1][j]`、插入 `dp[i][j-1]`、替换 `dp[i-1][j-1]` 中取最小再加 1。
4. `dp[i][0]=i`，`dp[0][j]=j`。

```python
def min_distance(word1, word2):
    rows, cols = len(word1), len(word2)
    dp = [[0] * (cols + 1) for _ in range(rows + 1)]

    for i in range(rows + 1):
        dp[i][0] = i
    for j in range(cols + 1):
        dp[0][j] = j

    for i in range(1, rows + 1):
        for j in range(1, cols + 1):
            if word1[i - 1] == word2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1]
            else:
                dp[i][j] = 1 + min(
                    dp[i - 1][j],      # 删除
                    dp[i][j - 1],      # 插入
                    dp[i - 1][j - 1],  # 替换
                )

    return dp[rows][cols]
```

- 时间：`O(mn)`；空间：`O(mn)`，可压缩到 `O(n)`。
- 易错点：理解三个前驱状态相对于 `word1 -> word2` 的含义；空前缀初始化不能漏。
- 恢复脚本：**前缀编辑距离；字符同走左上，不同从删上、插左、换左上取小加一。**

### 题意

数组中除一个元素出现一次外，其余都出现两次，使用线性时间和常数空间找出单独元素。

1. 异或满足哪些性质？

3. 数字与 0 异或结果是什么？

```python
def single_number(nums):

    return result
```

## 母题 96｜169. 多数元素【C】

### 题意

找出出现次数严格超过 `n/2` 的元素，题目保证存在。

### 先自己思考

1. 多数元素与所有其他元素两两抵消后会怎样？
2. 候选计数为 0 时为什么可以更换候选？
3. 当前值等于候选和不等于候选时分别怎样更新？
4. 若题目不保证多数元素存在，还需做什么？

### 逐步答案

1. Boyer-Moore 投票把不同元素视为互相抵消；真正多数数量超过其他所有元素总和，最终一定留下。
2. 计数归零说明此前片段内部已完全抵消，不影响后续多数判断。

```python
def majority_element(nums):
    candidate = None
    count = 0

    for value in nums:
        if count == 0:
            candidate = value

        if value == candidate:
            count += 1
        else:
            count -= 1

    return candidate
```

- 时间：`O(n)`；空间：`O(1)`。
- 易错点：题目不保证存在时，需要第二遍计数验证；计数不是候选真实频率。
- 恢复脚本：**相同投赞成，不同互抵；票数归零换候选；多数最终无法被抵完。**

## 母题 97｜75. 颜色分类【B】

### 题意

原地把只含 `0、1、2` 的数组按升序排列，只扫描一次并使用常数空间。

### 先自己思考

1. 三个指针分别维护哪些区间？
2. 当前值为 0、1、2 时各怎样处理？
3. 交换 2 到右侧后，为什么当前下标不能立即前进？
4. 交换 0 到左侧后，为什么当前下标可以前进？

### 逐步答案

维护四段：

```text
[0, low) 全是 0
[low, current) 全是 1
[current, high] 未处理
(high, n) 全是 2
```

遇 0 与 `low` 交换并同时推进；遇 1 只推进；遇 2 与 `high` 交换并缩小右界，但换回来的值尚未检查，所以 `current` 不动。

```python
def sort_colors(nums):
    low = 0
    current = 0
    high = len(nums) - 1

    while current <= high:
        if nums[current] == 0:
            nums[low], nums[current] = nums[current], nums[low]
            low += 1
            current += 1
        elif nums[current] == 1:
            current += 1
        else:
            nums[current], nums[high] = nums[high], nums[current]
            high -= 1
```

- 时间：`O(n)`；空间：`O(1)`。
- 易错点：处理 2 后不移动 `current`；循环条件包含 `current == high`。
- 恢复脚本：**左边放 0，右边放 2，中间自然是 1；换右后重查，换左后前进。**

## 母题 98｜31. 下一个排列【C】

### 题意

把数组原地变为字典序中紧邻的下一个更大排列；若已是最大排列，则变为最小排列。

### 先自己思考

1. 从右向左找到的第一个 `nums[i] < nums[i+1]` 表示什么？
2. 为什么右侧后缀此时是非递增的？
3. 应与右侧哪个元素交换，才能“只增大一点”？
4. 交换后为什么反转后缀即可得到最小后缀？

### 逐步答案

2. 从右侧找到第一个严格大于 `nums[pivot]` 的元素，它就是最小可替换值。
3. 交换后，后缀仍为非递增排列；反转即可变成升序的最小排列。
4. 若找不到 pivot，整个数组非递增，直接反转为最小排列。

```python
def next_permutation(nums):
    pivot = len(nums) - 2
    while pivot >= 0 and nums[pivot] >= nums[pivot + 1]:
        pivot -= 1

    if pivot >= 0:
        successor = len(nums) - 1
        while nums[successor] <= nums[pivot]:
            successor -= 1
        nums[pivot], nums[successor] = nums[successor], nums[pivot]

    left, right = pivot + 1, len(nums) - 1
    while left < right:
        nums[left], nums[right] = nums[right], nums[left]
        left += 1
        right -= 1
```

- 时间：`O(n)`；空间：`O(1)`。
- 易错点：找 pivot 用 `>=`；找 successor 用 `<=`，正确处理重复值；最后反转从 `pivot+1` 开始。
- 恢复脚本：**从右找首个上升拐点；与右侧刚好更大的数交换；后缀反转成最小。**

## 母题 99｜287. 寻找重复数【C】

### 题意

长度 `n+1` 的数组只含 `[1,n]`，只有一个数重复一次或多次；不能修改数组，只用常数空间找重复数。

### 先自己思考

1. 如何把“下标到数值”看成链表的 `next` 指针？
2. 为什么一定存在环？
3. 环入口为什么对应重复数字？
4. Floyd 两阶段分别做什么？

### 逐步答案

1. 把下标 `i` 看成节点，`nums[i]` 看成下一节点。因为值都在 `[1,n]`，每个节点都有合法后继。
2. `n+1` 个下标映射到 `n` 个值，必然有多个下标指向同一值，形成环；这个首次汇合的值就是环入口和重复数。
3. 第一阶段快慢指针在环中相遇；第二阶段一个从起点出发、一个从相遇点出发，同速前进，在入口相遇。

```python
def find_duplicate(nums):
    slow = nums[0]
    fast = nums[0]

    while True:
        slow = nums[slow]
        fast = nums[nums[fast]]
        if slow == fast:
            break

    finder = nums[0]
    while finder != slow:
        finder = nums[finder]
        slow = nums[slow]

    return finder
```

- 时间：`O(n)`；空间：`O(1)`。
- 易错点：移动方式是 `index = nums[index]`；依赖数值范围 `[1,n]`；不能修改数组做原地标记。
- 恢复脚本：**数组值当 next；重复值是多入口形成的环入口；Floyd 先相遇，再从起点同速找入口。**
