# 模块深挖卡模板

> **模块** = 一个知识域的完整覆盖。**母题** = 最小学习单位（一个需要解决的问题）。
> 关系：一个模块 = 8–15 个母题。模块卡是**地图**，母题卡是**脚步**。
> 铁律：**一次只推进一个模块；模块内母题全部通过证据验收才算闭环；未闭环不进下一个模块。**

用法：复制本模板 → 填 §0 边界 → 列 §2 题单 → 逐母题走母题法（闭卷 → 补断点 → 费曼 → 证据验收 → 1/3/7/14/30 复训）→ 过 §6 验收门。

- **理解** = 讲清原理与取舍，能被追问一层
- **了解** = 知道名词、适用边界和常见误区，不深究实现
