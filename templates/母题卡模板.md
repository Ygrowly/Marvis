# 母题卡模板

> **一张卡 = 一个训练单元 = 三层**：**① 学（教材）→ ② 测（自测）→ ③ 说（面试输出）**。
> **顺序不能跳**：先读教材（推着走），再自测（验证懂没懂），最后才看面试输出（怎么说）。
> **为什么输出层放最后**：结论一旦先给，读者就失去了自己推导的机会——那是「流畅性错觉」的制造机（对应 [[母题驱动证据闭环学习法]] 里"AI 学习场景默认不先给答案"）。
> **分工**：主线页（`modules/{模块}-NN-*.html`）保留「先答 → 展开对照讲解」的抽查用法；**单卡页（`topics/`）是教材，用来系统学**。

**层级（frontmatter `level`）**：`A` 教材级（地基型，结论能推出来）／`B` 标准级（机制型，有因果链）／`C` 提要级（取舍与清单型）。
判据：**这张卡的结论能不能被"算出来 / 推出来"？** 能 → A 或 B；不能（是取舍或清单）→ C。

## 六条写作规范（每条都对应一类写坏的写法）

| # | 规范 | 写坏的样子 | 该有的样子 |
|---|---|---|---|
| 1 | **首次使用必定义** | "16KB 的页能放约 1170 个键" | "页（page）是数据库与磁盘之间读写数据的最小单位，InnoDB 默认 16KB；**一次 IO 读整页，不是读一行**" |
| 2 | **比较前先介绍双方**：禁止"X 败在 Y"。三段式：**X 是什么 → X 的特点 → 用同一指标衡量 X** | "B 树：非叶节点也存数据 → 扇出小、树更高" | 先讲 B 树是什么、为什么这么设计，再算它的扇出与树高 |
| 3 | **同一指标才可比**（全文统一一个衡量口径） | "红黑树高度 20+" | "树高 ≈ log₂(2×10⁷) ≈ 24 → 最坏 24 次随机 IO" |
| 4 | **量化必须给算式**，让读者能自己算一遍 | "扇出小得多" | "非叶每条 键8B+行数据1KB ≈ 1KB，16KB 一页放约 16 条 → 树高 log₁₆(2000万) ≈ 6" |
| 5 | **每个结论标类型**：`【推导】`能从前提出／`【事实】`工程约定或参数／`【取舍】`没有唯一答案 | 把"页 = 16KB"当定理背 | "【事实】InnoDB 选 16KB"；"【取舍】太大则一次读进用不上的数据，太小则扇出不足" |
| 6 | **节点小结**：每节末尾一句"到这里你应该能回答：…" | 无 | "到这里你应该能回答：为什么说'读一行'这个说法在数据库里其实不准确？" |

**第 5 条专治一个隐蔽的病**：把**工程约定**当成**定理**——被追问"为什么是 16KB"时才答得出来。
**第 2 条是最常犯的**：读者不可能通过"否定一个没介绍过的东西"来理解任何事。

## 字段与渲染对照

| 字段 | 渲染成 |
|---|---|
| `**导读**` | 卡顶导读条（灰底） |
| `**题目**` | 题目区块（带色条） |
| `## 一、教材` | **教材层（默认展开）**；内部 `###`/`####` 渲染成四级标题 |
| `::figure 文件名 \| 标题 \| 说明` | **就地插图**——写在教材哪个位置就插在哪；svg 放 `site/figures/` |
| `## 二、自测` 的 `**Qn（类型）**` / `**An**` | 一张**翻转卡**（先想后翻，**不进复训调度**） |
| `**一句话结论**` / `**恢复关键词**` | 主卡 + 关键词 chips（**唯一进复训调度的单位**） |
| `**追问**` / `**同类变体**` / `**完整回答骨架**` / `**核心不变量 / 主线**` | 「展开」折叠组 |
| `**关联母题**` / `**可迁移场景**` / `**本次断点**` / `**通过证据**` | 页头 meta + 折叠组 |
| `## 四、拼接` 之后 | 不单独成区块（内容由上面字段承载） |

**硬约束**：`**母题**` 与 `**一句话结论**` 必须存在，否则 build 跳过这张卡；`::figure` 引用的 svg **必须已存在**于 `site/figures/`，否则该行被跳过并打印 warn。
**旧体裁兼容**：没有 `## 一、教材` 的卡按老规则走——`---` 之后到 `## 二、` 之间的内容折叠在「讲解」面板里。

## 验收口径（来自 [[母题驱动证据闭环学习法]]）

| 类型 | 通过标准 |
|---|---|
| Agent / 八股 / 系统设计 | 闭卷讲 3 分钟 + 答完追问 + 给一个项目案例，**且自测题全对** |
| 算法 | 识别题型 + 说出不变量 + 独立编码通过 + 解释边界条件 |
| 项目开发 | 代码/测试/日志可复现 + 能解释两个设计取舍 |

汇报语言：不说「今天读完了 X」，说「今天通过了「Y」母题的面试验收」。
