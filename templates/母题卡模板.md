# 母题卡模板

> 用法：复制下面整块，命名 `母题-NN-名称.md`（技术知识放 `wiki/topics/{模块}/`，面试表达放 `wiki/interview/`）。
> 一张卡只装**一个**能独立验收的问题。不同来源讲同一个问题 → 进同一张卡，不按文章建笔记。
> 形态：**主线（母题本身）→ 扩展（同类变体与追问）→ 拼接（关联与迁移）**。

## 验收口径（来自 [[母题驱动证据闭环学习法]]）

| 类型 | 通过标准 |
|---|---|
| Agent / 八股 / 系统设计 | 闭卷讲 3 分钟 + 答两层追问 + 给一个项目案例 |
| 算法 | 识别题型 + 说出不变量 + 独立编码通过 + 解释边界条件 |
| 项目开发 | 代码/测试/日志可复现 + 能解释两个设计取舍 |

汇报语言：不说「今天读完了 X」，说「今天通过了「Y」母题的面试验收」。
