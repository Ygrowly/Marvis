# 地基包模板（技术先修卡）

> 用途：给一个技术模块生成「先记住打底」的地基包——心智模型 + 必会清单 + 学习路径。
> 地基包**不进派单**（模块推进仍走主线），它回答的是「动手学这条主线之前，先记住什么」。
>
> 落盘位置：`wiki/cards/地基-{模块名}.md`（一个模块一个正本）。
> 内容红线：必希清单只收**该模块卡正本里有的**机制与锚点数字，不引入外部事实；
> 正文里的 `[@模块名-行号]` 会被 build 替换成主线页链接（写阿拉伯数字 1/2/3 即可）。

```markdown
---
type: brain-cards
kind: ground
module: {模块名，与模块卡 frontmatter 的 module: 一致}
status: candidate
human_reviewed: false
created: {YYYY-MM-DD}
updated: {YYYY-MM-DD}
---

## ground ground-{模块缩写} · {模块名} 地基包

**定位**：这个模块管什么、不管什么（从模块卡的边界一节压缩，一两句）。

**心智模型**：{2-3 句讲清这个模块最核心的思维骨架——后面所有机制都能从它推出来的那条根判据}

**必会清单**：
- {必须记住的硬知识点：机制名 + 一句话为什么/是什么，含正本里的锚点数字} [@{模块名}-{主线号}]
- {……} [@{模块名}-{主线号}]

**学习路径**：
1. 先学「{主线名}」：{为什么先学它} [@{模块名}-{主线号}]
2. 再学「{主线名}」：{……} [@{模块名}-{主线号}]

**验收门**：
- {做完地基的自我验收标准：能闭卷讲出什么 / 能推出什么} [@{模块名}-{主线号}]
```

## 写法判据

1. **必会清单 5–8 条封顶**：这是「地基」不是「教材」——每条都必须短到能默写。
2. **锚点数字照抄模块卡**：不用自己的记忆改写数字；拿不准就不写数字。
3. **心智模型找「根判据」**：像 MySQL 的「磁盘随机 IO 慢 5 个数量级」——一条能推出全模块的根。
4. **学习路径给理由不给命令**：每步写清「为什么先学它」，顺序要能被模块卡的主线结构支持。
5. **验收门可执行**：写「能当场算出 / 能闭卷画出 / 能按 X 讲出 Y」，不写「理解 / 掌握」。
