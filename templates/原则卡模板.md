# 原则卡模板（读厚卡）

> 用途：把一本读完的书 / 一份准则「读厚」成可派单、可训练的卡片。每张卡只回答一件事：
> **遇到什么情境 → 具体做什么**。概念解释压缩到一句话，做法必须展开成可执行步骤。
>
> 落盘位置：`wiki/cards/原则-{书名}.md`（一个文件一个来源，多张卡共用一个正本）。
> 写完跑 `python site/build.py`：卡片自动进 `_data/cards.js`、内化馆（`site/cards.html`）、
> 3D 星系（`brain.html` 书架厅）和每日派单（`progress.html`，每天 1 条）。
> 字段说明：`id` 是派单等级的挂载键（`card/{id}`），**发布后不要再改**；建议用 `来源缩写-序号`（如 adler-1、jy-2）。
> 红线：AI 生成的卡 `human_reviewed: false`、`status: candidate`；本人验证过才可改 `true`。

```markdown
# 《{书名}》· 读厚卡片

> 一段来源说明：AI 读厚产出还是本人整理；情境和动作要经过真实用过、改到顺手才算内化。

## card {id} · {原则名}

**一句话**：{概念的一个可复述定义，一句说完，不用书上的原句}

**情境**：{贴自己真实处境的派单题面——什么时刻会用到它，写成第二人称的场景}

**标准动作**：{具体怎么做，含步骤序号或明确的触发词/句式；照着做不需要再读原书}

**触发器**：
- 当{出现某个信号} → {做哪个具体动作}
- 当{……} → {……}

**易错**：{最常见的误读/误用，以及它的边界——不是什么}

**关联**：[[相关正本或准则卡]]
```

## 写法判据

1. **情境必须是真的**：从自己的生活（秋招、实习、人际、精力）里取材，不写「假如一个人……」。
2. **动作要过「明天能做」测试**：写不出具体动作 = 没读懂，回炉重读；纯观点内容不入卡。
3. **一句话不抄书**：用自己的话压缩，抄来的句子记不住也讲不出。
4. **一卡一个原则**：两张卡能合并就合并，派单和复习的单位都是卡。
5. **关联写同源动作**：书里的原则若与 `wiki/thinking/行动规则.md` 的某条同源，双向点名，不复制正文。
