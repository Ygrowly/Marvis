# 阅读结论：《精准努力·策略篇》——策略是「障碍 × 解法」的配对，错误要进题本

## 一句话理解

**策略不是计划表，是「障碍 × 解法」的配对——没指认出真障碍的努力，都是在已经会的东西上刷熟练感；怕的事先按四格拆账再决定，归因只认「具体 / 短暂 / 可改」；错误和成功都要进题本，同类错误最多犯三次；动手前问一句「这份投入能复用几次」（杠杆）。**

## 摘抄归纳（策略篇五板块）

1. **财富系统与车道**：人行道（月光）/ 慢车道（好工作 + 理财，一份时间卖一次）/ 快车道（设计系统，让一份时间卖 N 次、或不花时间得到 N 倍）；不做追着胡萝卜跑的驴（没有系统的机械努力）。
2. **成功三角形**（思维眼界 / 为人处事 / 策略习惯三面都要提升），核心是**积极竞争力**，拆成三种技能：
   - **擅长抓住机会**：机会必有风险；参与者 / 旁观者 / 创造者三种视角；**穷尽方案法则**（问题写下来，后面跟着解法清单，一个不行换下一个，试着试着问题就被解决了）。
   - **擅长吸收失败**：消极的人更安全（从不暴露在失败风险里）所以必然不成长；把失败后果按**物质 / 精神 / 人际 / 机会四方面**罗列来降低恐惧；允许失败法则与练习法则（每次都当练习——练习暴露问题、消化吸收；不问「为什么是我」，问「是什么、怎么做」）；归因只用**具体归因、短暂归因、内归因**，忌归到性格、环境等长期因素（改不了 → 诱导放弃努力）。
   - **认为自己可以学习和改变**：自我监测（知道自己在做什么、能指导自我）+ 自控力 + 正反馈 + 对改变有信心。
3. **杠杆**：投入一得到一 → 投入一得到多；人脉 / 资本 / 时间三种。作者的例子（北大、节目、互联网）都是「自己的一 × 平台的 N」；创造自己的杠杆系统，然后集中精力全力以赴。
4. **六步循环**：自我定位 → 瞄准目标 → 制定策略 → 执行反馈 → 调整行动 → 完成。关键增量：
   - 目标要有可执行性和衡量标准，**学会解释目标**——解释成自己的才算目标；
   - **千万不要把目标当成策略，千万不要把计划当行动**；
   - 定策略四步：找出通往目标的障碍 → 找出解法 → 解法之间成系统 → 集中冲刺；
   - 没认清障碍 = 把精力放在**会的东西上反复学**、反复验证自己很牛，是无用功；
   - 目标的作用是催促取舍，取舍后在路径上再做选择；系统 = 各行动目标统一 + 环节相互促进连续；
   - 执行三要求（及时开始 / 专注 / 持久）；**效果 = 时间 × 精力 × 目标 × 策略 × 专注度 × 熟练度**（乘法：任何一项为零，全盘为零）；
   - 要做记录（查偏差 + 观察执行程度）；毕业后要**主动设置反馈环节**；反馈后调整，循环执行到实现为止；**成功的经验也要记录**，并迁移到其他场景。
5. **人生错题本**：三个理由——不记 = 裸奔（错误会在人生各阶段、各人面前重复暴露，而靠谱是最稀罕的品质）；错误顽固（是思维习惯导致的，口头提醒「下次认真」根本无效）；忘性大（近因效应）。按一个人的性格习惯，错的就那几个类型，记全就能防住。四类入库（马虎习惯错 / 别人说错做错的 / 自己不知道而错的 / 别人做对而我不知道的）；每个原因配一个消灭动作、记录后重复使用，同一原因不重记；**同类最多错三次**；口号「把每一次不好受，都当成题目做透」。复盘六步（对目标 → 客观、按序、完整回顾 → 圈出错的环节 → 析因 → 配消灭办法 → 记录）+ 四原则（后悔无用成长最重 / 追到细节再停止、不具体就没用 / 无一例外成习惯 / 提炼一句话成错误类别）；错话本按**对象 / 情境 / 目的**三分归档，用的时候按当下情况翻对应类别。

## 本书真正带走的

1. **一张卡 jy-7**：「每个动作过一句自查——它在解决哪个障碍？」直接治「在会的东西上反复学」这个最隐蔽的无效努力；
2. **一张卡 jy-11**：错题本五步 + 同类三次上限——把行动规则 C 的两行制升级成有归档（对象 / 情境 / 目的）、有消灭动作、有三次红线的完整闭环；
3. **一个自检**：效果六因子是乘法——整体没效果时先找接近零的那一项，当前最可能的零因子是精力与专注（归命功管，不归学习法管）。

## 我的理解变化

- **阅读前**：策略 = 实现目标的计划表；努力 = 把计划做完。
- **阅读后**：策略 = 障碍与解法的配对系统；计划的每一步必须能指认「它在解决哪个障碍」，否则是无用功——**勤奋本身是最容易的逃避方式**。
- **被修正的地方**：错题本不是学生时代的作业，是成年人的负债管理——错误因为「顽固 + 会忘」两个属性，靠记忆和口头提醒注定防不住；「等准备好再上」是慢车道思维，练习法则允许带着丑版本上场（R5 是它的配额化版本）。
