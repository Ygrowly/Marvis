4.1 先把两个预期摆正

  • 考场那个 AI 不好用——第一次生成的代码跑不起来是常态，别怀疑自己。
  • 公开样例全过 ≠ 高分，隐藏用例专挑正常流程之外的地方。你的活不是「让 AI 一次写对」，是「在一个不太靠谱的执行者手上，把活推到能交付」。

4.2 开局先搭三条「公共通道」，再写任何业务

全场性价比最高的一件事 —— 前 20% 时间就干这个

下面三条不属于某一个接口，属于全部接口。在每个接口里各写一遍，写着写着必然不一致，漏一处就是一处失分。做成统一通道，写对一次，后面每个接口自动满足。

通道要解决的事怎么下指令
干净拒绝 非法请求被拒后不能留下任何痕迹——不留半个对象、不扣一点额度、不留一条记录。批量中途失败要整批退回。 「所有写操作先过统一校验入口，保证在校验通过之前不碰任何状态。」
重放安全
幂等		 同一写操作发了两次，第二次返回第一次的结果，不产生第二次效果。 「写操作执行前先查幂等键处理过没有，处理过就直接返回上次的结果，不再执行。」
逻辑时钟 时间是服务自己维护的计数器，不是真实时间。到期结算集中由推进时钟触发。 「所有到期结算集中写在时间推进处，业务接口里不要各自判断过期。」

为什么第三条关键：模型默认爱「先创建再校验、先扣额度再判合法，出错再回滚」——回滚漏一个分支就留下脏东西，而「干净拒绝」恰好明令禁止。所以这句一定要写进第一段指令。

另有一条高频小项：钱一律整数化（用「分」存），取整方向题面写死，不同题还不一样，照抄，别按习惯来。

4.5 边界八查（没时间造用例时，至少把这八条写进第一段指令）

1. 非法输入
字段缺了、类型不对、ID 不存在 → 返回错误，不是直接崩

2. 负数与归零
金额算下来是负的，要不要 clamp 到 0

3. 数值精度
小数保留几位、往哪个方向取整

4. 空集合
空列表、空订单 → 返回空结果还是报错

5. 重复提交
同一请求提交两次，会不会产生两笔账

6. 终态
已完成、已取消之后还想改 → 应被拒

7. 失败不留痕
被拒绝的请求，不能改动任何数据

8. 错误码分层
不存在 404、业务拒绝 409/400、鉴权失败 403；全用 400 糊过去会成片丢分

4.6 指挥的三条纪律

  • 纠错要给「能执行」的话。「好像不太对，你看看」是无效的——AI 只能随便挑个地方动一下，然后回你「已修复」。有效版：第 3 条状态流转反了。PENDING 不能直接跳 PAID，应该是 PENDING → CONFIRMED → COOKING → READY → PAID，非法流转返 400。改完补一个「PENDING 直接打 PAID」的用例验证。
    错在哪 + 正确的是什么 + 返回什么 + 改完怎么验证，一句里四样都有。
  • 一轮只改一件事，改前先给护栏。每轮加一句「这一轮只做某某，不要重构任何已经跑通的部分」。
  • 拆任务按「能不能立刻验证」切。「先把数据层写了」验不了，不该单独切；「实现下单，含参数校验、金额计算、不存在的商品返错」写完立刻能打请求，可以切。
两条止损线

① 同一个问题三轮没解决 → 立刻新开会话，把报错重贴一遍（旧对话里失败的尝试会把它越带越偏）。

② 提交后分数往下走 → 立刻退回上一个好的状态。到后期改坏的概率并不比改好低。见好就收在这里是能力，不是怂。

05编程题（1 道）：语言不限，但必须自己处理输入输出

⚠️ 通知已明确：需要自己处理输入输出 → 这就是你现在最该动手练的

你平时刷 LeetCode核心代码模式（只写函数体）。这里是ACM 模式——自己读标准输入、自己打印输出。这个差异必须在 18:15 之前用两三道题练出手感，不然考场上第一题就卡在读入上。

✅ 修正：我此前说的「可能只能用 C++」作废

通知给的语言列表很全，Python 3 和 PyPy3 都在里面。所以你不必换语言——但要会挑实现：

如果题目输入量大（n 到 1e5 以上、一大坨数字），优先选 PyPy3 而不是 Python 3。PyPy 是 Python 的 JIT 实现，对纯 Python 的循环密集代码通常显著更快，而你的代码一个字都不用改。（提升幅度依题而异，不是固定倍数——别当规格看。）

曾经有场次那道研发岗题，Python/Java 因读入慢超时只拿到约 20% 的分。你现在的处境比当时好：通知给了 PyPy3 这个选项。另外如果题目本身适合，C++ 仍然是最稳的保险。

高频考点（按已出现频次）

考点套路要点
前缀和 / 贡献法「删点后数连通块」→ 翻译成「点数 − 边数」；每条边只记在编号较小的那一端，避免重复扣除。
并查集 + 逆序处理并查集只能合并不能分裂 → 正向删边没法做，就把操作反过来，删边变加边。这是近年区分度最大的考点。
前缀和优化递推k 阶斐波那契每项是前 k 项之和，朴素 O(nk) 超时 → 前缀和使每项 O(1)。取模注意负数：(x % MOD + MOD) % MOD。
数论因子个数为奇数 ⇔ 完全平方数（因子成对出现，只有 d = n/d 时多一个）→ 区间计数 floor(sqrt(r)) − floor(sqrt(l−1))。整数开方要修正浮点误差，别直接用 sqrt。
贪心 / 构造「相邻交换」翻译成「元素走多少格」，次序不变 → 挑一个整体旋转量，落到中位数最小化绝对值和。无解判定往往是奇偶性，两条判据缺一条就挂。
图论每条边走恰好一次并回到起点 → 欧拉回路，Hierholzer 算法。
堆 / 树遍历建堆要老老实实走一遍（从最后一个非叶结点开始下沉），再按完全二叉树形态做中序遍历。

07目录制与提交纪律（本场最容易踩的坑）

通知原文：完成当前目录后才能选下一个；提交目录前可改，提交后不能改

这意味着你有一个不可撤销的动作。三条规定照着执行：

  • 提交顺序 = 由稳到险。最有把握、最不容易再改出分的目录先提交掉；把你还想迭代的那个（通常是 AI Coding）留到最后提交，把剩余时间都给它。
  • 提交前逐条核一遍这个目录内的题号和答案都填了。提交之后不能回头，漏填就是白丢分。尤其注意有没有翻页没翻到的题。
