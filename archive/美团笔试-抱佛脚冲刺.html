01选择题：十道「考点指纹」（2026-09-05 场全套）

用法：每道看「指纹 → 判据 → 答案」，遮住答案先自己判一遍。判错的停下来想 30 秒为什么。这十道覆盖了「算法 4 + 深度学习 3 + 大模型 2 + 机器学习 1」的完整分布。

指纹 1 · 递归求值 — 给 g(t)= t>0 ? t*g(t-1) : 2，求 g(g(g(1)))。
判据：由内向外逐层算，每一层都要乘上 t；干扰项 = 只算最内层就停、或把基例 2 当每层固定值连乘。 答：48

指纹 2 · CNN 正确说法
判据：图像分类靠「图像+标签」训练 = 有监督（对）。卷积核越大参数越多 → 更容易过拟合，不是更不容易。池化 = 下采样扩感受野，跟「全连接换成 RNN」无关。二维输入本来就是卷积的老本行。 答：有监督那项

指纹 3 · 分布式训练通信优化 — 梯度聚合通信占 70% 且可与反向计算重叠。
判据：反向传播从输出层往输入层走，靠输出的层梯度先就绪 → 按就绪顺序分桶立即发 all-reduce，把通信藏进后续计算（= PyTorch DDP 梯度分桶重叠）。「换随机猜参数」「关所有通信」「把 batch 顶到显存上限」全是干扰。 答：梯度就绪顺序发通信

指纹 4 · 单神经元二分类输出层激活
判据：输出要当概率 → logistic / sigmoid（压到 (0,1)，配二元交叉熵）。线性恒等不能当概率；单神经元没有多通道可 argmax；符号函数导数为零训不动。 答：logistic

指纹 5 · 无法直接解决长序列建模的是？
判据（本场最容易想反的一题）：FlashAttention 只优化显存与访存，数学上与标准注意力等价，复杂度仍是 O(n²) → 它才是「无法直接解决」的那项。Transformer-XL 分段递归缓存、Performer 核方法线性注意力、Longformer/BigBird 分块稀疏，都真改了复杂度或有效上下文。 答：FlashAttention

指纹 6 · 邻接矩阵存稠密图，DFS 复杂度
判据：找一个顶点的全部邻居要扫一整行 O(n)，n 个顶点各扫一次 → 时间 O(n²)；空间不计存图则只剩标记数组和递归栈 → O(n)。邻接表才是 O(n+e)。 答：O(n²) / O(n)

指纹 7 · 状态价值函数 V^π 的定义
判据：从状态 s 出发、之后遵循策略 π 的累积折扣回报的期望。干扰项「对动作价值取 max」= 最优状态价值 V*，只在最优策略下成立；转移概率是环境动力学不是价值。 答：期望那项

指纹 8 · 词向量正确说法
判据：word2vec 本质是降维（V 维 one-hot → 几百维稠密）。one-hot 是 V 维向量不是 1 个比特；词袋/TF-IDF/共现矩阵+SVD（LSA）都不需要生成式语言模型；字符级卷积是缓解未登录词、不是把词表膨胀。 答：word2vec 是降维

指纹 9 · 给前序，判哪个中序不可能
判据（固定套路）：前序首元素定根 → 在中序里以根切左右两段 → 递归检查左右段元素集合与前序对应段是否一致。矛盾常出现在子树：右子树前序定根 E，若中序里 E 左边只有 F，则前序中紧跟 E 的应该是 F——不是就矛盾。 按切分逐层验

指纹 10 · 建成最小堆后的中序遍历
判据：从最后一个非叶结点（下标 n/2−1）开始自底向上下沉，老老实实把建堆过程走一遍排出数组，再按完全二叉树形态做中序（左→根→右）。光看选项排除不掉，得动笔。 草稿纸上走一遍

再补五个「大概率出现」的 AI / 八股指纹

指纹一句话判据
SFT vs RLHF vs 预训练预训练=无标注语料学语言；SFT=有标注指令数据教「听懂指令」；RLHF=用人类偏好奖励模型调「说得好」。
RAG 标准链路切分 → 向量化 → 检索 → 重排 → 拼上下文 → 生成；幻觉治理靠引用绑定证据。
Function Calling / 工具调用模型输出结构化参数由外部代码执行；副作用操作要确认+幂等（正好对应你 A2/A3 卡）。
死锁四条件互斥、占有且等待、不可剥夺、循环等待；破坏任一条即可预防（资源有序分配破循环等待最常用）。
进程 vs 线程进程是资源分配单位、线程是调度单位；线程共享地址空间，切换代价更小（对应你 N3/O1 卡）。

骨架 1 · 并查集（+ 逆序处理删边）

class DSU:
    def __init__(self, n):
        self.p = list(range(n + 1))
    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x
    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra != rb: self.p[ra] = rb

# 先标记所有要删的边 → 用「永不被删」的边建初始 DSU

骨架 2 · 前缀和优化递推（k 阶斐波那契）

# f[1..k]=1；f[i]=前 k 项之和。朴素 O(nk) 超时 → 前缀和每项 O(1)
MOD = 10**9 + 7
f = [0]*(n+2); P = [0]*(n+2)
for i in range(1, n+1):
    f[i] = 1 if i <= k else (P[i-1] - P[max(0, i-1-k)]) % MOD
    P[i] = (P[i-1] + f[i]) % MOD

骨架 3 · 贡献法（删点后的连通块数）

# 树按编号 1..n 依次删点，每次输出剩余连通块数
# 森林：连通块 = 点数 - 边数；每条边只记在「编号较小端」
bigger = [0]*(n+2)
for _ in range(n-1):
    u, v = int(next(it)), int(next(it))
    if u > v: u, v = v, u
    bigger[u] += 1
broken = 0
for i in range(1, n+1):
    broken += bigger[i]
    ans = (n - i) - ((n - 1) - broken)   # 收集进 res

3.2 五个最常见的死法（对照自查，每条都有解）

死法解法（抄作战卡）
① 上来就「帮我实现一下这个系统」用第一段指令模板：环境原样抄 + 规则原样搬 + 字段名写死 + 三条公共通道先搭。
② 没搭公共通道就写业务，各接口越写越不一致前 20% 时间只干干净拒绝 / 重放安全 / 逻辑时钟三件事，能跑再写业务。
③ 响应体字段名凭感觉编判题按字段名取值，对不上就是 0 分。契约逐条写死，一个字母都不许模型自由发挥。
④ 公开样例全过就交让 AI 造隐藏用例打自己，挂掉的连报错贴回修，走 2–3 轮。记住加「先不要改我的业务代码」「已经通过的不要动」。
⑤ 同一问题死磕 / 分数下降还赌三轮没解决→新开会话重贴报错；提交后分数下降→立刻回退到上一个好状态。见好就收是能力。
拿分顺序：先保「冒烟 + 基础」两档满分，再冲「高级 / 复杂」

AI Coding 按冒烟 / 基础 / 高级 / 复杂四档业务给分。主干业务（冒烟+基础）才是基本盘——一个功能写不完可以砍，但主干的接口契约、状态机、幂等、错误码必须全对。题面说「写不完是常态，怎么拆由你判断」，分数看取舍，不看完成度。
