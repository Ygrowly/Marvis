01先说三个决定写法的事实

事实它怎么影响了这一版
你的英语口径是 CET-6 所以这一版不写任何需要口语实力的炫技句——不用从句套从句、不用高级词。你说得清楚比说得漂亮重要。写自己能稳住的语言，是这一版的第一原则。
这岗实际是数据开发 / BI 自我介绍里把数据库、SQL、数据建模放到 AI 前面。跟中文版同一个道理：让对方听出你读懂了岗，而不是「想做 AI 的人海投到这里」。
法资公司，英语是会真看的 所以不要假装流利。结尾主动给一个诚实的层次（读技术文档没问题、口语在练）——凯捷社招 JD 里有「英语可作为工作语言」的要求，坦诚比硬撑安全得多。

02正式版（实测 161 词 · 目标 55–70 秒）

  1. Good afternoon. My name is Liu Yuguang, a senior at University of South China, majoring in Data Science and Big Data Technology. 下午好。我叫刘宇广，南华大学大四，数据科学与大数据技术专业。
  2. I've had two internships in AI application development. At Kingsoft, I work on the backend of an energy monitoring Agent. 我有两段 AI 应用开发实习。在金山我负责一个能耗监控 Agent 的后端。
  3. I designed a four-layer data model and a data quality system. That raised aggregation completeness from 96.8 to 99.7 percent, and cut report query latency from 20.4 seconds to 2.8 seconds. 我设计了四层数据模型和一套数据质量体系，把聚合完整率从 96.8% 提到 99.7%，报表查询延迟从 20.4 秒降到 2.8 秒。
  4. Earlier, on a natural-language data platform, I optimized a million-row query from 12.6 seconds to 2.7 seconds. 更早一段做自然语言问数平台，我把百万行的查询从 12.6 秒优化到 2.7 秒。

  6. I've passed CET-6 and read English technical documentation daily, so reading and writing are comfortable. I'm still working on my spoken English. 我已通过 CET-6，每天读英文技术文档，读写比较轻松。口语我还在练。
  7. This role combines SQL and data engineering with model work, which fits my background well. Thank you. 这个岗位把 SQL、数据工程和模型工作结合在一起，跟我的背景很匹配。谢谢。

04发音与卡壳预案（HR 面真正会翻车的地方）

三个可能被打断的地方

情况一：HR 说「用中文就行」
→ 别坚持。回一句 「好，那我用中文」，然后直接接第 05 节的中文自我介绍。不要显得遗憾或者想争取——对方要什么给什么。
情况二：中途卡住、词想不起来
→ 只用这两句过渡，不要沉默：
  • 「Sorry, let me rephrase that.」（抱歉，我换个说法）
  • 「Let me put it another way.」（我换个方式讲）
卡住 3 秒以上必须有声音，静默比说错严重得多。说完这句就直接跳过那句，往下讲——没人会回去检查你漏了一句。
情况三：用英语追问技术问题
→ 优先说短句：「I used Python and PostgreSQL. I optimized the query by adding composite indexes.」
  宁可说 5 个短句，不要说 1 个长难句。短句说对了对方听得懂；长句说到一半崩了，印象分直接掉。
三个禁忌：
① 不要背成朗诵腔——语调全平、句子间停顿一样长，这是最典型的「背稿」信号。
② 不要用没把握的高级词。这版里的词都是初高中词汇，是有意的。
③ 不要写「My English is poor」。这句自贬一出口，后面说得再好也白搭。要说的是「还在提升」——是进行时，不是否定式。

05中文自我介绍（对不上就用这版）

内容与英文版一一对应，所以两边记骨架就行，不用记两套内容。中文版完整话术在作战卡第 05 节，这里只给一句话版兜底：

面试官好，我是刘宇广，南华大学数据科学与大数据技术专业 2027 届。我有两段 AI 应用开发实习：最近在金山负责一个能耗监控 Agent 的后端，做了四层数据模型和数据质量体系，把聚合完整率从 96.8% 提到 99.7%、查询 P95 从 20.4 秒降到 2.8 秒；更早一段做自然语言问数平台，把百万行查询从 12.6 秒优化到 2.7 秒。我的主力栈是 Python、SQL 和 PostgreSQL，SQL 优化和数据建模是我最强的地方。投这个岗位是因为它的数据库和 SQL 要求跟我的能力很对口，模型评估这块我也有实习积累。

06今晚怎么练（15 分钟就够）

  • 3 分钟｜查词：对着第 04 节的表，把 8 个词各念 5 遍。用手机词典听一下 aggregation / completeness / latency / PostgreSQL 四个的原声。先做这个
  • 4 分钟｜掐表念：对着第 02 节整段念 2 遍，用手机录音，看落在 55–70 秒没有。这是全篇唯一必须做的事。
  • 4 分钟｜回听：重点听两件事——有没有在赶、有没有音调全平。这两个是背稿感的来源。
  • 3 分钟｜看骨架：只对着第 03 节的 10 个锚点，自己说一遍，不要求跟原文一样。
  • 1 分钟｜记应急句：把 Sorry, let me rephrase that. 说顺。
  • 不要做：不要重写这一版、不要换成更华丽的句子。你要练的是「稳」，不是「难」。
