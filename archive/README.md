- **本目录不参与站点构建**。`site/build.py` 的扫描目录是显式白名单（`TOPIC_DIRS` / `REVIEW_DIRS` / `MODULE_DIRS` / `CARD_DIRS`），其中**不含 `archive/`**；且 `projects/` 一项只用于抽取 `::card` 块，而这批归档材料里没有任何 `::card` / `::figure` 标记。移入本目录不影响 `python site/build.py` 的输出（2026-09-14 实测：移动前后 `site/` 全树字节一致）。
